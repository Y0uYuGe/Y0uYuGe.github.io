# LiDAR
## Principle

LiDAR is a sensor that uses lasers for distance measurement and environment perception. It measures the distance of objects by emitting laser beams and receiving reflected light, generating point cloud data used to build a three-dimensional model of the environment. LiDAR is widely used in robotics, autonomous driving, drones, and other fields.



RViz is a visualization tool in ROS (Robot Operating System) used to display and debug robot data. It supports multiple data types, including robot models, sensor data, point clouds, images, etc.

Gazebo is a physics simulator used to simulate the behavior of robots in virtual environments. It supports multiple robot models and sensors, and provides physics simulation capabilities.


# Message Package Format

LiDAR message package [https://docs.ros.org/en/noetic/api/sensor_msgs/html/msg/LaserScan.html](https://docs.ros.org/en/noetic/api/sensor_msgs/html/msg/LaserScan.html)
[https://docs.ros.org/en/noetic/api/sensor_msgs/html/](https://docs.ros.org/en/noetic/api/sensor_msgs/html/msg/)

`rostopic echo /scan --noarr` is a ROS (Robot Operating System) command used to subscribe to and display the message content on the /scan topic. The --noarr parameter is used to simplify the output: instead of showing the full content of arrays, it shows the array's type and length.

```bash
llk@LLK:~$ rostopic echo /scan --noarr
header:
  seq: 14445
  stamp:
    secs: 1533
    nsecs: 920000000
  frame_id: "laser"
angle_min: -3.141590118408203
angle_max: 3.141590118408203
angle_increment: 0.017501894384622574
time_increment: 0.0
scan_time: 0.0
range_min: 0.23999999463558197
range_max: 6.0
ranges: "<array type: float32, length: 360>"
intensities: "<array type: float32, length: 360>"
---
```
1. header
seq: the sequence number of the message, used to identify the order of messages. In this example, seq: 14445 means this is the 14445th message.
stamp: the timestamp of the message, indicating when the message was generated.
secs: the seconds part of the timestamp; secs: 1533 means the message was generated at 1533 seconds.
nsecs: the nanoseconds part of the timestamp; nsecs: 920000000 means the message was generated at 920,000,000 nanoseconds.
frame_id: the reference coordinate frame of the message; frame_id: "laser" means the message's reference coordinate frame is laser.
2.  angle_min and angle_max
angle_min: the starting angle of the scan, in radians. angle_min: -3.141590118408203 means the scan starts at -π radians (i.e., -180 degrees).
angle_max: the ending angle of the scan, in radians. angle_max: 3.141590118408203 means the scan ends at π radians (i.e., 180 degrees).
3.  angle_increment
angle_increment: the angular increment of the scan, in radians. angle_increment: 0.017501894384622574 means the angular increment between each scan point is about 1 degree (0.0175 radians).
4.  time_increment and scan_time
time_increment: the time increment between two adjacent measurements in the scan, in seconds. time_increment: 0.0 means the time increment between adjacent measurements is 0 seconds, typically used for static scans.
scan_time: the time required to complete one full scan, in seconds. scan_time: 0.0 means the scan time is 0 seconds, typically used for static scans.
5.  range_min and range_max
range_min: the minimum distance the LiDAR can reliably measure, in meters. range_min: 0.23999999463558197 means the minimum measurable distance is 0.24 meters.
range_max: the maximum distance the LiDAR can reliably measure, in meters. range_max: 6.0 means the maximum measurable distance is 6 meters.
6.  ranges and intensities
ranges: a float array containing the distances from the LiDAR to each obstacle. ranges: "<array type: float32, length: 360>" means the array contains 360 floats, each representing the distance at a specific angle.
intensities: a float array containing the reflection intensity values corresponding to the distances in the ranges array. intensities: "<array type: float32, length: 360>" means the array contains 360 floats, each representing the reflection intensity at a specific angle.

# LiDAR Obstacle Avoidance
When LiDAR data is received, determine whether there is an obstacle and rotate accordingly



![在这里插入图片描述](/images/csdn/2025/csdn-145435339/image-005-c1da97ed3c.png)
When no new velocity packet is received, the robot moves at the speed specified by the previous packet

```cpp
#include <ros/ros.h>
#include <sensor_msgs/LaserScan.h>
#include <geometry_msgs/Twist.h>
// geometry_msgs 是 ROS 中的一个标准消息包，它定义了几何相关的消息类型，如 Point、Vector3、Twist 等。
// sensor_msgs 包依赖于 geometry_msgs，因此当你在 find_package 中指定了 sensor_msgs 时，catkin 会自动加载 geometry_msgs 作为依赖项。
ros::Publisher vel_pub;
static int nCount=0;
void LidarCallback(const sensor_msgs::LaserScan msg)
{   
    //fmiddist 通常是指 前方中间距离（Front Middle Distance）的缩写。它表示激光雷达在正前方方向（通常是 180 度）测得的距离值
    float FMidDist=msg.ranges[180];
    ROS_INFO("前方测距 ranges[180] = %f 米", FMidDist);
    //避障部分
    if(nCount>0)
    {
        nCount--;
        return;  //继续保持之前的运动
    }
    geometry_msgs::Twist twist;
    if(FMidDist<1.5) //1.5米 一个grid是1米
    {
        twist.angular.z = 0.5;
        nCount=30;
    }
    else
    {
        twist.linear.x = 0.5;  
    }
    vel_pub.publish(twist);
}

int main(int argc, char *argv[])
{
    setlocale(LC_ALL,"");
    ros::init(argc,argv,"lidar_node");
    ros::NodeHandle n;
    ros::Subscriber lidar_sub = n.subscribe("/scan",10,&LidarCallback);
    //避障部分
    vel_pub = n.advertise<geometry_msgs::Twist>("/cmd_vel",10);
    //得到scan话题里的雷达数据后选择行为
    ros::spin();
    return 0;
}
```


```python
#! /usr/bin/env python3
#coding=utf-8

import rospy
from sensor_msgs.msg import LaserScan
from geometry_msgs.msg import Twist
count=0
def LidarCallback(msg):
    global vel_pub
    global count
    FMidDist=msg.ranges[180]
    rospy.loginfo("前方测距 ranges[180] = %.2f 米",FMidDist)
    if count>0:
        count=count-1
        return
    vel_cmd=Twist()
    if FMidDist<1.5:
        vel_cmd.angular.z=0.5
        count=30
    else:
        vel_cmd.linear.x=0.5
    vel_pub.publish(vel_cmd)

if __name__=="__main__":
    rospy.init_node("lidar_node")
    lidar_sub=rospy.Subscriber("/scan",LaserScan,LidarCallback,queue_size=10)
    vel_pub=rospy.Publisher("/cmd_vel",Twist,queue_size=10)
    rospy.spin()
 
```
