### atoi
atoi is a function in the C standard library used to convert a string to an integer. The function's name comes from the abbreviation of "ASCII to integer". The atoi function is defined in the <stdlib.h> header file, and what it basically does is parse a string and convert it into a value of type int.

The function prototype is as follows:

```c

int atoi(const char *str);
```

 
The parameter str is a pointer to a character array terminated by the null character '\0' (i.e., a C string). The atoi function scans the string str, skipping any whitespace characters (such as spaces) until it encounters the first non-whitespace character, and then parses starting from that character until it encounters the first non-digit character or the end of the string.

Here are the general steps for using the atoi method:

1. Ignore all whitespace characters at the beginning of the string.
2. Record the sign (if any). Positive numbers usually have no sign, while negative numbers start with -.
3. Parse the digits in the string until a non-digit character or the end of the string is encountered.
4. Collect the parsed digits and convert them into an integer.
5. If the parsed digits are preceded by a -, convert the result to a negative number.
## __errno_location()
__errno_location() is a function defined on certain UNIX-like systems, particularly in the GNU C Library (glibc) on Linux systems. This function is used to obtain the address of errno. errno is a global variable or macro used to store the error code encountered by a function during execution.

In multi-threaded applications, using a global variable to store error codes is problematic because multiple threads updating this variable at the same time would conflict with each other. To solve this problem, errno in multi-threaded environments is generally implemented as a macro that maps to thread-local storage (TLS), ensuring that each thread has its own copy of the errno value.

The __errno_location() function is used to obtain the address of the current thread's errno variable. This function is usually not used directly by applications; instead, it is called by the errno macro to obtain the current thread's errno value. If you directly include <errno.h> and use errno, the compiler on most modern systems will automatically handle it as a call to a function like __errno_location().
###  Related Explanation
if (one_char == -1): This line checks whether the variable one_char equals -1. In functions that read characters from a stream, -1 usually indicates that an error occurred or the end of file (EOF) was reached.

if (*__errno_location() != 11 && *__errno_location() != 4): This is a nested if statement that executes when one_char equals -1. It uses the __errno_location() function to get the address of errno and dereferences it to check its value. It checks whether errno is not equal to 11 and 4, two numbers that represent specific error codes:

11 is EAGAIN (an error code on Linux), indicating that the I/O operation would block and should be retried later.
4 is EINTR, indicating that the operation was interrupted by a signal before it could complete.

After extending, when the large chunk is split by malloc, the remaining part overlaps with the position of the originally obtained related chunk, thereby leaking the unsortedbin base address.
## Leaking the heap base address
Pretty much the same as leaking the libc base address, except that this chunk is freed into the tcachebin.

## Modifying the fd of a chunk placed in the tcachebin to stdout
 **Remember to free a chunk into the tcachebin in advance first, and then modify it.**
 
By freeing a chunk so that it sits in the tcachebin, and then adding again through another original chunk with an add size range that covers the beginning part of that freed chunk, you can modify the beginning part of the freed chunk during the add.
