The expert says there is a movaps instruction at the end of this function:
movaps[rsp+198h+var_158],xmmo
(We can directly search in IDA's system region to see whether this instruction exists)
This instruction requires the hexadecimal form of the value of rsp+198h+var_158 to be a multiple of 0x10, otherwise you cannot getshell

Methods:
1. Change the payload length (local variables are pushed onto the stack, the stack length changes) so that the rsp value changes
2. Use ret to make rsp+1
3. Use other gadgets to affect rsp
4. Stack pivoting: when the payload length is limited, keep trying methods to change rsp
5. Calling execve requires three arguments, which is more demanding
