## Finding the Inorder Predecessor the Crude Way
When visiting a node, first check whether it matches the target node; if it matches, save it in the final pointer; if not, update by assigning the current node to the pre pointer. Then visit the next nodes in turn

![在这里插入图片描述](/images/csdn/2023/csdn-134761763/image-010-e3ecc99899.png)
# Inorder Threading
Check the predecessor's right child and the current node's left child; if both meet the conditions, connect them, then update the predecessor node to the current node
![在这里插入图片描述](/images/csdn/2023/csdn-134761763/image-011-7dd79a0f9d.png)

## Finding the Preorder Predecessor in a Preorder Threaded Binary Tree
Because a node's left and right children can only be successors, the predecessor cannot be found through the left and right children. In this case, you need to add a parent element or traverse from the beginning
In the third case, go right first; if there is no right subtree, go left
![在这里插入图片描述](/images/csdn/2023/csdn-134761763/image-023-3060082382.png)

## Finding the Postorder Successor in a Postorder Threaded Binary Tree
The left and right children can only be predecessors, not successors, so you have to add a parent element or traverse from the beginning
