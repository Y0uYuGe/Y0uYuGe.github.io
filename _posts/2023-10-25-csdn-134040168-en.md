# The Emergence and Development of Computers

Hardware technology: vacuum tubes - transistors - integrated circuits

# The Emergence and Development of Microcomputers

Microprocessor chip: the control unit and the arithmetic logic unit integrated on a single chip

Machine word length: the number of binary bits a computer can process in one operation

# The Rise and Development of Software Technology

## Languages

Machine language: binary, machine-oriented

Assembly language: symbolic, machine-oriented

High-level language: symbolic, problem-oriented

## Software

### System Software (manages the computer system)

Language processing programs: assemblers, compilers, interpreters

Operating systems: DOS UNIX Linux Windows

Service programs: linking programs, debugging programs, diagnostic programs, troubleshooting programs

Database management systems: databases and database management software

Network software: network protocol software, network application systems

### Application Software (various programs written for specific tasks)

Word processing and typesetting software, communication software, etc.
