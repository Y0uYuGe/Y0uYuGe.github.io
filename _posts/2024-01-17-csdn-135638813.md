## The functions of computer networks
1. Data communication, i.e. transmitting data
2. Resource sharing: for hardware, think of a network printer (a printer has an IP address; you can connect to the printer over the network and then issue a print request); software sharing means using software on someone else's computer through remote network access; data sharing can be exemplified by things like Baidu Wenku
3. Distributed processing (Hadoop)
![Image](/images/csdn/2024/csdn-135638813/image-004-b5e5564564.png)


> Hadoop is a distributed system infrastructure developed by the Apache Foundation; it is a software framework of a storage system and a computing framework. Its main purpose is to solve the storage and computing problems of massive data, and it is the cornerstone of big data technology. The core of Hadoop is HDFS (Hadoop Distributed File System) and MapReduce. HDFS is a distributed file system that runs on standard or low-end hardware; in addition to its high fault tolerance and native support for large datasets, it provides better data throughput than traditional file systems. MapReduce is a framework that helps plan parallel computations on data. In addition, Hadoop includes Yet Another Resource Negotiator (YARN), a tool responsible for managing and monitoring cluster nodes and resource usage, which schedules jobs and tasks.

4. Improved reliability: under distributed processing, even if one machine crashes, other machines can take its place — the overall speed is just relatively slower
5. Load balancing: distributed processing keeps the tasks undertaken by each computer from becoming unbalanced

# The composition and classification of computer networks
## The composition of computer networks
Software is deployed on corresponding hardware
Communication between hosts is actually communication between processes
 
 The more requests a server receives, the slower the client gets responses
B/S: it's just that the client is a browser
P2P: peer to peer; all hosts are simultaneously clients and servers (here, the more hosts, the faster the download speed. For example, A transmits data to both B and C at the same time, while B also transmits data to C; the data C needs can then be divided into two parts — one part obtained from B, the other part obtained from C)
![Image](/images/csdn/2024/csdn-135638813/image-010-5e0d672548.png)
![Image](/images/csdn/2024/csdn-135638813/image-011-bf02df2b4e.png)
## The classification of computer networks
Wide area network: between countries, between provinces — anyway, larger than a city
Local area network: networks like those of schools, companies, and organizations
Initially classification was by distribution range, but in the end it comes down to what types of technology are used — that determines which scope of network it is


Circuit switching: occupies the link resources; others cannot use them (similar to a telephone)

Message: a file or an individual item to be transmitted
Message switching and packet switching: store and forward

Broadcast networks mostly use a bus topology
Point-to-point networks mostly use a mesh topology
![Image](/images/csdn/2024/csdn-135638813/image-012-9cc997c888.png)
## Summary
Local area network: mostly bus type
Wide area network: mostly mesh type
Broadcast vs. point-to-point mainly depends on whether there is store-and-forward and route selection
