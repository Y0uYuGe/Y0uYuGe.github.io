# Overview
 In set-associative mapping, after finding the corresponding Cache set, the main memory content is placed wherever there is space in that set
 The tag is used to identify which block in main memory it corresponds to, i.e., the block number

# Direct Mapping (Can Only Be Placed in a Fixed Position)
When two main memory blocks map to the same position, the previously mapped content is overwritten.
