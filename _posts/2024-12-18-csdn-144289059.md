DHKE (Diffie-Hellman Key Exchange) is a key exchange protocol, not used for encryption (for DHKE-based encryption, ElGamal can be used).

It is widely used in protocols such as SSH (Secure Shell), TLS (Transport Layer Security), and IPSec (Internet Protocol Security).


# DH Key Exchange

![Image](/images/csdn/2024/csdn-144289059/image-001-6d8b5f4555.png)
Set the parameters p=29, α=2.
- Each side derives its own private key.
- Each side derives its own public key.
- The two sides exchange public keys.
- Each side computes the shared key, which is identical.
