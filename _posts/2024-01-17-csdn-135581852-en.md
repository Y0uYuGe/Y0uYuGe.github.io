# Interrupt masking technology
The priority levels of the hardware queuing circuit are fixed

Each interrupt source's mask word is composed of the mask flip-flops of all interrupt sources

# Summary
The interrupt vector is the address of the interrupt service routine
The vector address is the address of the instruction that jumps to the address of the interrupt service routine
The program execution trace is judged based on the interrupts and mask words to determine the order and duration of program execution
# Extension
The INTA signal goes to the interrupt controller, thereby letting the interrupt controller obtain the interrupt type number
Different interrupt types correspond to different interrupt request input signals

![在这里插入图片描述](/images/csdn/2024/csdn-135581852/image-006-aacfae052b.png)
First, the registers of the interrupt request register connect to various IO devices. When an IO device issues an interrupt request, it is output through the control logic INT to the CPU's INTR interface. If the CPU has interrupts enabled, it sends back a feedback signal to the interrupt controller via INTA. Then, through the interrupt controller's interrupt arbitration and the processing of the interrupt service register, the interrupt vector address is obtained, and the interrupt type number is passed to the CPU via the data bus

The vector address is the interrupt type number

The interrupt mask register stores the mask words of each interrupt
