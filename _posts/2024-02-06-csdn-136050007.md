# Related Knowledge
## File Viewing Commands
When we want to view the contents of some text files, we use a text editor to view them. On Linux, you can use some commands to preview the contents of a text file without opening it in a text editor. Just like viewing a picture — you generally just click on the picture to view it, without needing to download dedicated picture software. This level mainly introduces commonly used viewing commands, such as: cat, head, tail, and nl.

### cat Command
The cat command is used to concatenate files and print them to the standard output device. Many people call it the "kitty" command, but the cat command is actually an abbreviation of concatenate, meaning to display text content continuously. The cat command is often used to view files with little content, because when the file is too large, the earlier content scrolls off the screen and can no longer be seen.

### head Command
The head command can be used to view the beginning part of a file; it has a commonly used parameter -n for specifying the number of lines to display, which defaults to 10, that is, displaying 10 lines of content.

```bash
如果查看文件前 5 行，可以使用命令head -5 filename
```

### tail Command
The purpose of the tail command is to output the last part of the specified file to the standard device, usually the terminal; in plain terms, it displays the last few lines of a certain archive file (the last 10 lines by default) on the terminal.

> tail -f filename displays the tail content of the file filename on the screen and keeps refreshing; as long as filename is updated, you can see the latest file content.

```bash
查看最后文件 5 行命令tail -5 filename
```

### nl Command
The nl command writes the specified file to the standard output with line numbers added. Blank lines are not numbered, but the blank lines still exist.

### Basic File Editing Commands
For file editing operations, you can use the vi/vim editor; vim is an upgraded version of vi, and the operations of the two are basically the same.
The basic commands for the editor are as follows:
- vi filename: open the file.
- Press i or a on the keyboard to edit: when insert appears at the very bottom, you have entered edit mode and can edit.
- Press the Esc key on the keyboard: exit edit mode.
- Type :q! on the keyboard: forcibly exit editing without saving.
- Type :wq or :x on the keyboard: save the file and exit.
