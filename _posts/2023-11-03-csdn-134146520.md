# Segmentation
## Distribution
In 32-bit mode, memory is divided into segments one by one
Discrete distribution means they are not necessarily right next to each other
## Addressing
32-bit: segment selector + offset within the segment
16-bit: segment starting address*16 + offset within the segment

> Why ×16? Because in the 8086 CPU, the address bus is 20 bits, but the registers are 16 bits, addressing at most 64KB—it cannot address 1M of memory. So Intel designed this addressing method: first shrink by 4 bits to 16 bits and put it into the segment register; when used, expand it back to 20 bits. This also caused the restriction that the starting address of a segment must be a multiple of 16

Difference: in 32-bit mode, addressing does not need to shift left by four bits to get the starting address of the segment
           32-bit mode can define the position and length of segments by itself
## Global Descriptor Table (GDT)
The Global Descriptor Table is a memory space, at most 64KB (1KB=1024B); it can be understood as an array where each element is a segment descriptor
The address pointer of the Global Descriptor Table is stored in a special register called GDTR
GDTR is a 48-bit register. The address pointer of the global descriptor is also 48 bits

## Segment Descriptor
 The segment descriptor records the characteristics of this segment
 Each segment descriptor occupies eight bytes, divided into the high 32 bits and the low 32 bits
 
 ![Image](/images/csdn/2023/csdn-134146520/image-002-2bb774a11d.png)
 The base address and the length are stored split apart
 
 1GB=1024MB
 1MB (megabyte) = 1024KB (kilobyte)
 1KB=1024B (byte) 
 1Byte (byte)=8bit (bit)

The four registers CS, ES, SS, DS are still 16-bit registers in 32-bit mode

> Segment selector: in 32-bit assembly, the 16-bit segment registers (CS, DS, ES, SS, FS, GS) no longer store segment base addresses but store segment selectors

In real mode, what is stored is the segment address
In protected mode, what is stored is the segment selector
Protected mode also comes with two free segment registers: FS and GS
 CS and SS point to the correct type of segment
