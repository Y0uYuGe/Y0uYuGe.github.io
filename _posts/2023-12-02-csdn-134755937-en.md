# Preface
Since the previous operating system proved too difficult, I'm going to start from this RISC-V operating system and refine it later once my knowledge goes deeper.
# Environment Setup
Install the dependencies
```bash
$ sudo apt update
$ sudo apt install build-essential gcc make perl dkms git gcc-riscv64-unknown-elf gdb-multiarch qemu-system-misc
```
Create a directory risc-v-os and enter it
![在这里插入图片描述](/images/csdn/2023/csdn-134755937/image-001-80fd054a70.png)Copy the compressed package to this directory
![在这里插入图片描述](/images/csdn/2023/csdn-134755937/image-002-5d78a088d2.png)
Extract it here

Write export PATH="$PATH:/home/llk/risc-v-os/tools/gcc/bin:/home/llk/risc-v-os/tools/qemu/bin" into the home directory
![在这里插入图片描述](/images/csdn/2023/csdn-134755937/image-003-d2ad9d5258.png)
Then activate it
```bash
source $HOME/.bashrc
Linux source命令：

通常用法：source filepath 或 . filepath

功能：使当前shell读入路径为filepath的shell文件并依次执行文件中的所有语句，通常用于重新执行刚修改的初始化文件，使之立即生效，而不必注销并重新登录。
```
Then import the project files
Try whether make can compile successfully
![在这里插入图片描述](/images/csdn/2023/csdn-134755937/image-004-ddb5049625.png)
That means success
