# BCD Codes
The value of each digit is multiplied by its weight
Four binary bits can represent one decimal digit, with a few redundant cases left over
That is, the value corresponding to the four binary bits must be 0~9
9+9 equals 18, and the binary number is also out of range, so 6 must be added

If the result of an addition falls in 1010~10010, 6 must be added

![Image](/images/csdn/2024/csdn-135445281/image-002-49801ffd25.png)
# Excess-3 Code and 2421 Code
The excess-3 code is a non-weighted code

2421 is a weighted code

The 2421 code for 5 can be 0101 or 1011, so to avoid this situation, it is stipulated that for values greater than or equal to 5 the first bit is always 1
