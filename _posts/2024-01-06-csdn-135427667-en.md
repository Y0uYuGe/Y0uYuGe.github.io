# Algorithm Efficiency Analysis
Each time, the function first gets the pivot position for the range, then splits it into two ranges with that pivot as the middle element, and applies the function to each range

The partition function needs low and high to traverse all the data in the range, because the termination condition is low=high
![在这里插入图片描述](/images/csdn/2024/csdn-135427667/image-056-fc735c20c0.png)
The space complexity here corresponds to the maximum depth of the function call stack during the calls
![在这里插入图片描述](/images/csdn/2024/csdn-135427667/image-057-8d2ed98e0f.png)
Each level of quicksort processes the sublists split by the previous level of quicksort; each level's processing splits into two sublists![在这里插入图片描述](/images/csdn/2024/csdn-135427667/image-058-d1487d18ac.png)
The number of recursion levels is the number of levels of the binary tree
![在这里插入图片描述](/images/csdn/2024/csdn-135427667/image-059-dcb1b44c14.png)
