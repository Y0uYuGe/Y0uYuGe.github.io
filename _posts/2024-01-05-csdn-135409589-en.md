# Functions of the IO Interface
Data buffering: the speed gap between the CPU and peripherals is huge. With a data buffer register, for example, a peripheral can slowly write into the data buffer register, and once it is full, the CPU quickly takes the data away

Error or status monitoring: the IO interface needs to report the status of peripherals to the CPU. The IO interface detects the status of the peripherals connected to it, and once a peripheral's status changes, it modifies the status register; the CPU can then learn the peripheral's status by reading the IO interface's status register

Data format conversion: sometimes a peripheral transfers serially in and out of the IO interface, while the CPU transfers in parallel in and out of the IO interface

# Detailed IO Interface Structure
![在这里插入图片描述](/images/csdn/2024/csdn-135409589/image-004-b4b38f54bd.png)  One IO interface can sometimes connect multiple peripherals![在这里插入图片描述](/images/csdn/2024/csdn-135409589/image-005-cb8b4eeb45.png)
Since interrupt types differ, the interrupt type number also has to be transferred over the data lines
Besides indicating the IO port, the address lines can sometimes also indicate the device number, but the two require two separate transfers
The device to operate on can be determined by sending a device number, or each device can correspond to a set of registers, so operating directly on those registers operates the device
