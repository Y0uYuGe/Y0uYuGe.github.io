# Cgroups 
It limits the resources used by a group of processes (such as CPU, memory, storage, network, etc.)

# mount

A device's storage structure is a filesystem; mounting means associating it with a directory structure on the computer. That is, a mapping
Unmounting removes this mapping while applying the modifications to the original device's stored contents

The mount command is used in Linux and Unix-like systems to mount a filesystem to a specified mount point (directory). Through mounting, the files and directories in the filesystem become accessible under the specified mount point.

The basic syntax of the mount command is:

```bash
mount [options] <device> <mount_point>
```

 
Here, the <device> parameter specifies the device or partition to be mounted, which can be a hard disk, a partition, a disk image, and so on. The <mount_point> parameter specifies the directory to mount the device to.

Some common options of the mount command include: - -t <type>: specifies the filesystem type, which can be ext4, ntfs, xfs, etc. - -o <options>: specifies mount options, such as read-write permissions, permission control, etc. - -r: mounts the device in read-only mode, prohibiting write operations. - -o remount: remounts an already-mounted device, allowing the mount options to be changed.

For example, if you want to mount the /dev/sdb1 device to the /mnt directory, you can use the following command:

```bash
mount /dev/sdb1 /mnt
```

 
The mount command can show the filesystem information currently mounted in the system; using the mount command displays the correspondence between current mount points and devices.

# Related Components in the cgroup Filesystem

- cgroups: just folders, containing some of the current cgroup's configuration files (in file form) and folders of child cgroups
- subsystem: related to the system, responsible for managing different operating system functions; furthermore, the processes corresponding to those functions; and further still, the resources used by the managed processes. Corresponds to the resource limits (specified in file form) of the processes of each cgroup in cgroups
- hierarchy: a tree-like organizational directory structure composed of cgroups

# Docker Using cgroups
Running docker run on an image starts a container, and a cgroup is allocated to the container

> In Ubuntu 22.04, the cgroup of a Docker container is located in the system.slice directory under the /sys/fs/cgroup directory. Each container creates a corresponding directory under the system.slice directory, with a directory name like docker-<container_id>.scope

# Go Code

- /proc/self/exe is a special path that points to the currently running executable file. And os.Args[0] is the program's first command-line argument, i.e., the path of the program itself.
- 


```go
package main

import (
	"os/exec"
	"os"
	"syscall"
	"io/ioutil"
	"fmt"
	"strconv"
	"path"
	"bufio"
)

const process_cgroup_root_path="/sys/fs/cgroup/"

func main(){  
	if os.Args[0]=="/proc/self/exe"{  //检查是否是fork出来的新go程序进程
	cmd:=exec.Command("/proc/self/exe")
	fmt.Println("args[0]",os.Args[0])
	fmt.Println("/proc/self/exe",cmd)
	fmt.Println()
	cmd=exec.Command("sh","-c","stress --vm-bytes 200m --vm-keep -m 1")
	cmd.SysProcAttr = &syscall.SysProcAttr{}
	cmd.Stdin = os.Stdin 
	cmd.Stdout = os.Stdout 
	cmd.Stderr = os.Stderr 
	bufio.NewReader(os.Stdin).ReadString('\n') //等待回车再继续往下进行，防止cgroup还没有修改完就开始执行stress了
	if err:=cmd.Run(); err!= nil{ 
	 fmt.Println(err)
	  os.Exit(1)
	}
	fmt.Println("finish")
	}

	cmd:= exec.Command ("/proc/self/exe") 	
	cmd.SysProcAttr = &syscall.SysProcAttr{ 
		Cloneflags: syscall.CLONE_NEWIPC|syscall.CLONE_NEWPID|syscall.CLONE_NEWUTS|syscall.CLONE_NEWNS|syscall.CLONE_NEWUSER|syscall.CLONE_NEWUSER|syscall.CLONE_NEWNET,}
	cmd.Stdin = os.Stdin
	cmd.Stdout = os.Stdout 
	cmd.Stderr = os.Stderr
	if err:= cmd.Start( ); err !=nil { 
		fmt.Println ("error", err) 
		os.Exit(1) 
	} else { 
		
		pid:=cmd.Process.Pid  
		fmt.Println("fork process pid ",pid)
		os.Mkdir(path.Join(process_cgroup_root_path,"cgroup-test"),0755)
		fmt.Println("success mkdir")
		ioutil.WriteFile(path.Join(process_cgroup_root_path, "cgroup-test","cgroup.procs"),[]byte(strconv.Itoa(cmd.Process.Pid)), 0755)
		ioutil.WriteFile(path.Join(process_cgroup_root_path,"cgroup-test","memory.max"),[]byte(strconv.Itoa(100 * 1024 * 1024)), 0755)  //注意往memory.max写只能写数字
		fmt.Println("change finished ")
		cmd.Process.Wait()  //等待start()结束，防止go程序结束
		}
}

```
