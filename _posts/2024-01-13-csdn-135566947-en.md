# Characteristics of operating systems - concurrency
Parallelism: doing multiple events at the same time
Concurrency: only one event at any given moment, but events are switched, so macroscopically multiple events may get done
![在这里插入图片描述](/images/csdn/2024/csdn-135566947/image-002-a968145e00.png)
When a quad-core CPU executes five programs, concurrency still exists: 4 programs run in parallel and 2 programs run concurrently

# The relationship between concurrency and sharing
Suppose there were no concurrency: then only one program would run at each moment, so there would be no need for simultaneous resource sharing. And once there is no simultaneous resource sharing, concurrently running programs would need to access resources alternately at each moment; since only one program can use a resource within that time period, there is no point in running programs concurrently.

# Characteristics of operating systems - asynchrony
Due to the concurrency characteristic, two consecutive microscopic time periods may correspond to different processes that need the same resource (for example, the data of some register belongs to the previous process, so the second process cannot directly use that register at this point) — blocking occurs in this case
