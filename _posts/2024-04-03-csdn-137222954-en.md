#  Markov Model
The current state is only related to the previous state
Then a matrix stores the transition probability information between the states, and there is also initial state probability information
For example
![在这里插入图片描述](/images/csdn/2024/csdn-137222954/image-001-8064e952ba.png)
Then the probability that today is sunny = the probability that yesterday (the initial state) was sunny times the probability of sunny-to-sunny + the probability that yesterday (the initial state) was cloudy times the probability of cloudy-to-sunny + the probability that yesterday (the initial state) was rainy times the probability of rainy-to-sunny


#  Hidden Markov Model
Elements: observable states, hidden states, initial states

Relationship: for hidden states, the current hidden state is only related to the previous hidden state; the observable state is only related to the current hidden state

# Practical Elements of the Hidden Markov Model
![在这里插入图片描述](/images/csdn/2024/csdn-137222954/image-003-65945be28b.png)
-  Given the model, with unknown observation sequence and hidden sequence, find the probability of a certain observation sequence

# Given the Model, Find the Probability of a Certain Observation Sequence
##  Brute Force
That is, compute all possibilities

That is, first find the probability of each hidden sequence, and then find the probability of that certain observation sequence corresponding to each hidden sequence
At this point, if there are N hidden states, the number of possible hidden sequences is T times N to the power of T (T is the number of possible initial states)

## Forward Algorithm
Using dynamic programming

State transition equation: **the probability of the observation state corresponding to a certain current hidden state = the probability of the fixed observation state of each previous hidden state times the transition probability from each previous hidden state to the current hidden state, then times the probability of the current hidden state emitting the current observation state**

At this point, if there are N hidden states and T observation sequences, the time complexity of obtaining the observation state corresponding to the hidden state at the current moment is N squared (the previous moment has N hidden states fixed to a certain observation state, and the current moment has N hidden states fixed to a certain observation state); T iterations are needed in total, so it is T times N squared

# Unknown Model, Given an Observable Sequence, Find the Model that Maximizes the Probability of the Observable Sequence
## With Observable Sequence and State Sequence
**Directly compute the probabilities from the frequencies** to obtain the model parameters

##  With Observable Sequence but Without State Sequence

[Baum-Welch algorithm explanation](https://www.bilibili.com/video/BV1YY411X7yM/?spm_id_from=333.999.0.0&vd_source=a1be939c65919194c77b8a6a36c14a6e)
##  Baum-Welch Algorithm
1. In short, first initialize a set of model parameters
2. Then find the probability expression of the observable sequence (determined by the initialized model parameters and the model parameters of the next iteration)
3. Then use Lagrange (multipliers) to find the model parameters corresponding to its maximum
4. Then use them again as the initialized model parameters for iteration
![在这里插入图片描述](/images/csdn/2024/csdn-137222954/image-005-da64ee5927.png)


After multiple iterations, when the model parameters no longer change much, they can be considered the model parameters
# Given the Model and Observable Sequence, Find the Most Likely Hidden Sequence

## Viterbi Algorithm
Similar to dynamic programming, and somewhat recursive

That is, the maximum probability of a certain hidden state corresponding to the current fixed observation state = the maximum (the probabilities of reaching each hidden state corresponding to the previous fixed observation state multiplied by the probability of that hidden state transitioning to the current hidden state) multiplied by the probability of the current hidden state emitting the current observable state

# Using the HMM Toolkit

```python
import numpy as np
from hmmlearn import hmm

states = ["box 1", "box 2", "box3"]
n_states = len(states)

observations = ["red", "white"]
n_observations = len(observations)

start_probability = np.array([0.2, 0.4, 0.4])

transition_probability = np.array([
  [0.5, 0.2, 0.3],
  [0.3, 0.5, 0.2],
  [0.2, 0.3, 0.5]
])

emission_probability = np.array([
  [0.5, 0.5],
  [0.4, 0.6],
  [0.7, 0.3]
])

model = hmm.MultinomialHMM(n_components=n_states)
model.startprob_=start_probability
model.transmat_=transition_probability
model.emissionprob_=emission_probability

seen = np.array([[0,1,0]]).T
logprob, box = model.decode(seen, algorithm="viterbi") # 维特比算法求摸的盒子数
print("The ball picked:", ", ".join(map(lambda x: observations[x], seen)))  
print("The hidden box", ", ".join(map(lambda x: states[x], box)))

box2 = model.predict(seen)
print("The ball picked:", ", ".join(map(lambda x: observations[x], seen)))
print("The hidden box", ", ".join(map(lambda x: states[x], box2)))  # 求某个观测序列的概率

print (model.score(seen))


model2 = hmm.MultinomialHMM(n_components=n_states, n_iter=20, tol=0.01)
X2 = np.array([[0,1,0,1],[0,0,0,1],[1,0,1,1]])  # 求模型参数
model2.fit(X2)
print (model2.startprob_)
print (model2.transmat_)
print (model2.emissionprob_)
print (model2.score(X2))


```
