# KMeans Clustering

![Image](/images/csdn/2024/csdn-144678864/image-001-d3deac1c17.png)
## Image Segmentation
Pixels are divided into different clusters (pixels with highly similar feature values form a cluster).

![Image](/images/csdn/2024/csdn-144678864/image-002-beba2fd9dc.png)
## Social Network Analysis and Recommendation Systems
It is still based on features; different objects also have different forms of feature representation.
![Image](/images/csdn/2024/csdn-144678864/image-003-cc2cd436cd.png)
## The Detailed Process
Data points are divided into K different groups; if you don't know the value of K, you can try values one by one — the one with the best effect is a suitable K. 

![Image](/images/csdn/2024/csdn-144678864/image-004-759cd127c1.png)
# Effect and Purpose
After clustering is complete, you can determine which group new data belongs to simply by checking which cluster center it is closest to.
![Image](/images/csdn/2024/csdn-144678864/image-005-4bbd147c5c.png)
