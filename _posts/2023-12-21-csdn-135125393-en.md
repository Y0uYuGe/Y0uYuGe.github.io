###   Imbalance Caused by Insertion into the Left Subtree of A's Left Child

![在这里插入图片描述](/images/csdn/2023/csdn-135125393/image-007-3f1e3e7124.png)
The reason all subtrees have height h: if the height were h+1 or h-1, then after the insertion either the minimum unbalanced subtree would not be A, or there would be no minimum unbalanced subtree after the insertion, or a minimum unbalanced subtree would already have existed before the insertion. In short, none of these satisfy the assumed situation

## Search Efficiency Analysis
From the balanced binary tree we know that a balanced binary tree of height h with the fewest nodes consists of one root node and two subtrees, where one subtree is a minimum-node balanced binary tree of height h-1 (this satisfies the requirement that the tree has depth h) and the other subtree only needs to be a minimum-node balanced binary tree of height h-2. If it were also a minimum-node balanced binary tree of height h-1, that would be unnecessary, since it would have more nodes than a minimum-node balanced binary tree of height h-2, so h-2 suffices

## Summary
The subtree becomes shorter after rotation, causing upper-level ancestors to become unbalanced
Note that the time complexity of deletion in a balanced binary tree is the same as that of insertion
