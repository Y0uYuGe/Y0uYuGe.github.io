# Operating System
System calls are the interface from applications to the operating system
The instruction set architecture (ISA) is in turn the interface from the operating system to the hardware

The role of the operating system
 - To prevent applications with errors from directly accessing hardware and causing hardware problems
 - To provide applications with simple and consistent abstract interfaces to access complex and varied peripheral hardware

It feels like a middleman preventing some bad effects caused by applications directly accessing hardware
