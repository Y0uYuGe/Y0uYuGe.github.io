## Finding an Edge
With an adjacency matrix, just check whether a certain element in the graph is 1
With an adjacency list, traverse the edge list of the vertex
![在这里插入图片描述](/images/csdn/2023/csdn-134936769/image-002-53822e91f1.png)
![在这里插入图片描述](/images/csdn/2023/csdn-134936769/image-003-d00a8047fe.png)
## Listing the Edges Connected to a Vertex
With an adjacency matrix, look at the row or column
With an adjacency list, look at the edge list corresponding to the vertex
For incoming edges in an adjacency list of a directed graph, you need to traverse the edge lists of all other vertices
![在这里插入图片描述](/images/csdn/2023/csdn-134936769/image-004-e8237a3de6.png)
![在这里插入图片描述](/images/csdn/2023/csdn-134936769/image-005-ded3d22eaf.png)
## Inserting a Vertex
Here the inserted vertex has no connections to any other vertices
![在这里插入图片描述](/images/csdn/2023/csdn-134936769/image-006-c289c4fa46.png)
## Deleting a Vertex
For an adjacency matrix, set one of the vertex's variables to a boolean used to mark whether the vertex is valid; when deleting the node, you only need to set its row and column to 0
For an adjacency list, traverse all edge lists, delete all edges that have the vertex, and modify the corresponding edge lists

# Breadth-First Traversal of Graphs

## Overview
![在这里插入图片描述](/images/csdn/2023/csdn-134936769/image-015-dc2bb0c5dd.png)
## Breadth-First Traversal of Trees
That is, find the children of the root node first
![在这里插入图片描述](/images/csdn/2023/csdn-134936769/image-016-0446c86a1d.png)
## Breadth-First Traversal of Graphs
That is, visit the adjacent nodes of a node first
![在这里插入图片描述](/images/csdn/2023/csdn-134936769/image-017-9aaa9a4d14.png)
## Trees vs Graphs
Graph traversal may visit a previously visited node, but a tree will not, because it always visits child nodes
![在这里插入图片描述](/images/csdn/2023/csdn-134936769/image-018-c96511ee69.png)
