# Fully Connected Layers
## The Role of Convolutional Neural Networks
Convolutional Neural Networks (CNNs) are mostly used for image recognition, but not exclusively. However, when learning about convolutional neural networks, we can treat image recognition as the hypothetical task, which makes them more intuitive to understand.

## The Problem with Fully Connected Layers

 **Why does converting image data from multi-dimensional (the original image format) into a one-dimensional vector (for processing by a fully connected neural network) lose spatial and channel correlation information, as well as potentially hidden pattern information?**

### Scenario
Imagine we are processing a photo containing blue sky and green grass, with a clear boundary between the sky and the grass.

### Image Processing and Data Conversion
1. **Multi-dimensional data (image format)**:
   - In the image, the pixels of the blue sky may have high blue values, e.g., RGB(135, 206, 235).
   - The pixels of the grass may be green, e.g., RGB(34, 139, 34).
   - In the image format, these pixels are adjacent to each other, forming visible boundaries and patterns, such as the boundary between sky and grass.

2. **Conversion to a one-dimensional vector**:
   - When this image is converted into a one-dimensional vector to be fed into a fully connected neural network, all pixels are flattened into a long sequence of numbers. This sequence simply arranges the RGB values of each pixel in order.
   - For example, if the image is 100x100 pixels, the vector will be an array of length 30000 (3 color channels per pixel).

### Examples of Information Loss
1. **Lost spatial correlation**:
   - In the original image, adjacent pixels (such as neighboring blue pixels in the sky or green pixels in the grass) exhibit a high degree of spatial correlation. This correlation helps us understand and interpret the structure of the image (e.g., the sky is usually at the top and the grass at the bottom).
   - After conversion into a one-dimensional vector, these spatial relationships are lost. The values in the vector are simply a continuous sequence of color information, without preserving any of the original physical proximity between pixels.

2. **Ignored shape information and patterns**:
   - The shapes and patterns in the original image, such as the boundary between the sky and the grass, are key visual information that may reveal important features of the image or the boundaries of objects.
   - When this data is converted into a one-dimensional vector, all of this shape information and these patterns are flattened, making it difficult for a fully connected network to re-recognize or learn these important spatial features from such a one-dimensional representation.

To solve the above problems, we introduce convolutional neural networks for feature extraction, which can both capture feature patterns between neighboring pixels and ensure that the number of parameters does not change with the image size. A typical convolutional neural network structure applies multiple layers of convolution and pooling to the input image; a series of fully connected layers is usually added at the end of the network, ReLU activation functions are generally applied to the outputs of the convolutional or fully connected layers, and Dropout is usually added to the network to prevent overfitting.

![在这里插入图片描述](/images/csdn/2025/csdn-144859370/image-003-741f580598.png)
This image depicts the structure of a typical convolutional neural network (CNN) used for an image recognition task, here taking handwritten digit recognition as an example. The entire network is divided into two major parts: feature extraction and classification.

### Feature Extraction Stage
This stage mainly consists of multiple convolutional layers and pooling layers (downsampling layers), whose purpose is to automatically learn useful features from the input image.

1. **Input**: The network receives a 32x32 pixel image (for example, the handwritten digit "3" here).
2. **First convolutional layer (C1)**: A 5x5 convolution kernel is used to convolve the input image, generating multiple feature maps, here producing 28x28 feature maps. The convolutional layer extracts local features of the image by sliding the kernel; each feature map represents the response of the image to a different kernel.
3. **First pooling layer (S1)**: The convolved feature maps are downsampled with a 2x2 pooling window, usually using max pooling or average pooling to reduce the dimensionality of the feature maps (here down to 14x14), reducing the amount of computation while retaining the main information of the features.
4. **Second convolutional layer (C2)**: A 5x5 convolution kernel is applied again to the pooled feature maps to further extract features, outputting feature maps of a smaller size (10x10).
5. **Second pooling layer (S2)**: The output of the second convolutional layer is pooled, further reducing the size of the feature maps (here down to 5x5).

### Classification Stage
The extracted features are flattened into a one-dimensional vector and processed through one or more fully connected layers to perform the final classification.

1. **Fully connected layers**: The feature vector is fed into the fully connected layers, whose neurons learn the complex relationships between features and output a score for each class (here the digits 0-9).
2. **Output layer**: The final output layer usually uses the softmax activation function to convert the scores into probabilities, one probability for each digit.

The entire network is trained with the backpropagation algorithm, optimizing the weights in the convolution kernels and fully connected layers to improve classification accuracy. CNNs are especially well suited to image processing because they can automatically learn useful local features from images without manual feature engineering.

# VALID and SAME
 
![在这里插入图片描述](/images/csdn/2025/csdn-144859370/image-023-9b6cd2ce8b.png)
- In "valid" padding mode, no extra padding is added. This means the convolution kernel only operates within the valid boundaries of the input data and does not go beyond the edges. Therefore, the output size after convolution is usually smaller than the input size.
- As shown in the figure, with a stride of 3 and a kernel size of 5, the last element cannot be convolved because there is not enough room to complete the full convolution operation, which causes part of the input data to be discarded.

![在这里插入图片描述](/images/csdn/2025/csdn-144859370/image-024-046819a184.png)

![在这里插入图片描述](/images/csdn/2025/csdn-144859370/image-025-951b2feebf.png)


In "same" padding mode, padding is added appropriately so that the size of the output feature map equals the size of the input feature map divided by the stride (by definition). This is usually achieved by adding enough zeros evenly on both sides of the input.
In the figure, the convolution kernel has enough room to operate every time it moves, including zero padding added at the beginning and end of the input. This ensures that every input element can be covered by the kernel, but only when the stride is 1 does the same padding mode guarantee that the input and output sizes remain the same.

## The Role of Pooling
![在这里插入图片描述](/images/csdn/2025/csdn-144859370/image-033-0fe1c84d47.png)
Pooling improves the model's robustness to small translational changes in the image, mainly because it reduces the level of detail within each pooled region and retains only the most significant features (such as the maximum or average value). This approach reduces the model's sensitivity to slight positional changes in the input data. Specifically, this robustness is achieved in the following ways:

1. **Local invariance**:
   - When max pooling is used, only the maximum value within the region is retained, while other background information and less significant features are ignored. For example, if a region contains part of an eye and other facial features, no matter exactly where the eye is located within that small region, as long as it is the most prominent feature, it will be selected.
   - This means that if the eye shifts slightly to the left or right, as long as it remains the most significant feature within that small region, max pooling will still select it.

2. **Dimensionality reduction effect**:
   - By reducing the output of a large number of pixels to a smaller representative output, the pooling operation effectively reduces the dimensionality of the data. This dimensionality reduction means that slight variations between neighboring pixels (such as small translations) have a mitigated impact on the overall output, because the entire region is summarized into a single output value.

3. **Statistical feature summary**:
   - In average pooling, since it computes the average of all values within the region, it is less sensitive to small local changes (such as slight translations of the image). The average value reflects the general characteristics of the region rather than specific positional changes, making the output more stable against small variations in the input.
