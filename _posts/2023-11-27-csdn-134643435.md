#  Write Hit
## Write-Back
Data inconsistency refers to the data in Cache being inconsistent with the data in main memory
![Image](/images/csdn/2023/csdn-134643435/image-002-cff1a8fcde.png)
## Write-Through
 ![Image](/images/csdn/2023/csdn-134643435/image-003-3b15327952.png)
 
Write buffer
Using a write buffer, the data written to Cache is also written to the write buffer at the same time; then, while the CPU is doing other things, a control circuit writes it back to the corresponding main memory block one by one
The write buffer has a limited size; too many write operations cause the write buffer to fill up and then waiting is required.
![Image](/images/csdn/2023/csdn-134643435/image-004-ed9f2dcf30.png)
# Write Miss
## Write-Allocate
That is, first load the main memory block into Cache and then follow the write-back method
![Image](/images/csdn/2023/csdn-134643435/image-005-50c0f44fc7.png)
## No-Write-Allocate
That is, a write miss only writes to main memory, and a write hit uses write-through. In this case, only a read miss loads into Cache
![Image](/images/csdn/2023/csdn-134643435/image-006-9c96c53ab6.png)
# Multi-Level Cache
A higher-level Cache holds copies of some blocks of its lower-level Cache
![Image](/images/csdn/2023/csdn-134643435/image-007-8267b73107.png)
# Summary
Essentially, the relationship between levels of Cache is the same as the relationship between main memory and Cache — both aim to improve the CPU's read/write speed
![Image](/images/csdn/2023/csdn-134643435/image-008-7516d2ab8c.png)
