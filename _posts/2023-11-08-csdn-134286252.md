#  SRAM::Static Random Access Memory (Cache)
# Differences between the two

# Row and column addresses
  The first half of the address is fed into the row address decoder
  The second half of the address is fed into the column address decoder
  This reduces the number of connections
![Image](/images/csdn/2023/csdn-134286252/image-003-a5b0161daa.png)

# Refresh

Destructive readout: when read, the signal of a DRAM memory cell becomes 0 and the original signal is destroyed. SRAM does not have this problem
Volatility: DRAM needs refreshing (the refresh period is 2ms, row by row, refreshing one row of memory cells at a time, same as the read/write cycle), because the capacitor leaks charge. SRAM does not, because as long as power is supplied, the data does not change

DRAM refresh is done independently by the memory, without CPU involvement  
![Image](/images/csdn/2023/csdn-134286252/image-004-cdfa3a5201.png)
# DRAM address line multiplexing
SRAM: row and column addresses are sent simultaneously (low integration density)
DRAM: sent in two steps (address lines and address pins are halved)
![Image](/images/csdn/2023/csdn-134286252/image-005-91ac5c6cdc.png)
# Summary
DRAM is obsolete; main memory nowadays mainly uses SDRAM
