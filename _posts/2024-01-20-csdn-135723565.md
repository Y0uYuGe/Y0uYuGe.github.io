# What Is a System Call
The upward interface the operating system provides to users is the GUI, and the program interface is composed of system calls

Similar to functions, but with differences
![Image](/images/csdn/2024/csdn-135723565/image-002-2a4609b302.png)
# The Difference Between System Calls and Library Functions
Some C library functions use system calls

![Image](/images/csdn/2024/csdn-135723565/image-003-52455086ea.png)

# A Small Example: Why System Calls Are Necessary
WPS and Word are two processes at this point

System calls deal with the situation where multiple concurrent processes use the same resource. To avoid accidents caused by such simultaneous use of one resource, the kernel takes over to complete it
![Image](/images/csdn/2024/csdn-135723565/image-004-9ca26dceb5.png)
# Classification of System Calls
Related to shared resources

![Image](/images/csdn/2024/csdn-135723565/image-005-ec85c7a715.png)
# The Process of a System Call
 After putting the parameters into registers (in the CPU), the trap instruction is executed
 
 First the parameter-passing instructions are executed![Image](/images/csdn/2024/csdn-135723565/image-006-641435346d.png)
 After that the trap instruction is executed, and the system switches to kernel mode to execute the system call entry program
![Image](/images/csdn/2024/csdn-135723565/image-007-56d4d924c6.png)
The system call entry program determines which system call service is needed based on the previous parameters
![Image](/images/csdn/2024/csdn-135723565/image-008-f0fe65d71f.png)
 Then the corresponding system call handler runs. After that handler finishes, the system switches back to user mode and executes the instruction following the trap instruction of the previous program
 ![Image](/images/csdn/2024/csdn-135723565/image-009-064c410448.png)
The trap instruction is not a privileged instruction
Trap instruction = trap instruction
![Image](/images/csdn/2024/csdn-135723565/image-010-21a3a5db2a.png)

 
# Summary
 Concurrent processes compete for shared resources, so to ensure the correct operation of each process, the operating system needs to intervene. Therefore, when operations involving shared resources occur, system calls are used, and since system call programs run in kernel mode, the operating system intervenes at this point.
