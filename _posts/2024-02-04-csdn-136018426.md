# Framing Methods
## Character Count Method
An error in the count field of one frame will cause the following frames to be in error as well.
![Image](/images/csdn/2024/csdn-136018426/image-004-0d1aee45b0.png)
## Character Stuffing Method
One byte at the beginning and one at the end serve as the start and end.
ASCII codes have no overlap with the start byte and end byte of the frame.

But if it is not ASCII code, recognition errors may occur.
![Image](/images/csdn/2024/csdn-136018426/image-005-07740fd4b5.png)
The byte stuffing method is a technique to prevent the data from containing the same bit combination as the frame delimiter.
Byte stuffing (stuffing in an escape character tells the receiver to treat whatever follows as data regardless of what it is).

On reception, all received escape characters are deleted.
![Image](/images/csdn/2024/csdn-136018426/image-006-66e3c98b57.png)
## Zero-bit Stuffing Method
At the sending end, the hardware scans the entire frame; when it detects a bit sequence of five consecutive 1s, it automatically inserts a 0 after that sequence. The purpose of this is to prevent the data from containing the same bit combination as the frame delimiter (for example, the HDLC protocol usually uses 01111110 as the frame delimiter), thereby avoiding the receiving end mistakenly identifying frame boundaries.
![Image](/images/csdn/2024/csdn-136018426/image-007-24a7c607e8.png)

# Why the Character Stuffing Method Is Complex and Incompatible
 - Complex implementation mechanism: if the data naturally contains the same sequence as the stuffing character, the character stuffing method needs a mechanism to distinguish whether it is the data itself or a stuffing character, which increases the complexity of implementation.
- Compatibility issues: since the character stuffing method requires specific processing logic, this may cause compatibility problems between different systems or protocols. If one system uses the character stuffing method while another system does not have the corresponding decoding capability, problems will occur in data transmission.
