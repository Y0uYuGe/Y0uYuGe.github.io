# Bus Cycle, Bus Clock Cycle, Bus Operating Frequency, Bus Clock Frequency
A bus cycle is the time required to transfer one set of data over the bus
Request phase: bus arbitration, deciding which device gets to use the bus
Addressing phase: the address is transmitted over the address bus
Transfer phase: the content is transmitted over the data bus
End phase: release the bus usage rights for other devices

The bus clock cycle is the CPU's clock cycle
In some cases a bus transfer occurs on both the rising and falling edges of a clock cycle, in which case one bus clock cycle contains multiple bus cycles
