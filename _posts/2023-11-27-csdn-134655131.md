## Describing Relationships Between Nodes
 - Ancestor nodes: all nodes above a node are its ancestor nodes
 - Descendant nodes: all nodes below a node are its descendant nodes
 - Parent node: the node directly above a node is its parent node
 - Sibling nodes: descendant nodes that share the same parent node
 - Cousin nodes: emmm, a bit hard to describe — nodes on the same level but excluding siblings, such as the node labeled 你 ("you") and nodes G H I J in the figure

![Image](/images/csdn/2023/csdn-134655131/image-005-e8cd89ac2b.png)

The depth (level) of a node can start from zero or from one; the default is one (same for height)
Height is the opposite of depth — you should be able to understand it from the literal meaning

# Related Properties of Trees
Number of nodes in a tree = sum of degrees of all nodes + 1
It can be understood this way:
The sum of degrees of nodes at a certain level equals the number of nodes at the next level, as shown below
When there are four levels, the sum of degrees of levels one through four equals the number of nodes in levels two through four (the degree sum of level four is zero), but the number of tree nodes also includes the root node, while the degree sum of levels one through four does not include the node count of level one, which is 1.
So the number of nodes in a tree = sum of degrees of all nodes + 1

# Related Concepts and Basic Terminology of Binary Trees
A binary tree is ordered and each node has at most two subtrees (which can be empty subtrees)
![Image](/images/csdn/2023/csdn-134655131/image-017-d3530dda26.png)

##   Important (Five States)

![Image](/images/csdn/2023/csdn-134655131/image-018-d3e911283c.png)
## Special Binary Trees
Complete binary tree: nodes correspond one-to-one with nodes of the corresponding full binary tree
A complete binary tree has at most one node of degree 1; if there were two, it would mean there is a gap of one node between the children of these two degree-1 nodes, which would violate the one-to-one correspondence with nodes of the corresponding full binary tree
![Image](/images/csdn/2023/csdn-134655131/image-019-e892ba6f13.png)

**If a node of a complete binary tree has only one child, it must be a left child**

A binary search tree is one where the value stored in the left child is less than the value stored in the parent node, which is less than the value stored in the right child
  ![Image](/images/csdn/2023/csdn-134655131/image-020-1ace356834.png)
 When a binary search tree is a balanced binary tree, the search depth is smaller and efficiency is higher, because fewer comparisons are needed

![Image](/images/csdn/2023/csdn-134655131/image-021-6270e40aaa.png)
