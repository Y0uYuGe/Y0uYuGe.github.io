#  ELF
##  Introduction to ELF
Relocatable file: positions can only be fixed by linking
Core dump file: related information when a program crashes
![Image](/images/csdn/2023/csdn-134773149/image-019-561bd05294.png)
## ELF File Format
Binary
ELF Header: basic information of the ELF file (such as which architecture it runs on, version number)
.text: the program's instructions
.init: instructions for program initialization
4K-byte alignment
Program Header Table: used at runtime; determines which sections are combined into segments and where the segments are placed
Section Header Table: information about the sections, such as locating them
![Image](/images/csdn/2023/csdn-134773149/image-020-59ea11d3b4.png)
## ELF File Processing Tools: Binutils (binary utility)
ar=tar: needed for generating static libraries

![Image](/images/csdn/2023/csdn-134773149/image-021-562067d603.png)
### readlelf -h
View the file header (ELF header)
![Image](/images/csdn/2023/csdn-134773149/image-022-7dfe816896.png)

 -  Magic: the magic number; not very useful, it just gives ELF a special marker to distinguish it from other things

-  Class: file type, 64-bit or 32-bit
###  readelf -S or readelf  -SW (adding W widens the display)
View the Section Header Table
PROGBITS: means executable
RELA: relocatable
![Image](/images/csdn/2023/csdn-134773149/image-023-831aff4c56.png)

### objdump -S
