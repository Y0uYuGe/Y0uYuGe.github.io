Stream ciphers belong to synchronous encryption.

Stream ciphers are less popular than block ciphers in most areas such as Internet security. But there are exceptions, such as the popular stream cipher RC4.

Stream ciphers sometimes require fewer resources to implement than block ciphers, such as code size or chip area, and they are suitable for resource-constrained environments such as mobile phones.

# Toward Practical Stream Ciphers
#### Definition
- **Computationally secure**: a cryptosystem is computationally secure if the best known algorithm for breaking it requires at least t operations. This means that performing t operations is computationally infeasible for today's computers.
- In other words, **computationally secure**: the security of a cryptosystem is based on the fact that current technology cannot complete the required massive number of operations within a reasonable time.
#### Problems
This definition has several problems:

1. **The problem of the best algorithm**:
   - For a given attack, what is the best algorithm? In other words, how do we determine which attack method is the most effective?

2. **The problem of the lower bound on complexity**:
   - Even if we know a lower bound on the complexity of one attack, could there be a more powerful attack? That is, even if we know an attack requires \( t \) operations, could there be other unknown attack methods with lower complexity?

#### Symmetric Encryption Schemes
- For symmetric encryption schemes, we hope there is no attack method with lower complexity than exhaustive key search. This means that in the worst case, an attacker can only break the encryption by trying all possible keys.




Undesirable cryptographic properties caused by the linear nature of most pseudorandom number generators.

# Security of LFSRs
![在这里插入图片描述](/images/csdn/2024/csdn-144665283/image-025-5cfc88aebc.png)

Why 2m output bits are needed to determine an LFSR's feedback coefficients

Example:
Suppose we have a 3rd-order (m=3) LFSR whose characteristic polynomial is:
x³ + p₁x² + p₂x + p₃

Step-by-step analysis:

1) Let the initial state be (s₀,s₁,s₂); we need to solve for the unknown feedback coefficients p₁,p₂,p₃

2) The recurrence relation of the LFSR is:
sₙ₊₃ = p₁sₙ₊₂ + p₂sₙ₊₁ + p₃sₙ

3) Write out the first few equations:
s₃ = p₁s₂ + p₂s₁ + p₃s₀  (Equation 1)
s₄ = p₁s₃ + p₂s₂ + p₃s₁  (Equation 2)
s₅ = p₁s₄ + p₂s₃ + p₃s₂  (Equation 3)

4) Why 2m (=6) output bits are needed:
- We have 3 unknowns (p₁,p₂,p₃) to solve for
- Each equation requires knowing 4 consecutive output bits
- To set up 3 independent equations, we need to know the 6 output bits from s₀ to s₅

5) In matrix form:
[s₂ s₁ s₀] [p₁]   [s₃]
[s₃ s₂ s₁] [p₂] = [s₄]
[s₄ s₃ s₂] [p₃]   [s₅]

6) Only when we know the 6 output bits from s₀ to s₅ (2m=6) can we:
- Construct the complete coefficient matrix
- Ensure the system of equations has a unique solution
- Solve for the values of p₁,p₂,p₃

Summary:
- 2m bits are needed because m independent linear equations must be established
- Each equation requires m+1 consecutive output bits
- In total, m+(m-1)=2m output bits are needed to build the complete system of equations

This explains why 2m output bits are needed to determine the feedback coefficients of an m-th order LFSR.
