# overlayfs
It is a union filesystem that combines multiple files together into a unified view.

overlayfs is generally divided into four directories: lower, upper, merged, and work.

- lower: the read-only layer; data in this layer is never modified
- upper: the read-write layer; all modifications happen in this layer, even modifications to data in lower
- merged: the view layer, where you can see everything from lower and upper
- work: used internally by overlayfs

# `exec.Command("tar", "-xvf", busyboxTarURL, "-C", busyboxURL).CombinedOutput()` 
`exec.Command("tar", "-xvf", busyboxTarURL, "-C", busyboxURL).CombinedOutput()` This line of code starts a new process to execute the `tar` command, and it executes automatically.
`CombinedOutput` Calling this method executes the command and collects the combined output of standard output (stdout) and standard error (stderr). If the command executes successfully, it returns a byte array containing the output; if an error occurs during execution, that error (usually meaning the command failed) is returned.


# `exec.Command`
The `exec.Command` function in Go is used to execute external commands. Its basic format is:

```go
cmd := exec.Command(command, arg1, arg2, ..., argN)
```

Here, `command` is the name of the external command you want to execute (such as `ls`, `curl`, etc.), and `arg1` through `argN` are the arguments passed to that command. Arguments are separated by commas, and each argument is an individual string; even arguments that look like a single unit on the command line (such as file paths containing spaces) need to be passed as a single string.

### Format differences

- **Commands and arguments**: When executing different commands, the main format differences lie in the name of the command itself and the arguments it requires. Each command has different argument requirements and formats according to its function. For example, the `ping` command may need a hostname as an argument, while the `cp` command needs a source file path and a destination file path.

- **Passing options and arguments**: Some commands support long options (like `--help`) and short options (like `-h`); the use of these options and the arguments that follow them (if any) are also part of the `exec.Command` arguments. For example, `exec.Command("grep", "-r", "pattern", "directory")`.

- **Environment variables and working directory**: Besides the command and arguments, `exec.Command` also allows setting environment variables and the working directory through the `Cmd.Env` and `Cmd.Dir` fields. This does not change the basic command format, but it affects the environment in which the command executes.

- **Input/output redirection**: As shown in your earlier code, you can use `Cmd.Stdin`, `Cmd.Stdout`, and `Cmd.Stderr` to redirect the command's standard input, output, and error streams. This does not affect the command's format, but it affects how it interacts.


# Mounting (mount)
- Prepare the busybox directory as the read-only lower layer
- Prepare the read-write upper layer 
- Prepare the merged layer, mounting the read-write layer and the read-only layer onto the merged layer (all the above operations run before the container starts)
-  When the container (child process) runs, pivotRoot switches the directory (before the child process switches to the command line)

```go
package contain
import(
	log "github.com/sirupsen/logrus"
	"os/exec"
	
	"os"
)

func prepare_overlays(rooturl string){
	create_lower(rooturl)
	create_upper(rooturl)
	create_merged(rooturl)
	create_work(rooturl)
	mount_overlays(rooturl)
	log.Infof("prepare_overlays suceess")
}
func create_lower(rooturl string){
	busyboxurl:=rooturl+"/busybox"
	busytarurl:=rooturl+"/busybox.tar"
	_, err := os.Stat(busyboxurl)
    if err != nil {
        if os.IsNotExist(err) {
            log.Infof("文件不存在")
			if err:=os.Mkdir(busyboxurl,0777);err!=nil{
				log.Infof("mkdir error")
			}
			if _,err=exec.Command("tar", "-xvf", busytarurl, "-C", busyboxurl).CombinedOutput(); err!=nil{
				log.Infof("tar busybox.tar error")
			}	
        } else {
			log.Infof("无法获取文件信息: %v\n", err)
        }
    }
	
}
func create_upper(rooturl string){
	upperurl:=rooturl+"/upper"
	if err:=os.Mkdir(upperurl,0777);err!=nil{
		log.Infof("mkedir upper error")
	}
}

func create_merged(rooturl string){
	mergedurl:=rooturl+"/merged"
	if err:=os.Mkdir(mergedurl,0777);err!=nil{
		log.Infof("mkedir merged error")
	}
}
func create_work(rooturl string){
	workurl:=rooturl+"/work"
	if err:=os.Mkdir(workurl,0777);err!=nil{
		log.Infof("mkedir merged error")
	}
}

func mount_overlays(rooturl string){
	mnturl:=rooturl+"/merged"
	dirs:="lowerdir="+rooturl+"/busybox"+",upperdir="+rooturl+"/upper"+",workdir="+rooturl+"/work"
	cmd:=exec.Command("mount","-t","overlay","overlay","-o",dirs,mnturl)
	if err:=cmd.Run();err!=nil{
		log.Infof("mount overlay error")
		log.Error(err)
	}
}
```

# Unmounting (unmount)
- After the container exits (after the child process exits the program environment changes, and the root directory also changes at that point, so you can then unmount and delete the previous root directory), unmount the mount point
- Delete the upper, merged, and work layers; lower stays unchanged

```go
package contain
import(
	log "github.com/sirupsen/logrus"
	"os/exec"
	
	"os"
)
func end_overlays(rooturl string){
	unmount_overlays(rooturl)
	delete_upper_work_merged(rooturl)
}
func unmount_overlays(rooturl string){
	mntrul:=rooturl+"/merged"
	cmd:=exec.Command("umount",mntrul)
	if err:=cmd.Run();err!=nil{
		log.Infof("unmount merged error")
	}
}
func delete_upper_work_merged(rooturl string){
	upperurl:=rooturl+"/upper"
	mergedurl:=rooturl+"/merged"
	workurl:=rooturl+"/work"

	if err:=os.RemoveAll(upperurl);err!=nil{
		log.Infof("delete upper error")
	}
	if err:=os.RemoveAll(mergedurl);err!=nil{
		log.Infof("delete merged error")
	}
	if err:=os.RemoveAll(workurl);err!=nil{
		log.Infof("delete work error")
	}
}
```
