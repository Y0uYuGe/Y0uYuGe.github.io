Using Regular Expressions in Python
As the saying goes, life is short, I use Python. One characteristic of Python is that it has a huge number of libraries. Naturally it has a common library for regular matching, and this library is embedded in the Python standard library, which makes it very convenient to use — you only need to import the re module in your code.


>import re
Python's re module gives Python the ability to use the full functionality of regular expressions. In order to use regular expressions flexibly, our task now is to learn how to use regex in the re library.

 **The Most Basic Regular Expressions**
A regular expression is a tool that matches text by looking for patterns in a simple and intuitive way.
It sounds complicated, but it is actually very simple. Let's start experiencing the simplest regular expressions below. The simplest regular expressions are those containing only simple alphanumeric characters — without any other characters. In this case the regular expression is completely just a normal string.

For example, if we want to match 张明, then the two characters 张明 are the regular expression we need.

**Regular Matching Functions**
Now that we know the most basic regular expressions, how do we use them in Python? First we learn the first function, the search() function. Its purpose is to receive a regular expression and a string, and return the first matching string found.


```python
import re
a = re.search(r'fox','the quick brown fox jumpred')  #第一个参数为正则表达式，第二个参数为要处理的字符串
print(a.span())      # span方法获取的是正则表达式匹配到的位置
b =  re.search(r'www','the quick brown fox jumpred') 
print(b)   #如果匹配不到则会返回None
输出如下：

(16, 19)
None
如何匹配到了，我们输出他在正则表达式中的位置，如果没有匹配到，则输出为空。
```

In the previous task, we learned about regular expressions containing only simple alphanumeric characters, but if that were all, it would greatly underestimate the power of regular expressions. The power of regular expressions lies in the ability to specify text patterns for matching. In this level we will learn about character class matching in regular expressions.

Getting Multiple Matches
In many common scenarios you need multiple matches, such as filtering out the number of all students surnamed Zhang from a student list.

For this kind of need we can use the findall or finditer methods in the re module. The difference between the two methods is that findall returns a list, while finditer returns a generator.

```python
l = re.findall(r'张','张三 张三丰 张无忌 张小凡')
print(l)
['张', '张', '张', '张']
在这个例子中，我们会发现 findall 返回了 4 个“张”，这是因为“张”字在后面的字符串中出现了 4 次。即 findall 返回了所有的匹配信息。
```

Character Classes
Character classes allow matching a set of possible characters. In regular expressions, [] denotes a character class. Let's look at an example.


```python
'I like Python3 and I like python2.7 '
在这句话中，既有大写的 Python,又有全部是小写的 python 。如果我要求都匹配出来，这时候该怎么操作了？这就是正则匹配中字符组的威力了。下面看下示例。

a = re.findall(r'[Pp]ython','I like Python3 and I like python2.7 ')
print(a)
['Python', 'python']
可以发现 [Pp] 既可以匹配大写的 P 也可以匹配小写的 p ，这里值的我们注意的是 [Pp] 仅匹配一个字符，他表示匹配在这个[]内的某一个。
```

Ranges
Some common character classes are very large. For example, if we want to match any digit, following the code above we would have to use [0123456789] every time, which is clearly unwise, and if we wrote code this way to match letters from a-z, it would surely drive us crazy.

To accommodate this, the regular expression engine uses a hyphen (-) inside a character class to represent a range, so we can use [0-9] to match any digit. Similarly, if we want to match all lowercase letters, we can write [a-z], and to match all uppercase letters we can write [A-Z].

We might also have a need: matching the hyphen itself. Because - is understood by the regex engine as denoting a range, we need to escape the - in this case.

Example:

```python

a = re.findall(r'[0-9]','xxx007abc')
b = re.findall(r'[a-z]','abc001ABC')
c = re.findall(r'[A-Za-z0-9]','abc007ABC')
d = re.findall(r'[0-9\-]','0edu 007-edu')
print(a)
print(b)
print(c)
print(d)
执行结果如下：

['0', '0', '7']
['a', 'b', 'c']
['a', 'b', 'c', '0', '0', '7', 'A', 'B', 'C']
['0', '0', '0', '7', '-']
```

Range Negation
So far, the character classes we have defined have all been defined by characters that may appear, but sometimes we may want to define a character class by characters that will not appear, for example: matching a character class that does not contain digits.

```python

a = re.findall(r'[^0-9]','xxx007abc')
b = re.search(r'[^0-9]','xxx007abc')
print(a)
print(b)
执行结果如下：

['x', 'x', 'x', 'a', 'b', 'c']
<re.Match object; span=(0, 1), match='x'>
```


You can perform the negation operation by using the ^ character at the beginning of the character class, which inverts a character class (meaning it will match all characters other than those specified).

Next let's look at another expression: n[^e], which means the character n followed by any character except e.

```python

a = re.findall(r'n[^e]','final')
b = re.search(r'n[^e]','final')
c = re.findall('r[n[^e]]','Python')
print(a)
print(b)
print(c)
执行结果如下：

['na']
<re.Match object; span=(2, 4), match='na'>
[]
```

Here we can see that a and b match na. The character a can be matched because it is not e, while the value of variable c is empty. In this case the regex engine only matched up to the position of the string n, and there is no character after n that can match [^e], so the match fails here as well.
## Note
search finds the first match, while findall finds all matches.
