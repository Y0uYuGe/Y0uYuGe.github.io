# Introduction to IO Control Methods

 Data register: holds the data the host wants to output to a peripheral, or the data a peripheral wants to input to the host
 Control register: stores what action a peripheral should perform
 Status register: the status of the peripheral

 The CPU first issues a read command to the IO interface over the control bus, and can use the address bus at the same time to indicate which device to read from; the address bus can also indicate into which register the data read from that device should be placed
 
## Programmed Polling
 Here the CPU has to keep polling and cannot do anything else
![Image](/images/csdn/2024/csdn-135380584/image-006-1bf3c24680.png)
## Interrupt-Driven IO
Here the CPU goes off to do other things, and once the input is complete it takes the data from the data register at the IO interface based on the interrupt signal
![Image](/images/csdn/2024/csdn-135380584/image-007-28a03507e4.png)
The data flow after IO input for these two IO control methods is
![Image](/images/csdn/2024/csdn-135380584/image-008-3ad317b430.png)
The CPU checks for incoming interrupt requests at the end of each instruction execution cycle
The interrupt service routine here transfers the data from the IO interface's data register into the CPU
After the interrupt is handled, the previously running program resumes execution
![Image](/images/csdn/2024/csdn-135380584/image-009-d25c6af15f.png)
## DMA Control
A DMA interface is also a kind of IO interface, except that the external devices it controls are rather special
 
 The DMA controller reads one word of data from the disk at a time and stores it at the corresponding location in main memory. Only after an entire block of data has been transferred does the DMA controller send an interrupt request to the CPU, indicating that the job you assigned it is complete
![Image](/images/csdn/2024/csdn-135380584/image-010-91b589e384.png)When the device has a word ready for the DMA controller, the DMA controller issues a DMA request. The DMA controller occupies one memory access cycle to write a word of data into memory; if the CPU also wants to access main memory at that moment, it has to wait until the DMA controller finishes accessing main memory

Compared with the interrupt-driven approach, where an interrupt request must be sent and the interrupt handler run for every word transferred, the DMA control method only needs to send a DMA request and spend one memory access cycle — and the DMA interrupt request is sent only after an entire block of data has been transferred
![Image](/images/csdn/2024/csdn-135380584/image-011-666b94a630.png)
## Channel Control
Here the various IO devices are managed by a channel
![Image](/images/csdn/2024/csdn-135380584/image-012-5813a71431.png)
For example, if the IO device's task is to read in data through the IO device, then through channel control the data input by the IO device is ultimately transferred to some location in memory![Image](/images/csdn/2024/csdn-135380584/image-013-49a589f709.png)
# Basic Components of the IO System
How the host controls IO devices through the IO interface is the IO control method
The CPU must execute IO instructions to produce the corresponding IO operations, such as a channel starting work by executing channel instructions
The device driver is what lets the CPU know what the device's IO instructions are
