# Overview
- Framing refers to the data link layer adding its own frame header and frame trailer to the packets from the upper network layer (such as IP datagrams) to form a complete frame. This process includes the encapsulation of data so that it can be transmitted over the physical medium. The purpose of framing is to enable the receiving end to accurately identify the beginning and end of a frame, extract the control information, and ultimately recover the original data. The frame header and frame trailer contain information such as the source and destination MAC addresses, the Ethernet type field, and the cyclic redundancy check (CRC).

- Transparent transmission means that during data transmission, the data link layer does not make any changes to or perform any processing on the content of the service data — that is, the data passes directly through the interconnection function mode without any error-correction processing. Transparent transmission can ensure the integrity and originality of the data; it allows any data delivered by the upper layer to be transmitted without imposing restrictions or modifications on the data itself. The advantage of this transmission method is that it can maintain the original appearance of the data, but it also means that if errors occur during transmission, these errors will not be corrected, which may lead to erroneous reception of the data.

- A bit error at the data link layer usually refers to an error in a bit, while a frame error involves an error of the entire data frame, including loss, duplication, or out-of-order delivery.

# Basic Concepts of the Data Link Layer
A physical channel transmits through a transmission medium, and can be wireless or wired.

A data link, on the basis of transmitting through a transmission medium, also specifies some rules.

# Function Overview of the Data Link Layer
The most basic service is to make the physical layer transmit more accurately, so that the content arriving at the network layer has no errors.

Unacknowledged connectionless service: usually used for real-time communication or channels with a relatively low bit error rate.
Acknowledged connectionless service: no connection is established, but after receiving, an acknowledgment must be sent back, otherwise the data is retransmitted.
Acknowledged connection-oriented service: a connection is established, and after receiving, an acknowledgment must be sent back, otherwise the data is retransmitted.
