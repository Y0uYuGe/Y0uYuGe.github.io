# Error-correcting Code - Hamming Code
Parity check code: it can only detect errors; it cannot find the error location or correct the error.

![Image](/images/csdn/2024/csdn-136033237/image-001-763f862f4a.png)
# Hamming Distance
If a code distance of 1 is found, then it must be 1, because it is the minimum.
The code distance of a code set is searched starting from 1, increasing incrementally.

To detect d bits of error, a code distance of d+1 is required.
To correct d bits of error, a code distance of 2d+1 is required.

For the ability to detect d bits of error, the code distance must be at least d+1. This is because if the code distance is d+1, then any d-bit error will cause the codeword to change from one legal codeword into an illegal codeword, and will not coincide with any other legal codeword. In this way, the receiver can detect errors by checking whether the codeword is a legal codeword. If the code distance is less than d+1, then there may exist two legal codewords whose Hamming distance is less than or equal to d, which means a d-bit error may change one codeword into another legal codeword, making the error undetectable.

For the ability to correct d bits of error, the code distance must be at least 2d+1. This is because to correct an error, the receiver not only needs to be able to detect the error, but also needs to be able to determine the specific location where the error occurred. If the code distance is 2d+1, then even if d bits of error occur, the minimum Hamming distance between the erroneous codeword and all legal codewords is at least d+1, which means the receiver can determine the most likely original codeword by comparing the Hamming distances between the received codeword and all legal codewords. If the code distance is less than 2d+1, then there may exist multiple legal codewords with the same Hamming distance to the erroneous codeword, making it impossible to accurately determine the original codeword.

## 4. Error Detection and Correction
### Correction Method 1
![Image](/images/csdn/2024/csdn-136033237/image-006-e198fc476d.png)
The three large circles correspond to check codes No. 1, 2, and 4 respectively, and the overlapping parts are their respective sums. The correct part — check code No. 2 covers positions 2, 3, 6, 7, which are fine; the common part of the erroneous check codes No. 1 and No. 4, namely positions 5 and 7, must be the problem, and since 7 is fine (check code No. 2 covers 2, 3, 6, 7, which are fine), position 5 is the problem.
![Image](/images/csdn/2024/csdn-136033237/image-007-abd20e686e.png)
### Correction Method 2
XOR the pairs to obtain the binary encoding of the error position, and then convert this binary encoding to a decimal number to get the error position.
