# GNU assembler
The GNU assembler translates assembly code into machine code
Assembly instructions are mnemonics for CPU machine instructions; after assembly they become machine code consisting of 1s and 0s that can be read and executed by the CPU.
> Assembly source programs are used for the most basic system initialization, such as initializing the stack pointer, setting up page tables, and operating the ARM coprocessor; after initialization is complete, execution can jump to C code.
# File formats
File suffix lowercase s: Assembler code
File suffix uppercase S: Assembler code that must be preprocessed
# Assembly syntax
.long: defines four bytes of data

.section: defines a section

The CLI assembly instruction, short for Clear Interupt, disables interrupts; after CLI takes effect, all external interrupts are masked, ensuring the currently running code is not interrupted and protecting code execution

The hlt instruction stops program execution; the processor enters a halt state, performs no operations, and does not affect flags. The CPU leaves the halt state and executes the instruction after HLT when one of three things happens: a reset signal on the RESET line, the CPU responds to a non-maskable interrupt, or the CPU responds to a maskable interrupt.
  If cli was executed before the hlt instruction, maskable interrupts cannot wake up the CPU
# Related commands

```bash
i686-elf-gcc -E *.S文件 ：停止在预处理阶段后，不会运行编译器，结果是预处理后的源码，会发送到标准输出（显示在命令行上）

i686-elf-gcc -c *.S文件 ：可以生成目标文件 即*.0文件，因为此时函数还没有链接，所以没问题

-o指定生成文件名

xxd 目标文件即*.o文件：显示目标文件十六进制形式，按地址顺序显示字节内容
```
# Source code
## boot.S

```c
#include "multiboot.h"

.section .multiboot
    .long MB_MAGIC 
    .long MB_ALIGNED_4K_MEM_MAP
    .long CHECKSUM(MB_ALIGNED_4K_MEM_MAP)

.section .bss  /*栈的起始地址是十六字节对齐*/
    .align 16
    stack_bottom:
        .skip 16318,0
    stack_top:

.section .text
    start_:
        movl $stack_top,%esp /*栈顶赋值*/
        call _kernel_init

        push %ebx /*bool*/
        call _kernel_main

        cli  /*禁止所有中断*/
    j_:
        hlt   /*停止状态*/
        jmp j_ /*死循环，直到断电*/
```

## multiboot.h
```c
#define MB_MAGIC 0X1BADB002
#define MB_ALIGNED_4K_MEM_MAP 0X03  //即flag前两位为1
#define CHECKSUM(flags)  -(MB_MAGIC+flags) 
```
