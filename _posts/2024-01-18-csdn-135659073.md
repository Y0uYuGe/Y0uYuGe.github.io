# Overview
The green-boxed parts are the key exam points
![Image](/images/csdn/2024/csdn-135659073/image-001-f2bd0c1675.png)
# Manual Operation Stage
A hole represents 1, no hole represents 0

The program is written onto paper tape, then the machine reads and executes the content on the tape, then writes the content back onto the tape, and then the programmer retrieves the tape
The user monopolizes the entire machine: two people cannot use it at the same time; they must take turns one by one
![Image](/images/csdn/2024/csdn-135659073/image-002-4c91cd94c1.png)
# Batch Processing System - Single-Program Batch Processing System
First, the peripheral machine processes each paper tape and stores it onto magnetic tape
![Review](/images/csdn/2024/csdn-135659073/image-003-b2a3ef35e2.png)
The supervisory program controls the computer to automatically read in the tape content and then output it to the tape

At this point it is still serial (one program is read into memory at a time)
![Image](/images/csdn/2024/csdn-135659073/image-004-bb399bae3d.png)
# Batch Processing System - Multi-Program Batch Processing System
At this point it is no longer serial; the three processes of reading in, running, and outputting each program can overlap.
![Image](/images/csdn/2024/csdn-135659073/image-005-a04447bc86.png)
# Time-Sharing Operating System
Pay attention to the keyword "taking turns"
Terminals: keyboard, mouse, etc.
![Image](/images/csdn/2024/csdn-135659073/image-006-3462615d16.png)

# Real-Time Operating System
It can prioritize processing, and processing signals also has the characteristic of completing events within a time limit

Hard real-time: there must be a feedback result within every specified time interval. For example, in missile control, position signals must be fed back in real time in order to adjust accurately
