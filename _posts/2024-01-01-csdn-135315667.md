#   B+ Tree
Number of keys in a B-tree node + 1 = number of subtrees of that B-tree node
In a B+ tree node, the number of keys equals the number of subtrees of the node
The leaf nodes contain all the keys and are all linked to each other
![Image](/images/csdn/2024/csdn-135315667/image-001-c971a8b623.png)
# Leaf Nodes
The root node can also be a leaf node
![Image](/images/csdn/2024/csdn-135315667/image-002-e6ab7a1153.png)
# B+ Tree Search
## The First Search Method
First compare the keys in the root node. If a key is greater than the key being searched for, go to the subtree corresponding to that key, then continue comparing in sequence. 9 matches, so go to the subtree corresponding to 9
![Image](/images/csdn/2024/csdn-135315667/image-003-3add6f386b.png)
Search in the subtree corresponding to 9 and find the matching key
![Image](/images/csdn/2024/csdn-135315667/image-004-4d84790cf2.png)
Searching for 7: it is less than 15, so go to the subtree corresponding to 15; search again, find it is less than 9, and go to the subtree corresponding to 9
![Image](/images/csdn/2024/csdn-135315667/image-005-ac7758009b.png)
Search within the subtree corresponding to 9 and find a key smaller than 8. Since this comparison happens at a leaf node and only a smaller key is found without an equal one, the search is considered to have failed
![Image](/images/csdn/2024/csdn-135315667/image-006-95f99641a1.png)
## The Second Search Method
Sequential search: use the pointers linking the leaf nodes to compare the keys of the leaf nodes one by one
First compare against the keys in the leftmost leaf node — not found — then move into the keys of the second leaf node
![Image](/images/csdn/2024/csdn-135315667/image-007-abe84af541.png)
After comparison, 9 is equal — a match
![Image](/images/csdn/2024/csdn-135315667/image-008-3951b29883.png)
