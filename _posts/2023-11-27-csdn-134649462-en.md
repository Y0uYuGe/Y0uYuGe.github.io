# Virtual Storage System
Load part of the program from secondary storage into memory; the other parts of the program are loaded into memory later when needed
![在这里插入图片描述](/images/csdn/2023/csdn-134649462/image-001-93753591e4.png)
# Paged Virtual Memory
Divide the program in secondary storage into pages, and load the currently needed pages of the program into main memory.
 External storage block number: external storage is divided into blocks, each with a corresponding block number
 Valid bit: whether this page of the program in secondary storage has been loaded into main memory
 Access bit: the number of times this page in main memory has been accessed; those accessed fewer times are replaced
 Dirty bit: whether this page in main memory has been modified; if modified, then when this page is replaced, the modified content must be written back to secondary storage

 The virtual page number is the page number of the logical address

# Segmented Virtual Memory
That is, the program in secondary storage is split into segments by different functions
![在这里插入图片描述](/images/csdn/2023/csdn-134649462/image-005-f34a454a09.png)
With segmented virtual memory, main memory is no longer divided into blocks; each unit is one byte. It's just the normal... way. In other words, it can be placed anywhere in main memory, unlike the earlier paged memory which required placing in page-sized units 
![在这里插入图片描述](/images/csdn/2023/csdn-134649462/image-006-c5416e9e69.png)
#  Segment-Paged Virtual Memory
That is, after segmentation, each segment is further paged, and pages are loaded into main memory in units of pages.
At this point, each program corresponds to one segment table.
