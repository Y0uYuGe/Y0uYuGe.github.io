# Multiboot
> A20 line:
The CPU used in IBM's original microcomputer was the Intel 8088, which had only 20 address lines and could access only 1M of address space. The CPU addresses memory in a segment+offset manner, meaning the highest addressable address is 0xFFFF:0xFFFF, i.e. 0x10FFEF (0xFFFF0+0xFFFF). Addresses beyond 0x100000 (1MB) wrap around to 0x0FFEF by default — this is the so-called address wraparound. Some programs at the time relied on this address wraparound mechanism, but soon after, IBM introduced the AT machine, which used the Intel 80286 CPU with 24 address lines, able to address up to 16MB, and had the same real mode as the 8088, so address wraparound could not occur beyond 1MB. To achieve full compatibility, IBM developed a switch to enable or disable the 0x100000 address bit; this signal switch is A20. If it is 0, bit 20 and higher address bits are cleared, achieving compatibility. When we switch from real mode to protected mode, we need to be able to access and use physical memory above 1MB, so the A20 line must be enabled. Therefore, the A20 address line exists to solve the address wraparound problem for backward compatibility.

GRUB: loads the kernel into memory, enables the A20 line, and enters protected mode.

The reason for the multiboot header:
An OS image is in an executable file format, but there are a staggering number of executable formats. To load an OS image, the bootloader would have to understand all executable file formats, so an OS image always contains a multiboot header

magic: must be 0x1BADB002
flags: bit 0 — whether the kernel should be aligned on page (4KB) boundaries
           bit 1 — whether the kernel needs a memory map
           bit 2 — the kernel display mode
checksum: must be -(magic+flags）

# After Multiboot loads the kernel
  %EAX=0x2BADBOO2 indicates the kernel has been loaded
  %EBX=physical address of the bootloader information table
  %CS %DS %ES %FS %GS %SS =0x0 — segment registers are all 0
  A20: enabled
  %CR0=（%CR0&0x7FFFFFFF）|0x1  :equivalent to clearing the highest bit and setting the lowest bit. PE=1 PG=0
  %EFLAGS=%EFLAGS&0xFFFEFEFF IF=0 VM=0

>   CR0 is a control register in the system; bit 0 is the protection enable bit PE (Protedted Enable), used to start protected mode. If PE is set to 1, protected mode is enabled; if PE=0, the CPU runs in real mode. PG controls whether paging is enabled; 0 means not enabled

> EFLAGS register (flags register)
> IF (interrupt enable flag): IF=0 means interrupts are disabled; VM (virtual-8086 mode)
