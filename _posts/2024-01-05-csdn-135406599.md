### Character Display
The ASCII codes of characters are written into video memory
Under the control of the cathode ray tube controller, the ASCII codes in video memory are sent one by one as electrical signals to the character generator
Then the character generator finds the storage unit of the corresponding glyph pattern based on the ASCII code and the CRT controller signal information, and outputs the glyph pattern
Finally, the glyph pattern is displayed via the cathode ray

For LCD and LED displays, only the way pixels are displayed differs (unlike CRT, which uses electron beams)
![Image](/images/csdn/2024/csdn-135406599/image-009-9eceba0234.png)
