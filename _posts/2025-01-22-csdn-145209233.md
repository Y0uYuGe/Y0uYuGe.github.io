# Reinforcement Learning (RL)
Reinforcement learning is a machine learning paradigm in which an agent learns how to take optimal actions in different states through continuous interaction with the environment, in order to maximize the cumulative reward. The core idea of reinforcement learning is based on a trial-and-error mechanism, constantly adjusting the policy to improve behavioral performance.
## Basic Components

1. **Agent**:
   - The decision-making subject.
   - Responsible for choosing actions based on the current state and continuously optimizing its policy through learning, with the goal of maximizing cumulative reward.

2. **Environment**:
   - The space in which the agent interacts.
   - The agent's actions change the state of the environment, and the environment provides reward feedback.

3. **State (\(s\))**:
   - Describes the features of the environment at a given moment.
   - The agent perceives the environment through the state and chooses an action.

4. **Action (\(a\))**:
   - A behavior the agent can choose.
   - Different actions lead to changes in the environment's state and different rewards.

5. **Reward (\(r\))**:
   - The environment's immediate feedback on an action taken by the agent.
   - A positive reward indicates a good behavior (encouragement), while a negative value indicates a bad behavior (punishment).

6. **Policy (\(\pi\))**:
   - The rule or function that determines how the agent chooses actions.
   - It can be a probability distribution (policy network) or a direct mapping (Q-table).

7. **Value Function**:
   - Used to evaluate the long-term value of a state or state-action pair.
   - Usually measured by estimating future cumulative rewards.

## Characteristics

1. **Trial-and-error learning**:
   - Reinforcement learning adjusts behavior by repeatedly trying different actions and obtaining feedback from the environment.

2. **Delayed reward**:
   - The effect of an action may take some time to become apparent, so the agent needs to learn to balance short-term and long-term rewards.

3. **Goal-oriented**:
   - The goal of reinforcement learning is to maximize long-term cumulative reward, not just focus on immediate reward.

4. **Interactive learning**:
   - The learning process of reinforcement learning is continuous interaction between the agent and the environment.

---

## Basic Algorithms

Reinforcement learning algorithms can be divided into the following categories:

#### 1. **Value-based methods**
- Guide decision-making by learning the **state value function (Value Function)** or the **state-action value function (Q value)**.
- **Representative algorithms**:
  - Q-Learning: gradually learns the optimal policy using an update formula based on discrete states and actions.
  - SARSA: updates the Q value based on the agent's current action and the environment's feedback.

#### 2. **Policy-based methods**
- Directly optimize the policy so that it can directly output the probability distribution over actions.
- **Representative algorithms**:
  - Policy Gradient: directly optimizes the parameters of the policy function.
  - REINFORCE: a Monte Carlo-based policy gradient method.

#### 3. **Actor-Critic methods**
- Learn both the value function and the policy, combining the advantages of value-based and policy-based methods.
- **Representative algorithms**:
  - A3C (Asynchronous Advantage Actor-Critic)
  - PPO (Proximal Policy Optimization)


# Q-Learning
Q-learning is an algorithm within reinforcement learning; what Q-learning aims to learn is exactly what reinforcement learning aims to do

![Image](/images/csdn/2025/csdn-145209233/image-002-87a5bae8c6.png)
Example: navigating a maze

You need to find treasure in a mysterious maze. The maze has multiple rooms, each containing a chest that may hold treasure or may be a trap. Your goal is to find the treasure and avoid the traps in order to get as much reward as possible.

![Image](/images/csdn/2025/csdn-145209233/image-003-02fb0f0af5.png)
In Q-learning, you record the state of each room, the reward of each action, and your expected value for each action; this expected value is called the Q value. You choose an action based on the current state and the Q values, interact with the environment, and obtain the next state and the corresponding reward.

![Image](/images/csdn/2025/csdn-145209233/image-004-5edf0a7502.png)

After each interaction, you update the Q value of the action taken in the previous state using a formula called the Bellman equation. This formula takes into account the reward received after taking that action, the Q value of the current state, and the Q value of the previous state to update the Q value of the current state. By constantly trial-and-error in the maze and continuously updating the Q values, your decision-making policy gradually becomes more and more optimal.

As you keep exploring the maze, you gradually learn which actions are optimal, how to avoid traps, and move toward the best path to the treasure. Eventually, you may become a true maze master, able to find the treasure in the shortest time while avoiding traps.

Q-learning is a powerful and flexible algorithm that can be applied to many complex problems, such as autonomous driving, robot control, and game AI.
#  Q-Table
The Q-table is a data structure in Q-learning used to store the Q values between different states and actions

Example: navigating a maze

Suppose you are an adventurer exploring a maze. The maze has multiple rooms, each with a different state, such as your position, the surrounding environment, and so on. You can take different actions, such as going left, going right, staying put, etc.
![Image](/images/csdn/2025/csdn-145209233/image-005-29ab2053ba.png)
The Q-table is like a two-dimensional table, where each row represents a state and each column represents an action. Each cell in the table stores the Q value of taking that action in that state, representing the expected value of this action in the current state. The Q value is a number representing the cumulative reward that may be obtained after taking an action
![Image](/images/csdn/2025/csdn-145209233/image-006-c6a2af633d.png)
Before starting the exploration, the Q values in the Q-table are usually initialized to some initial values, such as 0. As the exploration proceeds, you continuously update the Q values in the Q-table based on actual interaction experience.

 ![Image](/images/csdn/2025/csdn-145209233/image-007-241b2b7094.png)
When you need to choose an action in the maze, you can look up the row corresponding to the current state and choose the action corresponding to the column with the highest Q value as your decision.
        
#  Bellman Equation
First understand the overall update formula. The essence of Q-Learning is to predict the Q value more accurately, and can't we view the task of predicting the Q value as a regression task? The most commonly used loss function for regression tasks is MSE

 
![Image](/images/csdn/2025/csdn-145209233/image-008-f8c4823edf.png)
It can be seen that adjusting the parameter Q value with gradient descent based on MSE gives: new parameter value = original parameter value + hyperparameter * (actual y value - predicted y value)

![Image](/images/csdn/2025/csdn-145209233/image-009-1122a972c5.png)
This formula can be simply explained as: the Q value of taking an action in the current state equals the current immediate reward plus the discounted Q value of the optimal action in the next state. That is, when choosing an action in the current state, consider both the immediate reward and the future reward, and choose the action that maximizes the overall expected value
