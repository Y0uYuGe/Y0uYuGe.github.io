# Purpose of the implementation
When `docker run -d` is used, the container runs in the background instead of entering command-line interactive mode

1. First, the -d option needs to be added
2. Then set it so that when the -d option is added, the main process does not wait for the child process but ends directly

```go
func Contain_run(cmd string,it bool,resource_config *cgroups.Resource,volume string) {
	command,writepipe,rooturl:=new_contain_process(it,volume)
	log.Infof("cmd %s it %t",cmd,it)
	
	if err:=command.Start();err!=nil{
		log.Error(err)
	}
	log.Infof("cmd %s",cmd)
	cmdstring:=strings.Split(cmd, " ")
	log.Infof("split cmd %v",cmdstring)

	llkdockercgroups:=cgroups.Cgroups{
		Cgroups_Name: "llkdockercgroups",
		Resour:resource_config,
		Sub:cgroups.Subsystemins,
	}
	log.Info(llkdockercgroups.Resour)

	cgroups_path:=cgroups.Get_cgroups_path("cgroup",llkdockercgroups.Cgroups_Name)
	log.Info("in run.go get cgroups_path")
	llkdockercgroups.Move(command.Process.Pid,cgroups_path)

	llkdockercgroups.Set(cgroups_path)
	//defer llkdockercgroups.Remove(cgroups_path) //-d后台运行的话不能删除cgroup

	write_to_pipe(cmdstring,writepipe)
	if it{ //-it实现交互，那么当前终端就不能关闭退出，还需留给子进程使用
		command.Wait()
		// 从容器内的命令行中的退出才会wait结束
		end_volume(rooturl,volume)
		end_overlays(rooturl)
	}
	
	log.Infof("exit  !!!")

}
```
3. Finally, note that the main process must not delete the cgroup created by this process, otherwise the following problem will occur. This is the problem caused by deleting the cgroup: the reason is that this cgroup still contains some running processes, and deleting the cgroup before those processes end will fail
![在这里插入图片描述](/images/csdn/2024/csdn-139237660/image-001-43eaa202ed.png)

Solution: delete it at the end in -it mode, but not for background running
```go
if it{ //-it实现交互，那么当前终端就不能关闭退出，还需留给子进程使用
		command.Wait()
		// 从容器内的命令行中的退出才会wait结束
		end_volume(rooturl,volume)
		end_overlays(rooturl)
		llkdockercgroups.Remove(cgroups_path) //-d后台运行的话不能删除cgroup
	}
```
This is docker running in the background

# An inexplicable problem
I found that when debugging, when using `log.Infof` and similar ones, the output was not fully displayed on the terminal in the end, but checking with `ps -ef|grep -e PPID -e top` showed that it was indeed running

For example, the 9550 process below is the top process running in the background
![在这里插入图片描述](/images/csdn/2024/csdn-139237660/image-004-f5597c2ac4.png)
But when displayed on the terminal, it is sometimes incomplete, and sometimes it is displayed in full
![在这里插入图片描述](/images/csdn/2024/csdn-139237660/image-005-e9e3ae3c0e.png)
Here I made the child process share the same standard input, output, and error as the current terminal, otherwise I wouldn't be able to see the related debugging information

```go
func new_contain_process(it bool,volume string)  (*exec.Cmd,*os.File,string){	
	
	readpipe,writepipe,err:=os.Pipe()
	if err!=nil{
		log.Fatal(err)
	}
	command:=exec.Command("/proc/self/exe","init")
	command.SysProcAttr=&syscall.SysProcAttr{
		Cloneflags: syscall.CLONE_NEWUTS | syscall.CLONE_NEWPID | syscall.CLONE_NEWNS |
			syscall.CLONE_NEWNET | syscall.CLONE_NEWIPC,
	}
	 //主进程和子进程共用一个终端
		command.Stdin=os.Stdin
		command.Stdout=os.Stdout
		command.Stderr=os.Stderr
	
	log.Info(command)
	log.Infof("sucess create a contain process")
	command.ExtraFiles=[]*os.File{readpipe}
	mntURL := "./merged"
	rootURL := "./"
	command.Dir = mntURL
	prepare_overlays(rootURL) 
	prepare_volume(rootURL,volume)

	log.Info(readpipe)
	return command,writepipe,rootURL
	
}
```

# The reason why running certain commands results in "file or directory not found"
At that time, the container looked for the related command before mounting, and what it found was the one on the host machine. But what we want is the path of the related command under the root directory after pivot_root, so running this host path later would show that the path cannot be found, because at that point the container's root directory is the relative reference
```go

func Contain_init(){
	
	
	cmd:=readpipe()
	log.Infof("init %s",cmd)
	
	log.Infof("cmd[0] %s",cmd[0]=="/bin/sh")
	log.Infof("cmd len %d",len(cmd))
	log.Infof("cmd %s",cmd[0])
	/*
	path,err:=exec.LookPath(cmd[0])//挂载前得到相关命令的路径会出现找不到

		log.Fatal(err)
	}
	argv:=[]string{}
    for i:=1;i<len(cmd);i++{
		argv=append(argv,cmd[i-1])
	}*/

	log.Infof("prepare for mount ")

	mount()
	path,err:=exec.LookPath(cmd[0]) //挂载后再得到相关命令的路径等
	if err!=nil{

}
```
