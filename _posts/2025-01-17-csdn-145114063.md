#   Statistical Language Models
   ![Image](/images/csdn/2025/csdn-145114063/image-003-9248575f98.png)
   The drawback of the n-gram model is that when a word sequence has never appeared in the training set, the model assigns it zero probability. This problem is usually solved with "smoothing" techniques. Smoothing avoids the zero-probability problem by assigning a small non-zero probability to low-frequency word sequences.

![Image](/images/csdn/2025/csdn-145114063/image-004-e48a3b2c0a.png)

- The core idea of the maximum entropy principle is: among all probability distributions consistent with the known conditions, choose the one that maximizes the system's uncertainty (entropy). In other words, given some known information, we want to choose a probability distribution that fits that information while preserving as much uncertainty as possible.

  For example, suppose you are predicting whether a word is a verb or a noun. From the training data, you know that certain words are more likely to be verbs and others more likely to be nouns. A maximum entropy model chooses a probability distribution by maximizing entropy, so that given the constraints of the known data, the model does not make overly strong assumptions about any label (verb or noun), but instead picks the most "neutral" distribution until the data provides more information to determine the correct label.

- Determining model parameters: the "parameters" of a maximum entropy model refer to what the model needs to learn, usually some weights or coefficients in the probability distribution. By pursuing the goal of maximizing entropy, the model learns how to set these parameters so that, subject to fitting the training data, it produces the probability distribution with the maximum entropy.

- A simple example:
Suppose you are doing text classification, and the goal is to decide whether a word is a verb or a noun. Assume we have the following information:
"吃" (eat) is usually a verb
"苹果" (apple) is usually a noun
When you train with a maximum entropy model, the model's goal is to learn how to maximize entropy based on the known training data — that is, to keep each word's label (verb or noun) as uncertain as possible until the data provides enough information to determine the correct label. For example, if context information is given (such as "我吃苹果" — "I eat an apple"), the model gradually adjusts its parameters, reducing uncertainty and thereby making the correct prediction.

The hidden layer weights are the E matrix, and the number of vector dimensions equals the number of neurons in the hidden layer. The final output layer has as many units as the one-hot encoding, representing the probability of each word


Specifically, there are two ways to train the neural network:
CBOW: predict what the current word is based on its context 
Skip-gram: predict the context based on the current word
 ![Image](/images/csdn/2025/csdn-145114063/image-018-a4980890f1.png)
For both training methods, the training data is obtained by sliding a window of size 5

The core idea of CBOW is to predict the center word from the context words. In the figure, the center word is the target word in the sentence, and the context words are the words surrounding the target word. Skip-gram is exactly the opposite of CBOW: it predicts the context words from the target word.

# Recurrent Neural Networks
![Image](/images/csdn/2025/csdn-145114063/image-022-5bd37e1cde.png)
Why do we need RNNs?

DNNs can only process inputs one by one in isolation; the previous input and the next input are completely unrelated. However, some tasks require better handling of sequential information, where the earlier inputs and the later inputs are related.

For example, when we understand the meaning of a sentence, understanding each word in isolation is not enough — we need to process the entire sequence of connected words. When we process video, we also cannot just analyze each frame individually; we must analyze the entire sequence of connected frames.

Take the three-word sentence "我 吃 苹果" (I eat an apple) as an example. The reason we understand "苹果" (apple) here as a fruit is that it is preceded by "吃" (eat), because most likely people don't eat Apple phones.

![Image](/images/csdn/2025/csdn-145114063/image-023-3d36e3ecf9.png)
U: the weight matrix from the input to the hidden layer.
V: the weight matrix from the hidden layer to the output layer.
W: the weight matrix from the hidden layer to the hidden layer, representing the state transition between different time steps.

If unfolded along the time axis, it becomes the diagram on the right. Note that U, V, and W are shared across all time steps. t, t-1, and t+1 are the inputs at different time steps, and the hidden layer output from the previous time step is passed through the W matrix to the hidden layer at the next time step.


The W matrix is the parameter matrix from the hidden layer at the previous time step to the hidden layer at the next time step. It is fully connected, meaning the hidden layer nodes at time t-1 are fully connected to the hidden layer nodes at time t. The parameter matrix is naturally an n*n matrix
![Image](/images/csdn/2025/csdn-145114063/image-024-503cb83407.png)
![Image](/images/csdn/2025/csdn-145114063/image-025-7dd28c8043.png)
Specifically, as shown below, each hidden node receives two kinds of inputs and two parameter matrices
The formula for the hidden state: h_t = tanh(U * X_t + W * h_(t-1))
- U and W are the RNN's weight matrices, corresponding to the weighting matrices for the input and the hidden state respectively.
- X_t is the input at the current time step.
- h_(t-1) is the hidden state at the previous time step.
- The activation function tanh is applied to this weighted sum to obtain the new hidden state h_t.

# Long Short-Term Memory
![Image](/images/csdn/2025/csdn-145114063/image-029-00401f885a.png)
 Recurrent neural networks suffer from short-term memory. If a sequence is long enough, they have difficulty carrying information from earlier time steps to later ones. So if you try to process a piece of text to make predictions, a basic RNN may miss important information from the very beginning.

During backpropagation, recurrent neural networks suffer from the vanishing gradient problem. Gradients are values used to update the neural network's weights. The vanishing gradient problem is when gradients shrink as they propagate backward over time. If a gradient value becomes extremely small, it doesn't contribute much to learning.

So in a recurrent neural network, layers that receive small gradient updates stop learning. These are usually the earlier layers. Because these layers don't learn, the RNN can forget what it saw in longer sequences, thus having only short-term memory.

## many to many
![Image](/images/csdn/2025/csdn-145114063/image-043-a7fe342f2d.png)

- Input sequence:

The input is a variable-length sequence, for example:
Each frame of a video.
Each word in a sentence.
- Output sequence:

The output is a sequence corresponding to the input length, producing one result at each step, for example:
Labels for video frames (action or object recognition).
Tagging each word in a sentence (named entity recognition).
- Synchronization:

Each output label corresponds one-to-one with each input element (such as a video frame or a word).

#  Attention Mechanism

In the field of artificial intelligence, the attention mechanism is also widely used. It helps computer models focus on features relevant to the current task while ignoring features irrelevant to the task, thereby improving the model's accuracy.

By assigning different weights, the model can learn from and process data in a more targeted way, thereby improving the model's accuracy.

The attention mechanism assigns weights to the model through a series of mathematical computations, enabling the model to pay more attention to information relevant to the current task. The larger these weights, the greater the contribution of that position to solving the problem, and vice versa.


Take machine translation as an example



![Image](/images/csdn/2025/csdn-145114063/image-051-1821997749.png)

The attention output (context vector) mainly contains information from the encoder hidden states that were assigned higher attention weights.
