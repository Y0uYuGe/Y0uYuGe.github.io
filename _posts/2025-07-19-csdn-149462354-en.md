#  What I feel is wrong
I've always felt that whatever I learn should be recorded in the blog, so it's convenient to review or look up later.
But CSDN doesn't seem suitable for global search — meaning I actually have to first know which article my fuzzy memory corresponds to, and then search within that article. It's such a hassle. Another problem is that when blog content is too long, it becomes very tedious, and when you need to present something, the blog format can't clearly show the flow, nor can it help you recall quickly.



#  Improvement
Using XMind — mind map format — which also allows taking notes and can be used for presentations, saving the time of making PPTs. But there's still a pain point: a node can only have one image inserted.

Mainly, it can also be converted to Markdown. From now on I might just convert it to Markdown and post it to the blog directly. Please forgive any inaccuracies.

At least, XMind supports global search and is more concise, so I can have a clear grasp of my own progress and what I'm doing. And because it's more condensed, recalling things is easier too.
