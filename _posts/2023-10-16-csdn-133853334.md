# 100% Fix for the VSCode Terminal Garbled Text Problem
## Method 1: Modify the Registry Editor
**After installing Code Runner and choosing to run in terminal, I found garbled text in the terminal. I first tried the registry editor modification method found online and found that cmd was fixed successfully, but the terminal encoding was still GBK. You can try it yourself—maybe it's just a problem with my computer**


![Image](/images/csdn/2023/csdn-133853334/image-001-d0c67f4c1c.png)
![Image](/images/csdn/2023/csdn-133853334/image-002-9f0b2f449f.png)
## Method 2: Modify terminal.integrated.profiles.windows

***Open the VSCode settings and search for terminal.integrated.profiles.windows***
![Image](/images/csdn/2023/csdn-133853334/image-003-0cd3676fee.png)
***Click "Edit in settings.json", then find terminal.integrated.profiles.windows and start editing. Generally you need to modify the args part***

```typescript
    "terminal.integrated.profiles.windows": {
        

        "PowerShell": {
            "source": "PowerShell",
            "icon": "terminal-powershell",
            "args": ["-NoExit","chcp 65001"]
        },
        "Command Prompt": {
            "path": [
                "${env:windir}\\Sysnative\\cmd.exe",
                "${env:windir}\\System32\\cmd.exe"
            ],
            "args": ["/K","chcp 65001"],
            "icon": "terminal-cmd"
        }
        }
    }
```
***Then the VSCode terminal will no longer have garbled text***
***If you want PowerShell or cmd to automatically use UTF-8 encoding when opened, you can do this***
