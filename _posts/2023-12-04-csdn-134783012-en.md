# Code Implementation of Union-Find - Union and Find
Union: first find the roots of the two sets, then assign the index value of one root's parent to the content of the other root's parent
Find: just traverse upward through the node's parents

![在这里插入图片描述](/images/csdn/2023/csdn-134783012/image-012-0d25373ab0.png)
# Time Complexity Analysis
The time complexity mainly comes from the union operation and is related to the height of the tree representing the set
The lower the tree height, the lower the time complexity
![在这里插入图片描述](/images/csdn/2023/csdn-134783012/image-013-33973030b1.png)
# Optimizing the Union Operation
Merge the shorter tree under the root of the taller tree as a child (merge the small tree into the big tree)
So that the overall tree height does not increase compared to the original taller tree
The content of the root node is the negative of the number of nodes in the current tree
Use the sign of a node's content to determine whether it is a root node
Then, the root node with smaller content corresponds to the taller tree
![在这里插入图片描述](/images/csdn/2023/csdn-134783012/image-014-7dbd812af7.png)
Put simply, this method makes every level of the merged tree full
So the height of a tree with n nodes can be calculated using the same method as for a full binary tree
Since the height is reduced, the time complexity of the Find operation can ultimately be reduced
![在这里插入图片描述](/images/csdn/2023/csdn-134783012/image-015-31e06cee5b.png)

# The Ultimate Optimization of Union-Find (Path Compression)
The Find operation has two loops
First loop: find the root node
Second loop: traverse to find the root node again, updating the content of every node visited to the root node found in the first loop
With this, the second Find can directly locate the corresponding root node

When merging n independent elements, Union first has to find the root node corresponding to each independent element (whose time complexity is related to the tree height), and then perform n-1 merges. So the total time complexity is the number of merges times the time complexity of a find
