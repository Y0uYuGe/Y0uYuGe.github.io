# Dual-Port RAM
RAM: used for main memory or cache; data is lost when power is off
![在这里插入图片描述](/images/csdn/2023/csdn-134488927/image-003-8c8125f5c7.png)
# Multi-Bank Parallel Memory
When reading a memory chip, only one unit of data can be accessed within one access cycle; but with different memory chips, you can access a unit of the current memory chip while simultaneously starting to access a unit of the next memory chip

Depending on the address decoding method, it is possible to have addresses on the same memory chip that are not adjacent
For low-order interleaving, consecutively fetching n memory words takes: nr+T-r
![在这里插入图片描述](/images/csdn/2023/csdn-134488927/image-004-88359c56b4.png)
# How Many Memory Banks Are Appropriate for Low-Address Interleaving (Bank Number)
 The access of low-address interleaving can be understood as a pipeline: macroscopically it appears to be done simultaneously, i.e., parallel, but microscopically it is actually done in order, i.e., serial

Macroscopically, an m-bank interleaved memory can fetch m memory words within one access cycle

To balance efficiency and cost, the value m=T/r is chosen as the number of memory banks
![在这里插入图片描述](/images/csdn/2023/csdn-134488927/image-005-68ef235f08.png)
Given an address x, determine which memory bank it belongs to

 - It can be determined by the bank number
 - It can be determined by taking modulo m
# Multi-Module Memory (Multi-Bank Memory)
Single-bank multi-word memory: can read m words at a time, and the number of memory cells readable per access is fixed
![在这里插入图片描述](/images/csdn/2023/csdn-134488927/image-006-5395341cea.png) 
# Summary
High-order interleaving: equivalent to expanding capacity (more memory cells)

# Real-World Scenario
Orange and green in the same card slot represent high-order interleaving
Orange in different card slots represents low-order interleaving

The same clock frequency means the same access cycle; the same capacity makes both multi-bank storage
If the frequencies differ, the CPU downclocks to the lower frequency; if the capacities differ, part of the region becomes single-bank storage
