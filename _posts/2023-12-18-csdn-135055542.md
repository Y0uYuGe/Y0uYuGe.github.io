## Implementation of Sequential Search
When i equals the total length of the table, it means every element has been checked without finding the target, so -1 is returned; otherwise the target was found and the corresponding index i is returned
![Image](/images/csdn/2023/csdn-135055542/image-012-29c35f7a20.png)
## Implementation of Sequential Search (with Sentinel)
When the search reaches element 0 it always matches; the returned i happens to be 0, which also indicates that the target was not found

# Binary Search
## Overview
![Image](/images/csdn/2023/csdn-135055542/image-019-5febada9b7.png)
## The Idea Behind Binary Search (Half-Interval Search)

### Successful Search
Compare the value of the array element at mid; the value to be found is greater than this value

![Image](/images/csdn/2023/csdn-135055542/image-020-1bd473895b.png)
Move low to mid+1, update mid, and compare again — this time the value to be found is smaller than the value at mid
![Image](/images/csdn/2023/csdn-135055542/image-021-bc8145ebae.png)

Move high to mid-1, compute mid; if mid is a fraction, round down, and compare again — this time the search target is greater than the value at mid
![Image](/images/csdn/2023/csdn-135055542/image-022-6f14e5acc8.png)
Move low to mid+1, compute mid, and compare again — this time they are equal

![Image](/images/csdn/2023/csdn-135055542/image-023-9bfa5a6493.png)
### Failed Search
Compute mid, compare — found to be smaller

![Image](/images/csdn/2023/csdn-135055542/image-024-67af0dabf7.png)
Move high to mid-1, compute mid, and compare again — found to be smaller
![Image](/images/csdn/2023/csdn-135055542/image-025-965188700c.png)
Move high to mid-1, compute mid again, and compare — found to be greater
![Image](/images/csdn/2023/csdn-135055542/image-026-0fb82283c9.png)
Move low to mid+1, compute mid, compare — this time it is greater
![Image](/images/csdn/2023/csdn-135055542/image-027-ad680aa781.png)
Move low to mid+1; low<high, search failed

![Image](/images/csdn/2023/csdn-135055542/image-028-bccfde03eb.png)

# Block Search
## Overview
![Image](/images/csdn/2023/csdn-135055542/image-039-caee1a19a8.png)
## The Idea Behind Block Search

![Image](/images/csdn/2023/csdn-135055542/image-040-080cb1663f.png)
Compare the search target with the values in the index table; if it is smaller, the target may lie in the block corresponding to that index entry, so go into that block and compare one by one
![Image](/images/csdn/2023/csdn-135055542/image-041-89f95ff41a.png)
When the range of that block is exceeded, the search fails
![](/images/csdn/2023/csdn-135055542/image-042-ae7154d218.png)

![Image](/images/csdn/2023/csdn-135055542/image-043-ea1fefdfad.png)
## Using Binary Search on the Index
The index table is ordered, so binary search can be used to find the corresponding index entry
![Image](/images/csdn/2023/csdn-135055542/image-044-fdfc3f952e.png)
Here the value at mid is greater than the search target, so high moves to mid-1
![Image](/images/csdn/2023/csdn-135055542/image-045-9ff1d50852.png)
Compute mid; now mid is smaller than the search target, so low moves to mid+1
![Image](/images/csdn/2023/csdn-135055542/image-046-6032fb118a.png)
Compute mid again; it is greater than the search target, so high moves to mid-1
![Image](/images/csdn/2023/csdn-135055542/image-047-5b2e9c0fa6.png)
Now high is smaller than low
(When low becomes greater than high, either high=mid-1 or low=mid+1, but at that point low always corresponds to the position just greater than the searched element)


Regarding why everything to the right of high must be greater than the search target and everything to the left of low must be smaller than the search target: this is determined by the earlier conversion mechanism between mid and low/high, because everything to the left of low is less than or equal to the original mid, and the original mid is smaller than the search target. The same applies to high

![Image](/images/csdn/2023/csdn-135055542/image-048-7a2f9bdb6d.png)
The search fails when low goes beyond the index

![Image](/images/csdn/2023/csdn-135055542/image-049-7025faf014.png)
