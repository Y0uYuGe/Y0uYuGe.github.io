## Insertion into a Binary Search Tree
First search to find the insertion position, then malloc a new space; if an element equal to the inserted value is encountered, the insertion fails
The function parameter is a reference type so that its value can be modified
![Image](/images/csdn/2023/csdn-135065725/image-005-e1f0075e93.png)
## Constructing a Binary Search Tree
Initially T is empty; a node is created whose value equals the inserted value, and this starts forming a tree; the subsequent insertion process is the same as before
![Image](/images/csdn/2023/csdn-135065725/image-006-b10acba2b6.png)
The binary search trees corresponding to different sequences are not necessarily the same, nor necessarily different
![Image](/images/csdn/2023/csdn-135065725/image-007-99e27e61b7.png)
## Deletion from a Binary Search Tree
### Deleting a Leaf Node
Deleting it directly still preserves the properties of the binary tree
![Image](/images/csdn/2023/csdn-135065725/image-008-d288ff607b.png)
### Deleting a Node with Only a Left Subtree or Only a Right Subtree
Simply replace it; the properties still hold, because after the replacement the subtree relative to its grandparent tree necessarily satisfies the same property that the parent tree had relative to its own grandparent tree
![Image](/images/csdn/2023/csdn-135065725/image-009-9a4ac7e66d.png)
![Image](/images/csdn/2023/csdn-135065725/image-010-9437f95d57.png)
### Deleting a Node with Both a Left and a Right Subtree
Here we can find the minimum node of the right subtree to replace it (the leftmost-bottom node of the right subtree)
![Image](/images/csdn/2023/csdn-135065725/image-011-6884715b61.png)
![Image](/images/csdn/2023/csdn-135065725/image-012-6d96373769.png)
Alternatively, we can find the maximum node of the left subtree to replace it (the rightmost-bottom node of the left subtree)
![Image](/images/csdn/2023/csdn-135065725/image-013-24aeb929e8.png)

## Search Efficiency Analysis
### Successful Search
The worst-case search length is also the same as the height of this tree
![Image](/images/csdn/2023/csdn-135065725/image-015-1bb25b7c0f.png)
If the binary tree is kept as balanced as possible, its height will be lower
![Image](/images/csdn/2023/csdn-135065725/image-016-89cab7ab7f.png)
### Failed Search
A failed search lands at the position of an empty node; fill in the empty nodes first
![Image](/images/csdn/2023/csdn-135065725/image-017-d5daaeee84.png)
