## CPU Internal Single-Bus Approach
![Image](/images/csdn/2023/csdn-135039843/image-008-0bd1f27550.png)

The temporary register can temporarily store data read from main memory or from certain registers

The register above the ALU stores the result of the ALU's computation; once the result is stable (or rather, once B's signal is stable), the connection between the result and the CPU internal bus is enabled, and the result is finally transferred to the designated register through the CPU internal bus

The green 'in' signal also determines, based on certain inputs, whether data can be written into the register

# Basic Structure of the Controller
CPU internal bus
The address code information in the instruction needs to be output onto the CPU internal bus
 The instruction decoder selects a certain output line, and the micro-operation signal generator produces the micro-operation sequence according to that signal
Each time the micro-operation signal generator receives a signal from the timing system, it issues the signal for that micro-operation and executes one micro-operation

MAR: the memory address of some content in main memory
CPU internal bus: the common pathway over which components inside the CPU transfer data
Address bus and data bus: the common pathways for data transfer between the CPU and other components
![Image](/images/csdn/2023/csdn-135039843/image-010-8a74d3f673.png)
# Basic Structure of the CPU
Programmable: the value of the register can be changed through assembly language
PC: jump instructions
PSW: produces flag bits, which jump instructions also need to read
ACC: some operations change the value of ACC
R0 R1 R2 R3: can be modified through assembly

Red means visible, gray means invisible
