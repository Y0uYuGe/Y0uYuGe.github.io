# Protected Mode
## x86
  The X86 architecture is a computer language instruction set; it refers to the abbreviation of the standard number of Intel's general-purpose computer series and also identifies a general set of computer instructions
  
  x86 is the abbreviation of the standard number of Intel's general-purpose computer series and also identifies a general set of computer instructions. This x has nothing to do with the processor; it is a simple, broad definition for all "something-86" systems, e.g., i386, 586, Pentium. Because early Intel CPUs were numbered like 8086, 80286 (all containing 86), and because this entire series of CPUs is instruction-compatible, X86 is used to identify the instruction set used. Today's Pentium, P2, P4, and Celeron series all support the X86 instruction system, so they all belong to the X86 family.
  
The X86 instruction set was specially developed by Intel of the United States for its first 16-bit CPU (i8086). The CPU in the world's first PC launched by IBM of the United States in 1981—the i8088 (a simplified version of the i8086)—also used X86 instructions, while the X87 series math coprocessor chips added to computers to improve floating-point data processing capability separately used X87 instructions; later, the X86 instruction set and the X87 instruction set were collectively called the X86 instruction set. Although with the continuous development of CPU technology Intel successively developed the newer i80386, i80486 up to today's Pentium 4 (hereinafter referred to as P4) series, in order to ensure that computers can continue to run the various applications developed in the past so as to protect and inherit rich software resources, all CPUs produced by Intel still continue to use the X86 instruction set, so its CPUs still belong to the X86 series.

## Virtual 8086 Mode
Virtual 8086 mode, also called virtual-real mode, allows real-mode programs to be executed under the control of a protected-mode operating system.
## What Is Protected
Protecting the safety of the memory portions occupied by each process
## Memory Map
The CPU controls memory access according to the rules of the memory map
Different regions in memory can be called segments
To make it easier for the CPU to manage memory, each region in memory can be registered in a table (the Global Descriptor Table). Then the CPU can learn some relevant information about the segment through the Global Descriptor Table (GDT)

## Entering Protected Mode - Part 1
Switching from real mode to protected mode
Simply set the PE flag bit in the CR0 register to 1 to enter protected mode
The assembly instructions are:

```c
move eax,cr0
or eax,1
mov cr0,eax
```
## Entering Protected Mode - Part 2
 The above three statements must be immediately followed by a JMP or CALL instruction, otherwise some errors will occur
  Because after the PE flag bit of the cr0 register is changed to 1, the subsequent 16-bit instructions that will be executed in a pipelined manner in 32-bit form will cause errors, so a jump instruction is needed at this point to reset the CPU once
