# Logistic Regression
Logistic regression is not an algorithm for regression tasks; it is a classification algorithm.

![Image](/images/csdn/2024/csdn-144530160/image-001-54c4d0dc37.png)
## The Logistic Regression Expression
An S-shaped curve (the sigmoid function) compresses the value of linear regression into the range 0 to 1, giving it a probabilistic meaning; greater than 0.5 is the positive class, otherwise the negative class.

# Notes
The difference between multi-label and multi-class.
![Image](/images/csdn/2024/csdn-144530160/image-009-e2d04870d6.png)

- Softmax regression suits multi-class models, because mutual exclusivity means the probabilities of all classes must sum to 1.
- Logistic regression suits converting a multi-class problem into multiple binary classifications, because the binary classifiers are mutually independent.
