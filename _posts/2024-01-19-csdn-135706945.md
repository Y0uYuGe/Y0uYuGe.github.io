# Switching Between User Mode and Kernel Mode
If the CPU determines that the instruction type is a privileged instruction while the current mode is user mode, it will issue an interrupt signal, and the hardware automatically completes the mode switch. It then switches to kernel mode and handles the interrupt, and after handling it switches back to user mode and returns to the original program or another program

![Image](/images/csdn/2024/csdn-135706945/image-006-641f3769d4.png)
