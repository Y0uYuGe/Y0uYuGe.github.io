# _setjmp and longjmp
`setjmp` and `longjmp` are C functions used to implement non-local jumps. They allow a program's control flow to cross function call boundaries, jumping from a specified location to a previously recorded one. This differs from the regular function call and return mechanism, which can only transfer control flow within functions.

### Introduction to the _setjmp and longjmp functions

The `setjmp` function is used to set a return point, while the `longjmp` function is used to jump back from anywhere in the program to the return point set by `setjmp`.

#### The _setjmp function
The prototype of the `_setjmp` function (commonly called `setjmp` in C++) is as follows:

```c
int _setjmp(jmp_buf env);
```

`env` is an array of type `jmp_buf` used to save information about the current execution environment, including register values and the program counter. `_setjmp` returns 0 if this is the first call to `_setjmp`; if `longjmp` jumps back to this `env`, then `_setjmp` returns a non-zero value.

#### The longjmp function
The prototype of the `longjmp` function is as follows:

```c
void longjmp(jmp_buf env, int val);
```

The `longjmp` function is used to jump from the current execution position back to the `setjmp` point identified by `env`. `val` is the return value passed to `setjmp`, typically used to indicate the reason for the jump.

### Example

Below is an example using `_setjmp` and `longjmp`:

```c
#include <stdio.h>
#include <setjmp.h>

jmp_buf jmpbuf;

void my_function() {
    printf("Inside my_function\n");

    // 模拟一个错误条件
    if (1) {
        longjmp(jmpbuf, 1); // 发生错误，跳回到setjmp点
    }
}

int main() {
    int ret;

    printf("Before setjmp\n");
    ret = _setjmp(jmpbuf); // 设置返回点

    if (ret == 0) {
        printf("First call to setjmp\n");
        my_function(); // 调用可能抛出longjmp的函数
    } else {
        printf("Caught an error, ret=%d\n", ret);
    }

    printf("After possible longjmp\n");

    return 0;
}
```

In this example, the `main` function first calls `_setjmp` to set a return point. If `my_function` detects an error condition, it calls `longjmp`, which immediately returns control flow to the location of the `_setjmp` call, skipping the remaining code in `my_function`. The `else` branch in the `main` function executes after the `longjmp`, handling the error.


Note that `longjmp` and `setjmp` should be used with caution, as they can corrupt the program's state — for example, skipping resource-release code or causing thread-safety issues. In general, exception-handling mechanisms such as C++'s `try/catch` or higher-level error-handling approaches are preferable alternatives.
## A Concrete Example
When you call the `longjmp()` function in a C program, it immediately transfers program control to the `setjmp()` call point associated with the passed `jmp_buf`. In this case, `longjmp(main_begin_jmp_buf, 1);` causes the program's control flow to jump back to where `_setjmp(main_begin_jmp_buf);` is located.

Specifically, in your code snippet, `longjmp(main_begin_jmp_buf, 1);` makes program execution jump from the `longjmp` call point back to the first instruction after the line `_setjmp(main_begin_jmp_buf);`. That is, if `_setjmp(main_begin_jmp_buf);` is immediately followed by:

```c
if ( _setjmp(main_begin_jmp_buf) )
{
  v3 = time(0LL);
  printf("restart at %ld\n", v3);
}
```

Then after `longjmp(main_begin_jmp_buf, 1);` executes, the program continues executing from the line `if ( _setjmp(main_begin_jmp_buf) )`, but this time `_setjmp()` no longer returns 0 — it returns the value passed by `longjmp()` (1 in this case). Therefore, the `if` statement's condition is true, and the program executes the two lines `v3 = time(0LL);` and `printf("restart at %ld\n", v3);`.

In short, `longjmp(main_begin_jmp_buf, 1);` makes the program jump to the code after `_setjmp(main_begin_jmp_buf);` and continue from there, with `_setjmp()` returning 1, which triggers the code block in the `if` statement.
