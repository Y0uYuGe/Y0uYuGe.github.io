# Operands of RISC-V Assembly Instructions
RV32I: the RISC-V 32-bit integer instruction set
Instruction sets are divided into unprivileged and privileged instruction sets
XLEN: a variable representing the word length of the current machine (32-bit, 64-bit, 128-bit)
x0: cannot be written, only read, and always reads as 0
PC: cannot be accessed directly 
What the ALU can directly interact with are registers

# RISC-V Assembly Instruction Encoding Formats
Instruction alignment: in the figure below, a multiple of 4 bytes. Misalignment may cause the program to raise an exception

funct7: occupies 7 bits
funct3: occupies 3 bits
A register field has 5 bits, corresponding to 32 general-purpose registers
rs: source register
rd: destination register
imm: immediate

# The Concept of Little-Endian
Byte order is a concept that only exists for multiple bytes
Host machines default to little-endian
 ![Image](/images/csdn/2023/csdn-134827649/image-006-0487e3fc18.png)
Big-endian:
 - The high-order bytes of the data are stored at the low addresses
 - The low-order bytes of the data are stored at the high addresses
