## Advantages and Insecurity of the toy protocol


![在这里插入图片描述](/images/csdn/2025/csdn-144934702/image-016-931cd36122.png)

- Single point of failure: attacking the KDC compromises everything.
- Replay attack: intercept the ya and yb values that were encrypted with the session key in the first round; then, when a session key is requested in the next round, intercept the request and send each party the session key intercepted in the previous round, causing them to communicate using an old session key.
- Key confirmation attack: Oscar intercepts the request and tampers with it so that it becomes a request between Alice and Oscar. The KDC then generates a session key and sends the session keys to Alice. Alice decrypts her session key, encrypts the message, and sends it to Bob together with the other encrypted session key. Oscar intercepts it in the middle and decrypts it to obtain the session key and the message. From then on, all communication between Alice and Bob using that session key is intercepted by Oscar, so Alice thinks she is communicating with Bob when she is actually communicating with Oscar.

## Kerberos: Needham-Schroeder Protocol
![在这里插入图片描述](/images/csdn/2025/csdn-144934702/image-018-cf22a7e70b.png)
Both na and nb are random numbers.
![在这里插入图片描述](/images/csdn/2025/csdn-144934702/image-019-1650c4e0c8.png)

If an attacker manages to obtain the KEK, they can decrypt all session keys previously encrypted with that KEK. Session keys are used to protect the actual communication content (such as file transfers and messages). Therefore, the attacker only needs to save past encrypted communication data, and once the KEK is obtained, all of those past communications can be decrypted.
