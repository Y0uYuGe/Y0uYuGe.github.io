# VGA (Video Graphics Array)
> VGA (Video Graphics Array) is a video transmission standard introduced by IBM in 1987 together with the PS/2; it has advantages such as high resolution, fast display speed, and rich colors, and has been widely used in the field of color displays
## VGA text mode
VGA text mode is a simple way to print characters to the screen

> To print characters to the screen in VGA character mode, we must write them into the VGA text buffer provided by the hardware. Typically, the VGA text buffer is a two-dimensional array whose contents are rendered to the screen in real time. The elements of this array are called character cells, which describe a character on the screen using the following format:
![Image](/images/csdn/2023/csdn-134370976/image-001-f63b87617e.png)

![Image](/images/csdn/2023/csdn-134370976/image-002-c546234480.png)

> The smallest unit of the text buffer: one word (two bytes)

> Text buffer start address: 0xB8000 (physical address)

> Buffer size: 2 x height x width, in characters



# The ld linker  
> ld (Linker) is a program responsible for linking object files and library files into an executable or shared library. During compilation, the compiler compiles source code into object files, and then ld links these object files into an executable or shared library.

Or in other words:

> The linking process links various .o files into one file. A linker script describes how the linker maps these input (.o) files into an output file and specifies the memory layout of the output file. Almost all linker scripts do these things.

##  Syntax
= means that whenever the variable is used, variables that use it change as the variable changes.
```bash
HELLO = world
HELLO_WORLD = $(HELLO) world!

# This echoes "world world!"
echo $(HELLO_WORLD)

HELLO = hello

# This echoes "hello world!"
echo $(HELLO_WORLD)
```
:= means the value of a variable that uses it is fixed at definition time based on the corresponding variable's value at that time
```bash
HELLO = world
HELLO_WORLD := $(HELLO) world!

# This echoes "world world!"
echo $(HELLO_WORLD)

HELLO = hello

# Still echoes "world world!"
echo $(HELLO_WORLD)

HELLO_WORLD := $(HELLO) world!

# This echoes "hello world!"
echo $(HELLO_WORLD)
```
?= means: if the variable has already been defined and assigned before, skip this definition/assignment; otherwise perform this assignment

CURDIR is a built-in Makefile variable, automatically set to the current directory

In a Makefile, the include keyword can include other Makefiles, much like C's #include; the included file is placed verbatim at the include location in the current file.

mkinc is a custom name

We call other Makefile files from within a Makefile, forming a Makefile hierarchy.

To pass variables from the upper-level make process's Makefile to the child make process, this must be stated explicitly.

In GNU make, the directive that implements this is export. When a variable is declared with export, the variable and its value are added to the current working environment variables, and all rules executed by make afterwards can use this variable.

 Predefined variable CC: i686-elf-gcc
 Predefined variable LD: ld
 Predefined variable AR: i686-elf-ar
 
In a rule, if there are multiple targets, make runs the rule's commands independently for each target. $@ is an automatic variable whose content is the name of the target in each independent command run.

The semicolon is a separator, and the backslash is a line continuation character. When an if statement block or a for statement must be written on one line, semicolons must be used as separators; if line breaks are needed in between, use the backslash \. Also, note that the left bracket [ after an if statement must have spaces on both sides; the double equal sign "==" denotes equality, while the single equal sign "=" can denote either equality or assignment — the difference is: when comparing, there are spaces on both sides of the comparison sign; when assigning, there are no spaces around the equal sign
