# Flow Control at the Data Link Layer and Its Difference from Transport-layer Flow Control

End-to-end: between two hosts.
Point-to-point: between two nodes.

Window advertisement: tells the other party about the reception situation on one's own side.

Flow control can be compared to a cat owner feeding a cat.

# Flow Control Methods
Stop-and-wait protocol: think of it as both the send window and the receive window having size one.
Sliding window protocol: frame sequence numbers are cyclic; when an acknowledgment frame is received, the sending window moves forward by one slot.
![在这里插入图片描述](/images/csdn/2024/csdn-136063112/image-002-7546aefb0d.png)
## Send Window and Receive Window Sizes Corresponding to Each Method
In data-link-layer flow control, the sizes of the receive window and the send window of the three protocols are all fixed values.
