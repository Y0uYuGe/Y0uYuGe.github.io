# Introducing the various ROMs
Bit density: the number of binary bits stored per unit size
MROM: information is written by the manufacturer, and once written it cannot be changed
PROM: information is written by the individual, and once written it cannot be changed
![在这里插入图片描述](/images/csdn/2023/csdn-134433640/image-002-3c80378ae5.png)
# Important ROM
We know the CPU reads instructions from memory one by one in order and executes them. But right after powering on, the data in memory has been cleared, yet certain instructions such as the operating system must run for the machine to boot normally — and those OS instructions are stored on secondary storage. What to do?
This is where the BIOS chip comes in. Although it is a chip located on the motherboard, logically we classify it as memory, because the CPU executes the instructions on this chip one by one in order, just like reading instructions from memory one by one and executing them — so we classify it as memory.
Memory also uniformly assigns addresses to the BIOS: the BIOS is the initial part of memory, and the remaining memory part starts from the address at the end of the BIOS
