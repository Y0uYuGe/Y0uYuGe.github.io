# Algorithm Implementation
The loop runs n times; each time the i-th element is compared against the previous i-1 elements, and whenever an element is found greater than the i-th element, that element is shifted one position to the right
![在这里插入图片描述](/images/csdn/2024/csdn-135413289/image-012-1ddee1c226.png)
Store starting from index 1, with position 0 as the sentinel holding the current i-th element
