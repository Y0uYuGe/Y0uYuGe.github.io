# Format String
The CPU uses ebp to access things on the stack
Arguments are pushed onto the stack from right to left
printf function arguments are pushed onto the stack from right to left

%[flags][width][.precision][length]specifier

The specifier is used to specify the type of the output data
The flags are used to specify the output style
The minimum width is used to control the width of the displayed field
```c

#include <stdio.h>
#define PAGES 931
int main() {
    printf("*%2d*\n", PAGES);         //输出的字段长度大于最小宽度，不会截断输出
    printf("*%10d*\n", PAGES);        //默认右对齐，左边补空格      
    printf("*%*d*\n", 2, PAGES);      //等价于 printf("*%2d*\n",PAGES)
    return 0;
}
  
//程序运行结果：
*931*
*       931*
*931*
```
Precision (.precision) is used to specify the output precision
For integer specifiers (d, i, o, u, x, X): precision specifies the minimum number of digits to print. If the written value is shorter than this number, the result is padded with leading zeros. If the written value is longer than this number, the result is not truncated. A precision of 0 means nothing is written;
For the e, E, and f specifiers: the number of decimal digits to output after the decimal point;

```c
#include <stdio.h>
int main() {
    const double RENT = 3852.99;  // const-style constant
    printf("*%4.2f*\n", RENT);
    printf("*%3.1f*\n", RENT);
    printf("*%10.3f*\n", RENT);
 
    return 0;
}
  
//程序运行结果：
*3852.99*
*3853.0*
*  3852.990*
```
The length is used to control the data type length of the data to be output



## Viewing Memory Contents
Above the format parameter, the arguments are pushed upward in order
%x outputs in hexadecimal

## Writing to Memory
%n writes the length already printed so far into a memory address

```c
print("%d %n",a,&a)
```

If a=1234, then a becomes 5, because the space also counts

## Customizing the Value Written to Memory
```c

print("%5d%n",a,&a)
或
print("%.5d%n",a,&a)
```

## %n$p
Represents the nth argument of the format string, not counting the format string itself; positions count upward

It is recommended to use %p to get the value

## [some obvious string]%p%p%p%p……
Observe the result of printf(s) to find which argument is s; you can then replace it with the GOT address of some function. Input got-address-value%n$s to print out the real address


##  Overwriting Memory
some address + %Nd + %A$n
Writes the total length (some address or something else + N) into the Ath argument

### Overwriting with a Small Number
Change the order: [something of a certain length] + %A$n

### Overwriting with a Large Number
Little-endian storage: the low address stores the low byte
Overwrite byte by byte
%A$hhn: takes the lowest byte of the total length printed so far and writes it into the Ath argument
# Format String Vulnerabilities Related to malloc and free
malloc(), calloc(), realloc() allocate space in the heap
alloca() allocates space on the stack

When scanf inputs or printf outputs too many characters, malloc is called to handle it, and free is called after it finishes.
So when there is a lot of input or output, you can overwrite _free_hook or _malloc_hook with the address of another function to call that function

## Format String Vulnerability Tool
This is a function specifically for outputting payloads for format string vulnerabilities in 32-bit programs
fmtstr_payload(offset (the offset of the format string among the function arguments), {addr: value1, addr2: value2}) is used to write value into addr (commonly used: {printf_got})



# 64-bit
Arguments are placed in registers; when there are more than six, they are placed on the stack
At this point, the argument number in %np is still counted from the arguments after the format string
