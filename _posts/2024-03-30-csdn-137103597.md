# Definition of Machine Learning
Machine learning is a machine gradually learning the correct results by continuously training on datasets

Machine learning includes supervised learning and unsupervised learning

- Supervised learning: requires input data and result data for continuous training

Supervised learning includes regression and classification
Regression: the result is continuous, not finite
Classification: the result is discrete and finite

Unsupervised learning: only requires input data to learn
For example, clustering (grouping one kind of input data into one group and another kind of data into another group)


# Linear Regression in Supervised Learning

Linear regression: based on the correspondence between a set of input data and output data, obtain a functional relationship (the function is linear) that can still produce reliable output data when the input data is something else

# Cost Function and Visualization
The loss function is the cost function
Here m is the number of data points in the dataset
From the definition of the cost function, we can see that the smaller the value of the cost function, the closer the correspondence between the Model function and the real dataset
![Image](/images/csdn/2024/csdn-137103597/image-002-1a6aa62811.png)
Visualization means representing it in the form of a graph
When the cost function takes different parameter values, the value of the cost function may be different or the same
When the parameters form the plane and the value of the cost function is the vertical axis, we get a 3D visualization
For the corresponding plane, connect the points in the plane with the same cost function value; this forms contour lines

![Image](/images/csdn/2024/csdn-137103597/image-003-e4e32598e5.png)


# Gradient Descent
Purpose: obtain the parameter values that minimize the cost function (not only for linear regression)
Principle: slightly change the parameters each time to try to reduce the value of the cost function, eventually reaching a minimum

It is like running from some position to the lowest point in the cost function visualization


![Image](/images/csdn/2024/csdn-137103597/image-004-6f07be0b16.png)
Taking the derivative of the cost function with respect to a parameter is the partial derivative of the cost function with respect to that parameter

![Image](/images/csdn/2024/csdn-137103597/image-005-f5b727b017.png)
Learning rate: a fixed value

If the learning rate is too large, w changes too much, jumping left and right around the local minimum, or even getting farther and farther from the local minimum
If the learning rate is too small, w changes too little, and it takes many steps to reach the local minimum

The partial derivative changes automatically; the closer to the local minimum, the smaller the corresponding partial derivative. At this point, even if the learning rate stays the same, the change in w becomes smaller

![Image](/images/csdn/2024/csdn-137103597/image-006-af32116abe.png)

def compute_cost(X, y, w, b):
    m = X.shape[0]
    cost = 0.0
    for i in range(m):
        f_wb_i = np.dot(X[i],w) + b           #(n,)(n,)=scalar
        cost = cost + (f_wb_i - y[i])**2
    cost = cost/(2*m)
    return cost

def inbounds(a,b,xlim,ylim): #判断w和b是否出界
    xlow,xhigh = xlim
    ylow,yhigh = ylim
    ax, ay = a
    bx, by = b
    if (ax > xlow and ax < xhigh) and (bx > xlow and bx < xhigh) \
        and (ay > ylow and ay < yhigh) and (by > ylow and by < yhigh):
        return True
    return False

def plt_contour_wgrad(x, y, hist, ax, w_range=[-100, 500, 5], b_range=[-500, 500, 5], # 等值线上迭代的w和b的变化
                contours = [0.1,50,1000,5000,10000,25000,50000],
                      resolution=5, w_final=200, b_final=100,step=10 ):
    b0,w0 = np.meshgrid(np.arange(*b_range),np.arange(*w_range))
    z=np.zeros_like(b0)

    CS = ax.contour(w0, b0, z, contours, linewidths=2,
                   colors=[dlblue, dlorange, dldarkred, dlmagenta, dlpurple]) # 绘制等值线图
    ax.clabel(CS, inline=1, fmt='%1.0f', fontsize=10) # 等高线图上添加标签
    ax.set_xlabel("w");  ax.set_ylabel("b")
    ax.set_title('Contour plot of cost J(w,b), vs b,w with path of gradient descent')
    w = w_final; b=b_final

    ax.vlines(w, ax.get_ylim()[0],b, lw=2, color=dlpurple, ls='dotted')

    base = hist[0]
    for point in hist[0::step]:
        edist = np.sqrt((base[0] - point[0])**2 + (base[1] - point[1])**2) # 计算当前点到到下一个w和b对应的坐标
        if(edist > resolution or point!=hist[-1]):  # 当跳转距离较大的时候或者还没到最后一个点的时候继续跳转
            if inbounds(point,base, ax.get_xlim(),ax.get_ylim()):
                plt.annotate('', xy=point, xytext=base,xycoords='data',
                         arrowprops={'arrowstyle': '->', 'color': 'r', 'lw': 3},
                         va='center', ha='center') # 在当前点绘制一个箭头
            base=point
    return

def compute_gradient(x, y, w, b):   # 计算w和b此时对应的偏导数（梯度）

    # Number of training examples
    m = x.shape[0]    
    dj_dw = 0
    dj_db = 0
    
    for i in range(m):  
        f_wb = w * x[i] + b 
        dj_dw_i = (f_wb - y[i]) * x[i] 
        dj_db_i = f_wb - y[i] 
        dj_db += dj_db_i
        dj_dw += dj_dw_i 
    dj_dw = dj_dw / m 
    dj_db = dj_db / m 
        
    return dj_dw, dj_db


def gradient_descent(x, y, w_in, b_in, alpha, num_iters, cost_function, gradient_function):  # 从起始位置迭代规定次数，最后得到合适的参数

    w = copy.deepcopy(w_in) # avoid modifying global w_in
    # An array to store cost J and w's at each iteration primarily for graphing later
    J_history = []
    p_history = []
    b = b_in
    w = w_in
    
    for i in range(num_iters):
        # Calculate the gradient and update the parameters using gradient_function
        dj_dw, dj_db = gradient_function(x, y, w , b)     

        # Update Parameters using equation (3) above
        b = b - alpha * dj_db                            
        w = w - alpha * dj_dw                            

        # Save cost J at each iteration
        if i<100000:      # prevent resource exhaustion 
            J_history.append( cost_function(x, y, w , b))
            p_history.append([w,b])
        # Print cost every at intervals 10 times or as many iterations if < 10
        if i% math.ceil(num_iters/10) == 0:
            print(f"Iteration {i:4}: Cost {J_history[-1]:0.2e} ",
                  f"dj_dw: {dj_dw: 0.3e}, dj_db: {dj_db: 0.3e}  ",
                  f"w: {w: 0.3e}, b:{b: 0.5e}")
 
    return w, b, J_history, p_history #return w and J,w history for graphing
