The third pass and everything after is similar
Each pass finds the smallest among the elements whose positions are not yet fixed and places it after the elements whose positions are already fixed
Note that in the fourth pass, equal comparisons do not swap, which guarantees stability
![Image](/images/csdn/2024/csdn-135416593/image-020-8597314242.png)
Note that in the fifth pass there is no swap, so the sequence can be considered already ordered
![Image](/images/csdn/2024/csdn-135416593/image-021-bcec979d18.png)
## Algorithm Implementation
The flag marks whether a swap occurred; if no swap occurred, the sequence is already sorted
A total of n iterations of the loop, starting from 0
![Image](/images/csdn/2024/csdn-135416593/image-022-eee34f69fa.png)
## Algorithm Performance Analysis
An already-ordered sequence still needs n comparisons; only when no swap occurs do we learn that it is ordered
In the worst case, the sequence being compared is in reverse order every time
Swapping elements once requires three element moves
![Image](/images/csdn/2024/csdn-135416593/image-023-6fcc49d425.png)
## Stability
Stable — no swap happens on equality
##  Is Bubble Sort Applicable to Linked Lists
