# Common Hash Functions
## Division Remainder Method
Here we find that taking a prime number produces even more synonyms, because the keys are contiguous
![Image](/images/csdn/2024/csdn-135358027/image-011-aad9dbbd55.png)
If the keys are mostly even numbers
![Image](/images/csdn/2024/csdn-135358027/image-012-4727c63d40.png)
## Direct Addressing Method
With direct addressing, since the positions corresponding to keys are also contiguous, if a key is missing, the content at the corresponding position is missing as well. This creates empty slots, wasting storage space

![Image](/images/csdn/2024/csdn-135358027/image-013-48234c8c56.png)
## Digit Analysis Method
The distribution is relatively uniform, meaning each key may correspond to a different position
![Image](/images/csdn/2024/csdn-135358027/image-014-9da7de282d.png)
## Mid-Square Method
Suitable when the values in each digit are unevenly distributed, or when there are fewer digits than the hash address requires
![Image](/images/csdn/2024/csdn-135358027/image-015-009b652e0c.png)
This makes the hash address depend on every digit of the key

![Image](/images/csdn/2024/csdn-135358027/image-016-de3bc9ab9f.png)
![Image](/images/csdn/2024/csdn-135358027/image-017-57718837a0.png)

When we compare against an empty hash table position, the search is considered failed
Note that empty positions also need to be compared here
With chaining, each hash table position actually stores a pointer, which does not count as a key comparison. With open addressing, the stored items are of the same type as the keys, so they count as key comparisons
![Image](/images/csdn/2024/csdn-135358027/image-028-36e422c48b.png)
