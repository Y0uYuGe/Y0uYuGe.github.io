# OSI and TCP/IP
OSI: theory first, but without practice
TCP/IP: practice first, then theory
TCP/IP: layered based on the protocol stack
Network interface layer: the data link layer and the physical layer
Application layer: contains the upper three layers

# Similarities Between OSI and TCP/IP

Heterogeneous network interconnection: enabling devices produced by different manufacturers to communicate with each other

![Image](/images/csdn/2024/csdn-135753176/image-002-e2813b59d7.png)
# Differences Between OSI and TCP/IP
The IP protocol is connectionless
The transport layer is end-to-end and has the function of reliable transmission, i.e. connection-oriented functionality

Transport layer: TCP/IP also having connectionless service takes practical efficiency requirements into account; OSI is a more rigorous standard, so it has no connectionless service
Network layer: TCP/IP having only connectionless and no connection-oriented service also considers practical efficiency requirements, so it has no connection-oriented functionality
