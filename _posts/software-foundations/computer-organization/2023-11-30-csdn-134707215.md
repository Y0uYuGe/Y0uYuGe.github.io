# Classification of Memory (by Access Method)
Magnetic tape: the tape needs to be rotated and read through the corresponding position of the magnetic head
Random access memory: main memory, Cache
Direct access storage: mechanical hard drives — i.e., there are locations with the same access time and locations with different access times

# Performance Metrics of Memory
Storage speed: can be understood as the time required to store one bit of a storage word
Main memory bandwidth (data transfer rate): the maximum amount of information entering or leaving main memory per second; the unit can be words/second, bytes/second, etc.
