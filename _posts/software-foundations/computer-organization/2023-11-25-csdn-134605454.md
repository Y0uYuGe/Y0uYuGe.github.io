#  Mechanical Hard Drive vs Solid State Drive
Solid state drives use flash memory technology and are electrically erasable ROM
The black blocks on the right side of the figure below are individual flash memory chips
![Image](/images/csdn/2023/csdn-134605454/image-002-c63cdadf00.png)
# Structure of an SSD
Block size 16KB~512KB
Page size 512B~4KB
Reads and writes to an SSD are in units of pages
![Image](/images/csdn/2023/csdn-134605454/image-003-d93245f616.png)

![Image](/images/csdn/2023/csdn-134605454/image-004-f2ad13d5c7.png)
Read/write in units of pages
Erase in units of blocks; each page can only be written once, but can be read an unlimited number of times
If a page already has data written to it and you want to modify that page's data, you need to copy the other pages of the block containing that page to another flash chip, then write to the corresponding page of the other flash chip, and then copy the block back to the original block's location. Because each page can only be written once, if you want to write a second time, the entire block must be erased
![Image](/images/csdn/2023/csdn-134605454/image-005-a7dd06f59b.png)
# Characteristics of SSDs Compared to Mechanical Hard Drives
SSDs locate physical addresses through circuits — it's random access, meaning the time to access any address is equal.
Mechanical hard drives locate physical addresses via the magnetic arm; the time to access different addresses differs, because the arm may need to move to different positions, and the time required may also differ
![Image](/images/csdn/2023/csdn-134605454/image-006-a64eec9b7f.png)
# Wear Leveling
To deal with SSDs wearing out from too many erase cycles — i.e., repeatedly writing to a page in the same block causes the entire block to be erased — wear leveling technology is introduced (which ensures that each block is erased roughly the same number of times)
That is, the flash translation layer maps logical addresses to different physical addresses; when a block is found to have been erased too many times, the physical address mapped to by that logical address is changed to one whose block has been erased fewer times, so that blocks with fewer erases get erased
![Image](/images/csdn/2023/csdn-134605454/image-007-38dd1dbabc.png)
