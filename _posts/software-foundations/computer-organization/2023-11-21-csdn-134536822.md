# Bit Expansion (Bit Width of Memory Words)

Simply put, it reads a memory cell from the same position of different chips and transmits them to different data bus lines of the CPU, which is equivalent to expanding the word length of the memory chip
![Image](/images/csdn/2023/csdn-134536822/image-005-07b2b22456.png) 

![Image](/images/csdn/2023/csdn-134536822/image-006-891f0d9faf.png)
# Word Expansion (Number of Memory Words)
That is, if a memory chip has 2 memory words, then two such chips will have 4 memory words; a chip selector is just added for selection
The disadvantage of this method is that some addresses are wasted; those starting with 00 and 11 are both invalid
![Image](/images/csdn/2023/csdn-134536822/image-007-0e7ff9b858.png)
Optimize using a decoder
 This way the addresses are contiguous and nothing is wasted

![Image](/images/csdn/2023/csdn-134536822/image-008-d7326caa4e.png)

In exams, a certain wire may be left unconnected; in that case, whether the signal on that address line is zero or one has no effect

# Supplement: Decoder
![Image](/images/csdn/2023/csdn-134536822/image-014-4ac932e44e.png)

  

When the enable pins are 100 the decoder works; otherwise all outputs are 1
About the timing diagram of a RAM read cycle
First the CPU sends the address signal; since there are high bits and low bits, the address timing diagram has two lines, one above and one below,
Some time after sending the address signal, the CPU sends the memory request signal; at this point the decoder starts working, the corresponding cs becomes 1, and the address is valid
Then after some time the chip select signal becomes invalid and the data in the memory cell is transmitted out via the data bus
After the transmission completes, the CPU's memory request signal becomes invalid
