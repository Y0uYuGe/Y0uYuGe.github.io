# IMU (Inertial Measurement Unit) Message Package
[https://docs.ros.org/en/noetic/api/sensor_msgs/html/msg/](https://docs.ros.org/en/noetic/api/sensor_msgs/html/msg/)
[https://docs.ros.org/en/noetic/api/sensor_msgs/html/msg/Imu.html](https://docs.ros.org/en/noetic/api/sensor_msgs/html/msg/Imu.html)

The sensor_msgs/Imu message is used to represent IMU data, including orientation, angular velocity, and linear acceleration. By subscribing to this message, you can obtain data from the IMU sensor and use it for applications such as robot navigation and pose estimation.

1.  Header
Header: contains timestamp and coordinate frame information.
stamp: the timestamp, indicating when the data was collected.
frame_id: the name of the coordinate frame, indicating the reference frame of the data.
2.  orientation
geometry_msgs/Quaternion: represents the orientation of the object, expressed as a quaternion. [How do quaternions control object rotation?](https://www.bilibili.com/video/BV14t421h7M4/?spm_id_from=333.337.search-card.all.click&vd_source=a1be939c65919194c77b8a6a36c14a6e)
x: the x component of the quaternion.
y: the y component of the quaternion.
z: the z component of the quaternion.
w: the w component of the quaternion.
3.  orientation_covariance
float64[9]: represents the covariance matrix of the orientation measurement; the 9 elements represent a 3x3 covariance matrix in row-major order.
orientation_covariance[0]: covariance in the xx direction.
orientation_covariance[1]: covariance in the xy direction.
orientation_covariance[2]: covariance in the xz direction.
orientation_covariance[3]: covariance in the yx direction.
orientation_covariance[4]: covariance in the yy direction.
orientation_covariance[5]: covariance in the yz direction.
orientation_covariance[6]: covariance in the zx direction.
orientation_covariance[7]: covariance in the zy direction.
orientation_covariance[8]: covariance in the zz direction.
4. angular_velocity
geometry_msgs/Vector3: represents the angular velocity of the object, in rad/s.
x: angular velocity about the x axis.
y: angular velocity about the y axis.
z: angular velocity about the z axis.
5.  angular_velocity_covariance
float64[9]: represents the covariance matrix of the angular velocity measurement; the 9 elements represent a 3x3 covariance matrix in row-major order.
angular_velocity_covariance[0]: covariance in the xx direction.
angular_velocity_covariance[1]: covariance in the xy direction.
angular_velocity_covariance[2]: covariance in the xz direction.
angular_velocity_covariance[3]: covariance in the yx direction.
angular_velocity_covariance[4]: covariance in the yy direction.
angular_velocity_covariance[5]: covariance in the yz direction.
angular_velocity_covariance[6]: covariance in the zx direction.
angular_velocity_covariance[7]: covariance in the zy direction.
angular_velocity_covariance[8]: covariance in the zz direction.
6. linear_acceleration
geometry_msgs/Vector3: represents the linear acceleration of the object, in m/s².
x: acceleration along the x axis.
y: acceleration along the y axis.
z: acceleration along the z axis.
7. linear_acceleration_covariance
float64[9]: represents the covariance matrix of the linear acceleration measurement; the 9 elements represent a 3x3 covariance matrix in row-major order.
linear_acceleration_covariance[0]: covariance in the xx direction.
linear_acceleration_covariance[1]: covariance in the xy direction.
linear_acceleration_covariance[2]: covariance in the xz direction.
linear_acceleration_covariance[3]: covariance in the yx direction.
linear_acceleration_covariance[4]: covariance in the yy direction.
linear_acceleration_covariance[5]: covariance in the yz direction.
linear_acceleration_covariance[6]: covariance in the zx direction.
linear_acceleration_covariance[7]: covariance in the zy direction.
linear_acceleration_covariance[8]: covariance in the zz direction.
8. Notes
Covariance matrix: if all elements of a covariance matrix are zero, it means the covariance is unknown and covariance information needs to be obtained from other sources.
No estimate: if a data element has no estimate (for example, the IMU does not provide an orientation estimate), the first element of that covariance matrix should be set to -1.

```cpp
#include <ros/ros.h>
#include <sensor_msgs/Imu.h>
#include <tf/tf.h> // 四元数转换为欧拉角

/**
 * IMUCallback 函数用于处理IMU数据回调。
 * 该函数接收IMU消息，检查方向估计的有效性，并将四元数转换为欧拉角后打印出来。
 *
 * @param msg 接收到的IMU消息，包含四元数和其他传感器数据。
 */
void IMUCallback(sensor_msgs::Imu msg)
{
    // 检查是否有有效的方向估计值
    if (msg.orientation_covariance[0] < 0) 
        return;

    // 创建 tf::Quaternion 对象，用于后续将四元数转换为欧拉角
    tf::Quaternion quaternion(
        msg.orientation.x,
        msg.orientation.y,
        msg.orientation.z,
        msg.orientation.w
    );

    // 将四元数转换为欧拉角（roll, pitch, yaw）
    double roll, pitch, yaw;
    tf::Matrix3x3(quaternion).getRPY(roll, pitch, yaw);
    // tf::Matrix3x3 是一个 3x3 的矩阵类，用于表示旋转矩阵。
    // tf::Matrix3x3(quaternion)：将四元数 quaternion 转换为旋转矩阵。

    // getRPY 方法从旋转矩阵中提取欧拉角（roll、pitch、yaw）。
    // 将欧拉角从弧度转换为角度 将弧度乘以π/180，即可将弧度转换为角度。
    roll = roll * 180 / M_PI;
    pitch = pitch * 180 / M_PI;
    yaw = yaw * 180 / M_PI;

    // 打印转换后的欧拉角信息
    ROS_INFO("roll滚转: %.2f, pitch俯仰: %.2f, yaw朝向: %.2f", roll, pitch, yaw);
}

/**
 * main 函数是程序的入口点。
 * 初始化ROS节点并订阅IMU数据，进入消息循环等待回调处理。
 *
 * @param argc 命令行参数数量。
 * @param argv 命令行参数数组。
 * @return 返回0表示程序成功结束。
 */
int main(int argc, char *argv[])
{
    // 设置区域，以便正确显示字符
    setlocale(LC_ALL, "");

    // 初始化ROS节点
    ros::init(argc, argv, "imu_node");

    // 创建节点句柄
    ros::NodeHandle n;

    // 订阅IMU数据
    ros::Subscriber imu_sub = n.subscribe("/imu/data", 10, IMUCallback);

    // 进入消息循环，等待回调处理
    ros::spin();

    // 返回成功
    return 0;
}
```

```cpp
#include <sensor_msgs/Imu.h>
#include <tf/tf.h> // 四元数转换为欧拉角

 * IMUCallback 函数用于处理IMU数据回调。
 * 该函数接收IMU消息，检查方向估计的有效性，并将四元数转换为欧拉角后打印出来。
 *

ros::Publisher vel_pub;
void IMUCallback(sensor_msgs::Imu msg)
{

    if (msg.orientation_covariance[0] < 0)

    // tf::Matrix3x3 是一个 3x3 的矩阵类，用于表示旋转矩阵。
    // tf::Matrix3x3(quaternion)：将四元数 quaternion 转换为旋转矩阵。

    // getRPY 方法从旋转矩阵中提取欧拉角（roll、pitch、yaw）。
    // 将欧拉角从弧度转换为角度 将弧度乘以π/180，即可将弧度转换为角度。
    roll = roll * 180 / M_PI;
    pitch = pitch * 180 / M_PI;
    yaw = yaw * 180 / M_PI;

    // 打印转换后的欧拉角信息
    ROS_INFO("roll滚转: %.2f, pitch俯仰: %.2f, yaw朝向: %.2f", roll, pitch, yaw);

    double target_yaw = 90;
    double diff_angle=target_yaw-yaw;
    geometry_msgs::Twist vel_cmd;
    vel_cmd.angular.z=diff_angle*0.01;
    vel_cmd.linear.x=0.1;
    vel_pub.publish(vel_cmd);

}

int main(int argc, char *argv[])
{
    // 设置区域，以便正确显示字符
    setlocale(LC_ALL, "");

    // 初始化ROS节点
    ros::init(argc, argv, "imu_node");

    // 创建节点句柄
    ros::NodeHandle n;

    // 订阅IMU数据
    ros::Subscriber imu_sub = n.subscribe("/imu/data", 10, IMUCallback);

    vel_pub=n.advertise<geometry_msgs::Twist>("/cmd_vel", 10);

    // 进入消息循环，等待回调处理
    ros::spin();

    // 返回成功
    return 0;
}
```

```python
#! /usr/bin/env python3
#coding=utf-8
import rospy
from sensor_msgs.msg import Imu
from tf.transformations import euler_from_quaternion
import math
from geometry_msgs.msg import Twist

def imu_callback(msg):
    if msg.orientation_covariance[0] < 0:
        return
    quaternion=[
        msg.orientation.x,
        msg.orientation.y,
        msg.orientation.z,
        msg.orientation.w
    ]
    (roll,pitch,yaw)=euler_from_quaternion(quaternion)
    roll=roll*180/math.pi
    pitch=pitch*180/math.pi
    yaw=yaw*180/math.pi
    rospy.loginfo("roll滚转=%.0f pitch俯仰=%.0f yaw朝向=%.0f",roll,pitch,yaw)
    target_yaw=90
    diff_angle=target_yaw-yaw
    vel_cmd=Twist()
    vel_cmd.angular.z=diff_angle*0.01
    vel_cmd.linear.x=0.1
    global vel_pub
    vel_pub.publish(vel_cmd)
if __name__ == '__main__':
    rospy.init_node('imu_node')
    imu_sub = rospy.Subscriber('/imu/data', Imu, imu_callback,queue_size=10)
    vel_pub = rospy.Publisher('/cmd_vel', Twist, queue_size=10)
    rospy.spin()
```

# Custom Message Packages
A message package is also a software package

1. Message definition file
File location: msg files are usually stored in the msg directory of a ROS package.
File format: a msg file is a plain text file where each line defines a field, and a field consists of a type and a name.
2. Message content syntax
Field definition: each line defines a field in the format `type name`.
Supported types:
Basic types:
int8, int16, int32, int64 (and the corresponding unsigned types uint8, uint16, uint32, uint64)
float32, float64
string
time, duration
Other message types: you can reference other already-defined message types.
Arrays: variable-length arrays [] and fixed-length arrays [C] are supported.

# Occupancy Grid Map Format
[https://docs.ros.org/en/api/nav_msgs/html/msg/OccupancyGrid.html](https://docs.ros.org/en/api/nav_msgs/html/msg/OccupancyGrid.html)
The map origin is at the bottom-left corner
![Image](/images/csdn/2025/csdn-145444782/image-013-805e2e0891.png)
nav_msgs/OccupancyGrid is a message type in ROS (Robot Operating System) used to represent a 2D grid map. Each grid cell represents the occupancy state of that location


1. Header header
Type: std_msgs/Header
Purpose: contains timestamp and coordinate frame information, used to describe the temporal and spatial reference of the map data.
Fields:
uint32 seq: sequence number, used to identify the order of messages.
time stamp: timestamp, indicating the time of the message.
string frame_id: the name of the coordinate frame, indicating the reference frame in which the map data is expressed.
2. MapMetaData info
Type: nav_msgs/MapMetaData
Purpose: contains the map's metadata, describing the map's properties and configuration.
Fields:
float32 map_load_time: the timestamp when the map was loaded.
float32 resolution: the resolution of the map (unit: meters/pixel), or in other words the length of a grid cell
int32 width: the width of the map (unit: pixels).
int32 height: the height of the map (unit: pixels).
geometry_msgs/Pose origin: the position and orientation of the map's origin, as an offset relative to the coordinate frame.
3. int8[] data
Type: int8[] (integer array)
Purpose: stores the actual map data in row-major order.
Meaning of values:
-1: unknown, meaning the occupancy state of that location is unknown.
0: free, meaning the location is not occupied.
100: occupied, meaning the location is occupied.
Range: occupancy ranges between [0, 100], with -1 for unknown.

# Publishing a Map
![Image](/images/csdn/2025/csdn-145444782/image-014-0cbc116265.png)

```cpp
#include <ros/ros.h>
#include <nav_msgs/OccupancyGrid.h>

int main(int argc, char  *argv[])
{
    ros::init(argc, argv, "map_pub_node");
    ros::NodeHandle nh;
    ros::Publisher map_pub = nh.advertise<nav_msgs::OccupancyGrid>("/map", 1);
    ros::Rate loop_rate(10);
    while(ros::ok())
    {
        nav_msgs::OccupancyGrid msg;
        msg.header.frame_id = "map";
        msg.header.stamp = ros::Time::now();
        //地图相对坐标系原点的偏移量
        msg.info.origin.position.x = 1.0; 
        msg.info.origin.position.y = 0.0;
        msg.info.resolution = 1.0; //栅格的长度
        msg.info.width = 4;
        msg.info.height = 2;

        msg.data.resize(msg.info.width * msg.info.height);
        msg.data[0]=90;
        msg.data[1]=100;
        msg.data[2]=0;
        msg.data[3]=-1;
        map_pub.publish(msg);
        loop_rate.sleep();

    }
    return 0;
}

```

```python
import rospy
from nav_msgs.msg import OccupancyGrid

if __name__ == '__main__':
    rospy.init_node('map_pub_node')
    pub = rospy.Publisher('/map', OccupancyGrid, queue_size=10)
    rate = rospy.Rate(10)
    while not rospy.is_shutdown():
        msg = OccupancyGrid()
        msg.header.stamp = rospy.Time.now()
        msg.header.frame_id = 'map'

        msg.info.resolution = 1
        msg.info.width = 4
        msg.info.height = 2
        msg.info.origin.position.x = 0
        msg.info.origin.position.y = 0

        msg.data[0]=100

        msg.data[2]=0
        msg.data[3]=-1
```
