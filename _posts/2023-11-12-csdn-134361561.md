#  Callee-saved registers and caller-saved registers
> Function A calls function B, and register rbx is modified in function B; logically, the contents of %rbx should be the same before and after calling function B.
There are two strategies to solve this problem:
(1) Function A saves the contents of register %rbx before calling function B and restores them after function B finishes; this strategy is called caller-saved;
(2) Before using register %rbx, function B first saves its value, and before function B returns, it restores the original contents of %rbx; this strategy is called callee-saved.


> For the two strategies above, different registers are defined to use different strategies.
Registers using the first strategy are caller-saved registers; registers using the second strategy are callee-saved registers.


> callee-saved: actually better called call-preserved; it has the const   attribute and is protected
> %rbx ，%rbp，%r12，%r13，%r14，%r15

> caller-saved:  actually better called call-clobbered; it has the volatile attribute and is subject to change
> %rax，%rdi，%rsi，%rdx，%rcx，%r8，%r9，%r10，%r11

# Overview of function calls
When a function is called, the function's arguments are pushed onto the stack, the return address is pushed onto the stack, then after entering the function, the function's local variables are pushed onto the stack.

Arguments are pushed from right to left; local variables defined earlier are pushed earlier

When the function call ends, the leave and ret instructions are executed
The leave instruction copies rbp to rsp, then pops into rbp
The ret instruction pops into rip

# Differences in arguments
32-bit: arguments are above the return address
64-bit: the first six arguments are RDI RSI RDX RCX R8 R9 (register contents: pointers for strings, the corresponding encodings for numbers, and their corresponding encodings for characters); the rest are saved on the stack. Also, a memory address cannot be greater than 0x00007FFFFFFFFFFF, otherwise an exception is thrown

> A 64-bit pointer representing a memory address has only the low 48 bits valid, sign-extended to 64 bits. In other words, its high 16 bits must be all 1s or all 0s and must match the highest bit (bit 47) of the low 48 bits.
