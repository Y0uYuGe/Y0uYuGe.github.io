# wsl
If it freezes, just open Task Manager and kill it.

```bash
wsl --list -v # 安装的
wsl --list --online #可以安装的
```

```bash
 wsl -d  kali-linux # 启动子系统
  wsl -unregister kali-linux # 卸载子系统
```
Export a subsystem
```bash
wsl --export Ubuntu-22.04 ubuntu.tar
```
Import a subsystem; Ubuntu2    is the subsystem name, and C:\Users\35925\wsl is the location where the imported image is saved

```bash
 wsl --import Ubuntu2    C:\Users\35925\wsl  ubuntu.tar
```
