# Construction and Application of a Hydrological Model Knowledge Graph (Core)

[Construction and Application of a Hydrological Model Knowledge Graph](https://mp.weixin.qq.com/s/oV-16C4EQ7hqHJ2kUAlxvw)

Title: Construction and Application of a Hydrological Model Knowledge Graph
Authors: Zhou Yifan, Duan Hao, Zhao Hongli, Zhao Huizi, Li Hao, and Han Kun
Journal: Journal of Hydraulic Engineering, 2024 Issue 1

Summary: top-down construction.
![Image](/images/csdn/2024/csdn-144455199/image-001-eee173e2dd.png)

1. Ontology modeling: graph boundary -> concept/term nodes -> attributes
2. Entity extraction: BERT model -> different extraction strategies for different entity types with assigned strategy weights -> the results of different strategies are scored and ranked (entities extracted by a strategy get the corresponding weight score), plus pattern filtering (removing possible duplicates that were extracted differently)
3. Relation extraction: a combination of direct matching and pattern matching (common methods are template-based relation extraction, supervised-learning-based relation extraction, and weakly-supervised-learning-based relation extraction)
4. Knowledge fusion: entity fusion via vocabulary mapping (mapping different expressions of the same model to a standard name) to resolve multi-word coreference + a vocabulary mapping table is likewise used to organize and align synonymous evaluation metrics
5. Knowledge storage: stored in Neo4j




#  Construction and Application of a Knowledge Graph for Water-Conservancy Flood Control and Emergency Rescue
[Construction and Application of a Knowledge Graph for Water-Conservancy Flood Control and Emergency Rescue](https://mp.weixin.qq.com/s/SqHaZMxSzF2bd9lHErYO7A)
![Image](/images/csdn/2024/csdn-144455199/image-002-5fdae50747.png)

Summary: multi-source text -> LLM + convolutional module + improvements at the semantic-association level


1. Data processing: flood-control and emergency-rescue knowledge comes from multi-source heterogeneous knowledge carriers, both semi-structured and unstructured

2. An LLM extracts terms related to flood control and emergency rescue via prompts + a clustering algorithm extracts term topics for reorganization and optimization
3. Entity data augmentation expands the data, and a CNN is introduced to improve the extraction model
4. Knowledge fusion and processing, then stored in a graph database


Highlight: triples + the Standard for Terminology of Water Resources and Hydropower Engineering Design (SL 26-2012) —> quintuples

# Construction and Application of Knowledge Graphs in Hydraulic Engineering
[Construction and Application of Knowledge Graphs in Hydraulic Engineering](https://mp.weixin.qq.com/s/s-JUhfTG5Lila085oMkr1g)
1. Data cleaning, integration, and standardization
2. The General Rules for Classification and Coding of Water Resources Objects determine the concept nodes (or node types) + basic object information serves as the attributes of the types and as attribute data nodes + a bipartite-graph mapping algorithm (whose nodes can be divided into two groups, with every edge connecting nodes from different groups) determines the relationships between concept nodes
3. Based on the probability nodes, attributes, and relations, instantiation is performed with concrete data (inference rules are embedded in the relations)
4. ECharts visualization provides retrieval and recommendation
