# What Is a Regression Task
A task that trains a model on historical data to predict concrete numerical values in the future is a regression task.
Multiple linear regression is the most fundamental of the many regression algorithms.

# What Does "Multiple" Mean
Multiple: multiple dimensions — the multiple factors that influence the prediction target. A house's sale price depends on multiple factors.
Linearity in three dimensions: simply a plane.
Linearity in higher dimensions: collectively called a hyperplane.
![Image](/images/csdn/2024/csdn-144494598/image-001-a5db87bf85.png)

# What Is Regression
Regression: fitting the data points.
Fitting can be linear or nonlinear.
Linear regression in 3D: fitting data points with a plane.
Nonlinear regression in 3D: fitting data points with a curved surface.

# What Is Multiple Linear Regression
Multiple linear regression: using a linear shape (line, plane, hyperplane) in a multivariate space to fit the data points.

# When to Use Multiple Linear Regression
When to use it: when you suspect it applies — try it in unknown situations to see whether it fits.

# Notes
Counting Y, there are actually N+1 dimensions: N X's and 1 Y.
![Image](/images/csdn/2024/csdn-144494598/image-003-61b9e07e96.png)

Y is determined by a group of X's; concretely, it is the Y value at the position corresponding to X on the linear shape.
# Loss Function
The mean squared error (Mean Squared Error) between the actual Y and the predicted Y: a common loss function for regression tasks — the smaller it is, the better the fit.
![Image](/images/csdn/2024/csdn-144494598/image-004-f4e824d5c2.png)
