# Algorithm Implementation
When performing insertion sort on each sublist, start directly from the sublist's second element, which is at position d+1, and iterate up to n

Then compare — but always comparing positions separated by the increment of the increment sequence. Moving positions also has to be done by steps of the increment

When a greater element is finally found, the position of the element being compared must be advanced by the increment
![Image](/images/csdn/2024/csdn-135414743/image-009-ca6d7950d5.png)
# Algorithm Performance Analysis
