# Managing the State of Each Page in the heap Region
Linked list approach: link all unallocated pages in the heap region with a linked list, and link all allocated regions with another linked list
Array approach: use an array to represent all pages in the heap region, and set certain flag bits to indicate whether the page corresponding to the array element is allocated

# Code
Overall, two parts are implemented: memory layout and dynamic memory allocation

The linker script and the assembly memory.S implement the memory layout
Dynamic page allocation is implemented in page.c

- word: represents four bytes

- In assembly, you can use symbols from the linker script for assignment, but they only take effect after linking; that is, the assignment does not succeed when the object file is generated (the symbol is recognized as an undefined symbol, meaning the symbol is not defined in the current object file and will be resolved to a symbol defined in another object file during the linking stage. In this case, _heap_start may be defined in another object file and resolved during the linking stage.)

- The extern keyword can be used not only to declare global variables defined in other C files, but also to declare global variables defined in assembly files. This usually happens in embedded development or low-level system programming, where interaction with assembly code is needed.


- A variable is declared in the data segment, and the value of this variable is included in the ELF; the ELF file includes the symbol and value of this variable, but if, for example, the compiler finds that some of your variables are initially 0, the compiler can store only their symbols, not their values (they are all 0 anyway), and put them all in the BSS segment (**reference: expert 刘霁兰** )

- la is short for "load address"; it is a pseudo-instruction used to load the address of a symbol into a register.
- bgeu is short for "branch if greater or equal, unsigned"; it is a conditional branch instruction.
- sw is store word
- addi is add immediate
- bltu is branch if less than unsigned
- sll is Shift Left Logical
