# Instruction Format
![Image](/images/csdn/2023/csdn-134745864/image-005-6a343077e4.png)
## Zero-Address Instructions
This can be understood in combination with postfix expressions: the two operands are implicitly stored at the top and second-from-top of the stack
![Image](/images/csdn/2023/csdn-134745864/image-006-a013cf1c23.png)
## One-Address Instructions
Fetching the instruction requires one memory access; reading the contents of some address from main memory also requires one memory access
![Image](/images/csdn/2023/csdn-134745864/image-007-ab89f73ab1.png)
## Two- and Three-Address Instructions
That is, a three-address instruction specifies where the result is stored
A two-address instruction does not specify where the result is stored; the default is used
![Image](/images/csdn/2023/csdn-134745864/image-008-7e0c53f9e9.png)
- Two-address instructions can be divided into (depending on what is accessed):
1. Memory-memory (SS) type instructions (only memory is accessed)
2. Register-register (RR) type instructions (only registers are accessed)
3. Register-memory (RS) type instructions (both memory and registers are accessed; generally the instruction has both bits indicating a register and bits for a formal address)
## Four-Address Instructions
Modifying the PC is not simply incrementing it sequentially by 1
The address range corresponding to the total instruction length is limited. If the total instruction length stays the same, the more address codes there are, the smaller the addressable range will be relative to the total address range
![Image](/images/csdn/2023/csdn-134745864/image-009-6fc54336d6.png)
