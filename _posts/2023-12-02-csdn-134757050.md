# Basic Introduction to ISA
## What Is ISA
Interface specification: can be understood as a kind of standard
Microarchitecture: a hardware implementation of an instruction set architecture; for example, if two hardware architectures can both implement x86, then both hardware architectures can be called microarchitectures
![Image](/images/csdn/2023/csdn-134757050/image-001-633860245e.png)
##  Why Design an ISA
To provide an abstraction for upper-layer software, establishing rules and constraints, so that programmers don't have to worry about the specific circuit structure, or worry about causing hardware malfunctions
## CISC vs RISC
![Image](/images/csdn/2023/csdn-134757050/image-002-f5338e49f3.png)
## Width of an ISA
![Image](/images/csdn/2023/csdn-134757050/image-003-b528816910.png)
The width of an ISA is unrelated to the width of instructions (i.e., you cannot say that a 32-bit machine must have 32-bit instructions)

# Exceptions and Interrupts
An exception jumps to the exception handler, and after execution finishes, returns to continue executing the original instruction
An interrupt also jumps to the interrupt handler, and after execution finishes, returns to execute the instruction following the original one
