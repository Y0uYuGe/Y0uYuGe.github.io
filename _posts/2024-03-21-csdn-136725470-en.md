# System Boot
Bootloader loading: when the power is turned on, the processor loads the bootloader from a predefined storage device (such as a hard disk, solid-state drive, flash memory, etc.). The bootloader is located at a specific position on the boot device and is responsible for starting the operating system.

Bootloader initialization: bootloader initialization includes setting up the basic hardware environment, such as processor mode, memory management unit (MMU), etc.

Kernel loading: the bootloader loads the operating system kernel to a specific location in memory. This kernel is usually a standalone precompiled binary file that contains the core functions of the operating system.

Kernel initialization and startup: once the kernel is loaded into memory, the processor switches to executing the kernel. The kernel performs a series of initialization operations, including initializing hardware devices, starting device drivers, building necessary data structures, etc.


When compiling, -Ttext is used to select a location such as 0x80000000 as the starting position of the kernel
qemu -kernel specifies the kernel to load

# Kernel Boot Process
1. After power-on, the CPU automatically executes the BIOS (located in the motherboard ROM, mainly checking whether the hardware has problems)
2.  Finally the BIOS loads the contents of the disk's sector zero (the MBR, Master Boot Record) into memory and starts executing the MBR
3. When executing the MBR, it selects and loads the contents of the first sector of a system partition (that system's bootloader) into memory
4. It starts executing the contents of the loaded sector, and then the system boots

# Bootloader
The boot loader, usually called the Bootloader, is a key component in starting the Linux operating system. Its main role is to load the operating system kernel when the computer starts up and hand control over to the kernel, thereby starting the operating system. The Bootloader is also responsible for detecting and initializing hardware devices, providing the operating system with the necessary information and parameters.
