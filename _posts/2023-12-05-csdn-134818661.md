# Introduction to RISC-V Assembly Language
## Introduction to Assembly Language Concepts
High-level: can be understood as being closer to human understanding
Low-level: can be understood as being closer to the machine

Hard to port: assembly instructions basically correspond one-to-one with machine instructions, and machine languages differ across instruction set architectures. So assembly for one machine may not run on a machine with a different architecture.

Flexible: high-level languages interact with the low level through machine instructions generated by the compiler; if you want to optimize the generated machine instructions, a high-level language cannot do it directly, so it is not flexible enough. Assembly, on the other hand, is lower-level and can directly control the generation of the corresponding machine instructions, so optimization is more convenient.

# Introduction to Assembly Language Syntax (GNU Version)
Different assemblers support different assembly syntaxes
Uppercase S keeps preprocessing statements
lowercase s is pure assembly statements
[ ] square brackets indicate that the content is optional; it may or may not be present, and if none is present it is an empty line
![Image](/images/csdn/2023/csdn-134818661/image-003-7622658221.png)
label: content 
label:
				content
The label and the content can be on one line or two lines
A label can be understood as an address
Pseudo-instruction: an instruction that contains multiple basic instructions
The assembler decomposes pseudo-instructions into multiple instructions, then converts them into machine instructions for execution
Directive/pseudo-operation: it does not tell the assembler what to do, but rather tells the assembler how to do it. For example, movq $0, %rax is directly translated by the assembler into machine code and is eventually executed directly by the CPU, while .section __TEXT,__text is not translated into machine code, and no trace of this statement can be found in the final executable. Its role is to tell the assembler how to assemble. It is syntax defined by the assembler itself, written for the assembler to read. Its definition can be found in the assembler's manual
