# Explanation of Related Concepts Provided by the Spark Model (for Reference Only)

 The physical layer is the lowest layer in the OSI model of computer networks and is responsible for the actual transmission of data.

The related concepts of the physical layer include the following aspects:

1. Physical media: the physical layer connects different computer devices through various transmission media (such as optical fiber, cable, twisted pair, etc.).
2. Data transmission: the main function of the physical layer is to ensure that the raw bit stream data can be correctly transmitted over these physical media.
3. Transparent transmission: the physical layer provides transparent transmission, meaning that the parties in network communication do not need to care about the specific transmission medium type in the data path, the related standards, or the details of the communication protocol.
4. Data encoding: to ensure that the data bit stream can be transmitted normally in the corresponding channel, the physical layer needs to encode the data. Different transmission media support different data encoding types, such as return-to-zero code, non-return-to-zero code, Manchester code, differential Manchester code, etc.
5. Data transmission management: the physical layer also has certain data transmission management functions, including bit-stream-based data transmission flow control, error control, activation and release of physical lines, etc.
6. Transmission modes: the physical layer defines the data transmission modes, including concepts such as one-way communication, two-way communication, simplex, half-duplex, and full-duplex.

In general, the core task of the physical layer is to provide data transmission services for the data link layer, ensuring the correct transmission of bit streams through the transmission medium. It formulates corresponding physical layer protocols according to the transmission medium used, specifying the encoding method of data signals, the transmission rate, and other related parameters.
