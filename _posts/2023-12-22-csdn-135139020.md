## Properties of Red-Black Trees
Since the number of black nodes on the path from the root to any node is the same, the shortest path is all black, while the longest has red nodes on the path. Because there are no adjacent red nodes, the case with the most nodes is when red nodes sit between black nodes, in which case the total number of nodes is at most twice that of the all-black case
![Image](/images/csdn/2023/csdn-135139020/image-013-175b8d986f.png)
# Searching a Red-Black Tree
Same as searching a balanced binary tree or a binary search tree: go to the left subtree if smaller, and to the right subtree if greater
![Image](/images/csdn/2023/csdn-135139020/image-014-4905ee9df7.png)

## Summary
Since the longest path from the root to a leaf node is no more than twice the shortest path, the heights of the left and right subtrees differ by no more than a factor of two
![Image](/images/csdn/2023/csdn-135139020/image-040-2fc1fb2c3c.png)
## Theory Related to Black Height
External nodes are the empty nodes
For a red-black tree whose root has black height h, the number of internal nodes is minimized when all nodes are black, because red nodes cannot be adjacent. And in this all-black case the tree must also be a full tree, otherwise the black height from the root cannot reach h
![Image](/images/csdn/2023/csdn-135139020/image-041-7636b7e286.png)
The black height is greater than or equal to h/2 because with one black and one red alternating, the black height will be at least h/2; from the black height of the root we can derive the minimum number of internal nodes, and finally the range of the total height
![Image](/images/csdn/2023/csdn-135139020/image-042-f34c302d2f.png)
