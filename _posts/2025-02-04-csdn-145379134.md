# Reinforcement Learning Fundamentals
1. Get a reward returned from the current environment
2. Get an action based on the current environment
3. The action updates the environment
4. The above three steps repeat in a loop, and the total reward obtained is tallied; the goal is to maximize the total reward

But if we only take actions that maximize the returned reward, we may ignore actions that could lead to greater future rewards but have relatively small current rewards

## Characteristics of Reinforcement Learning
The differences between reinforcement learning and supervised learning are as follows.

(1) The input samples of reinforcement learning are sequential data, unlike supervised learning where samples are all independent.

(2) The learner is not told what the correct action should be at each step; the learner needs to discover for itself which actions can bring the most reward, and can only discover the most beneficial actions through constant trial.

(3) The process by which an agent acquires its ability is actually a process of continuous trial-and-error exploration. Exploration and exploitation are very core issues in reinforcement learning. Exploration means trying some new actions, which may bring us more reward or may leave us with "nothing"; exploitation means taking the actions already known to yield the most reward and repeating them, because we know doing so can bring a certain reward. Therefore, we need to balance exploration and exploitation, which is a situation not present in supervised learning.

(4) In the reinforcement learning process, there is no very strong supervisor, only a reward signal, and the reward signal is delayed — that is, the environment tells us only much later whether the action we took earlier was actually effective. Because we don't get immediate feedback, it is very difficult for the agent to learn with reinforcement learning. When we take an action, if we were using supervised learning, we could immediately get guidance — for example, we took a wrong action, and here is what the correct action should be. In reinforcement learning, however, the environment may tell us that this action is wrong, but it does not tell us what the correct action is. What's more difficult is that it may tell us a minute or two later that the action was wrong. So this is also where reinforcement learning differs from supervised learning.

## Two Types of Reinforcement Learning


We can classify agents according to what they learn. A value-based agent explicitly learns the value function and implicitly learns its policy. The policy is derived from the learned value function. A policy-based agent directly learns the policy: given a state, it outputs the probability of the corresponding action. A policy-based agent does not learn the value function. Combining value-based agents and policy-based agents gives the actor-critic agent. This type of agent learns both the policy and the value function, and then obtains the best action through their interaction.

Q: What is the difference between policy-based and value-based reinforcement learning methods?

A: For a Markov decision process with known state transition probabilities, we can use dynamic programming algorithms to solve it. From the perspective of decision-making, reinforcement learning can be divided into policy-based methods and value-based methods. The decision-making method is the basis on which the agent selects an action from the action set in a given state; it is static and does not change as the state changes. In policy-based reinforcement learning methods, the agent formulates a set of action policies (determining which action to take in a given state) and operates according to this policy. The reinforcement learning algorithm directly optimizes the policy so that the formulated policy can obtain the maximum reward. In value-based reinforcement learning methods, the agent does not need to formulate an explicit policy; it maintains a value table or value function and selects the action with the maximum value through this value table or value function. Value-iteration-based methods can only be applied in discontinuous, discrete environments (such as Go or certain game domains). For scenarios with large action sets and continuous actions (such as robot control), it is difficult for them to learn good results (in these cases, policy-iteration-based methods can select continuous actions according to the configured policy). Value-based reinforcement learning algorithms include Q-learning, Sarsa, etc., while policy-based reinforcement learning algorithms include the Policy Gradient (PG) algorithm, etc. In addition, actor-critic algorithms use both policy and value evaluation to make decisions. The agent takes actions according to the policy, and the value function assigns a value to the actions taken, which can accelerate the learning process on top of the original policy gradient algorithm and achieve better results.

##  Two Strategies: Exploration vs. Exploitation
Exploration means we explore the environment by trying different actions to obtain the best policy (the policy that brings the maximum reward). 
Exploitation means we don't try new actions, but instead take the actions already known to bring large rewards.

### Discount Factor
1. Avoid infinite rewards
In some Markov processes, the agent may fall into a cyclic state, causing the cumulative reward to become infinitely large. For example, suppose the agent can indefinitely receive small positive rewards in an environment with no terminal state. Without a discount factor, the cumulative reward would tend toward infinity, which is mathematically intractable. By introducing a discount factor γ (where 0≤γ<1), future rewards are gradually reduced, thereby avoiding the problem of infinitely large cumulative rewards.
2.  Handle uncertainty
In practical applications, we usually cannot simulate the environment with complete accuracy. Future rewards may be affected by many factors, including the randomness of the environment, model inaccuracy, and the agent's decision-making errors. By introducing a discount factor, we can focus more on current rewards rather than relying too heavily on predictions of the future. This reflects our uncertainty about the future — we want to obtain rewards as soon as possible, rather than at some uncertain point in the future.
3. Reflect the actual value of rewards
In many practical scenarios, immediate rewards are more valuable than future rewards. For example, a sum of money now is usually worth more than the same amount at some point in the future, because the money now can be used immediately, while future money may be affected by inflation and other factors. Similarly, in reinforcement learning, the agent may prefer to obtain immediate rewards rather than future rewards.
4.  Encourage immediate rewards
The discount factor can also be used to adjust the agent's behavioral policy. By setting different discount factors, we can encourage the agent to focus more on immediate rewards or future rewards. For example:
γ=0: the agent only cares about the current reward and completely ignores future rewards. This applies to scenarios where only immediate effects matter.
γ=1: the agent values future rewards and current rewards equally, with no discounting. This applies to scenarios where future rewards and current rewards are equally important.
0<γ<1: the agent balances immediate rewards and future rewards. The smaller the discount factor, the more the agent favors immediate rewards; the larger the discount factor, the more the agent favors future rewards.

##  Markov Decision Process (MDP)
The Markov decision process adds actions on top of the Markov reward process. It describes the actions the agent can take in each state, and how these actions affect state transitions and rewards.

![Image](/images/csdn/2025/csdn-145379134/image-008-d9c4e4a340.png)

Simply put: there is a probability from a state to an action, and there is also a probability from an action to the next state
![Image](/images/csdn/2025/csdn-145379134/image-009-ea3bb296ba.png)
At this point, each state and each action has a (deterministic) reward function. The reward function for a state is the weighted sum of the reward functions for that state paired with each possible action, weighted by the probability of the corresponding action occurring in that state

###  Differences Between Markov Decision Process and Markov Process / Markov Reward Process
Markov process / Markov reward process: direct state transitions, state transition probabilities
Markov decision process: there is also an action probability and a probability of a state-action pair transitioning to the next state

###  Control Methods for Markov Decision Processes
The process of finding the optimal policy is the control process of a Markov decision process

Policy search:
![Image](/images/csdn/2025/csdn-145379134/image-022-3291cc09f3.png)
Policy iteration:
The first step is policy evaluation. We are currently optimizing the policy π (a concrete policy, such as how to move at each step), and during the optimization we obtain a latest policy. We first keep this policy fixed, then estimate its value — that is, estimate the state value function given the current policy function.
 The second step is policy improvement. After obtaining the state value function, we can further derive its Q function. After obtaining the Q function, we directly maximize the Q function, improving the policy further by performing a greedy search over the Q function.
![Image](/images/csdn/2025/csdn-145379134/image-023-c87cf1ef37.png)
These two steps iterate continuously.

![Image](/images/csdn/2025/csdn-145379134/image-024-222aeff508.png)
