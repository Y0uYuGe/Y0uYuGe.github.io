## Vertex Degree, In-Degree, Out-Degree
In an undirected graph, one edge connects two nodes and contributes two degrees
In a directed graph, one edge connects two nodes: it contributes an in-degree to one node and an out-degree to the other
![Image](/images/csdn/2023/csdn-134785778/image-007-075cc0ec55.png)
## Describing Vertex-to-Vertex Relationships
Connected (in undirected graphs): there is a path between two vertices
Strongly connected (in directed graphs): there are paths in both directions between two vertices
![Image](/images/csdn/2023/csdn-134785778/image-008-3deddfd5ef.png)
## Connected Graphs, Strongly Connected Graphs
For an undirected graph G with n vertices
For it to be a connected graph, it suffices to connect the n vertices in a line, which takes n-1 edges
For it to be a non-connected graph, isolate one vertex and fully connect the edges among the remaining nodes; this amounts to counting how many ways there are to choose two vertices from n-1 vertices. After fully connecting them, adding any more edge can only connect the isolated vertex to the remaining nodes, which would make the graph connected, so that is not allowed. So you only need to count the number of edges that fully connect the remaining nodes

For a directed graph with n vertices
For it to be a strongly connected graph, there must be at least n edges (i.e., forming a cycle, so that any vertex can reach any other vertex by following the direction of the cycle)
![Image](/images/csdn/2023/csdn-134785778/image-009-f48a09a1b1.png)

# Adjacency List
![Image](/images/csdn/2023/csdn-134785778/image-031-86ae6867b5.png)
## Sequential + Linked Storage
Use a one-dimensional array to store the graph; each vertex has pointer information for its corresponding edges
![Image](/images/csdn/2023/csdn-134785778/image-032-d909fecb3f.png)
## Comparison with the Child Representation of Trees
![Image](/images/csdn/2023/csdn-134785778/image-033-dee01f142b.png)
## Directed Graphs vs Undirected Graphs
The same edge needs to be stored twice in an undirected graph but only once in a directed graph, so the space complexity differs
![Image](/images/csdn/2023/csdn-134785778/image-034-f002b72fae.png)
## Finding Vertex Degree, In-Degree, Out-Degree
Degree in an undirected graph: just traverse the edge list of that node
Out-degree in a directed graph: just traverse the edge list of that node
In-degree in a directed graph: you need to traverse the edge lists of all nodes other than that node (troublesome)
Degree in a directed graph: in-degree + out-degree
## The Representation Is Not Unique
That is, the edge lists of vertices are not unique
But the adjacency matrix of a graph is unique
![Image](/images/csdn/2023/csdn-134785778/image-035-a1458eae6f.png)

## Storing an Undirected Graph with an Adjacency Multilist
That is, each edge corresponds to only one edge element, and the linked list represents the edges connected to a vertex
![Image](/images/csdn/2023/csdn-134785778/image-042-5a230ca323.png)
When deleting an edge, you only need to change the pointer of the previous one to point to the next edge
When deleting a vertex, just delete the edge list corresponding to that vertex, and modify the pointers of elements in other lists that point to elements in this list
