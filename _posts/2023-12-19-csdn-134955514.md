# use after free
When a chunk is freed but its corresponding pointer is not set to NULL, various problems may occur
# Situations after free

 - After the memory block is freed, its corresponding pointer is set to NULL; using it again naturally crashes the program.
- After the memory block is freed, its corresponding pointer is not set to NULL, and no code modifies this memory block before its next use, so the program very likely keeps running normally.
- After the memory block is freed, its corresponding pointer is not set to NULL, but some code modifies this memory before its next use, so when the program uses this memory again, strange problems are very likely to occur.

### del_note
Deletes a node: first enter the index, then free the node and the node's content pointer. There is a use after free vulnerability here.
In other words, you can allocate this heap chunk again, modify the original content, and still use the functionality of the elements corresponding to the original content
![Image](/images/csdn/2023/csdn-134955514/image-005-ce9acb077e.png)
### print_note
Prints the node content
First enter the index, then call the output function inside the node according to the index; the argument is the node pointer
![Image](/images/csdn/2023/csdn-134955514/image-006-17c6647f1e.png)
### put 
a1 is the node pointer here, and a1+4 is the location of the corresponding content pointer. So this just outputs the content

## Approach
1. First create two heap chunks, then free them (size requirements apply)
2. Then create a heap chunk that lets us modify the content of the original chunk
3. Finally, since the original chunk pointer still exists, reuse the content of the original chunk
(For example, some input uses a piece of data in the original heap chunk (a function address) to jump to that location and call the function; use the above operations to overwrite that data with the address of system, and since the original chunk pointer was not set to NULL after free, entering the input that calls the function of the original chunk pointer gets a shell)
