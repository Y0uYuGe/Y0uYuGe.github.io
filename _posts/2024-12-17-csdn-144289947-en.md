# The Task
Task: improve the accuracy of identifying heavy rain and rainstorms from real-time data.
#   Method
Identification using a similarity comparison method.
- The macro-level object the similarity elements belong to (different regions)
- Which features are selected for similarity comparison
- How the selected features are compared for similarity
- How the selected data is processed for similarity comparison


> Spatio-temporal similarity comparison of rainfall events based on multi-distance fusion: multi-distance fusion.
> [Method] First, by setting a rainfall-proportion threshold, rainfall events are divided — a total of 225 rainfall events in the flood season (June–September) are identified. Then feature elements such as rainfall amount, rainfall duration, rainfall intensity, and rainfall center range are extracted, and rainfall feature distances in three aspects are computed: rainfall element distance, rainfall center distance, and total rainfall distance. Meanwhile, to better integrate the feature distances, principal component analysis is used for distance fusion to compute the weights, producing the final distance, and similarities are ranked according to the computed results.

Existing problems
- Data problem: heavy-rain/rainstorm events are rare, and heavy rainfall has no upper bound, so values vary widely.
- Every similarity computation compares against every historical record, which is expensive.
- Model: whether the way the parameters of each distance are obtained is appropriate (principal component analysis).
- Whether the computation method of each distance is appropriate.
- The selected feature elements must be scientifically sound, chosen as much as possible in directions that could improve the rainstorm recognition rate.
- Corresponding feature distances must be added for different scenarios.
- The assessment of a single rainfall event.


Multi-distance + single core + deep-learning adjustment.

# Reproduction
## Feature Extraction and Distance Computation
## Source of Rainfall Features
- Regions are divided into pixels; each pixel has one rainfall feature.
- Not all pixels can have actually captured rainfall features, so the inverse distance weighting method is needed to fill in the data.

Each element of a matrix represents one pixel.

## Distances
### Total Rainfall Distance

Total rainfall distance between two events = the sum of the squared differences of each element's rainfall.
![在这里插入图片描述](/images/csdn/2024/csdn-144289947/image-001-824d23b8e2.png)

###  Rainfall Center Distance
The top 10% of elements of a rainfall event form the rainfall center.

Rainfall center similarity of two events = the number of overlapping rainfall-center elements of the two events / the total number of elements.
Rainfall center distance of two events = 1 − the rainfall center similarity of the two events.
![在这里插入图片描述](/images/csdn/2024/csdn-144289947/image-002-71f73a6b7b.png)

### Rainfall Element Distance
(1) Rainfall duration T, in hours (h), represents the time element of the rainfall process, counted in whole hours.
 (2) Heavy-rainfall duration Tt, in hours (h), represents the number of hours within the rainfall center range in which the rainfall intensity is greater than 7 mm/h. 
(3) Average rainfall Ra, in mm, represents the average of the rainfall information of all grid points in the event's total rainfall. (4) Maximum rainfall Rm, in mm, represents the average of the rainfall information of the top 10% of grid points in the event's total rainfall. 
(5) Maximum 1 h rainfall intensity I, in mm/h: first compute the average of the rainfall information of all grid points for each hour, then take the maximum among them. 
(6) Maximum rainfall intensity at the rainfall center Ic, in mm/h: first compute the average of the rainfall information within the rainfall center range for each hour, then take the maximum among them.

When computing per event, it may involve how each element's rainfall feature is aggregated into the event's rainfall feature.

The event's rainfall elements are standardized first.

Rainfall element distance between two events = the square root of the sum of the squared differences of their respective six rainfall elements.

## Similarity Measurement and Rating
After computing each distance matrix × its parameter = the comprehensive distance matrix,
the distance to each rainfall event is known; then 1 − each element of that matrix = the similarity matrix.

Then the similarities are graded; the highest is the most similar.
As the category index increases, sample similarity shows an overall decreasing trend; categories with smaller rainfall have similarities concentrated in a higher range, while categories with heavier rainfall have a wider distribution and a lower average, making the similarity evaluation less satisfactory.
