#  Base64 Encoding Reversal

![Image](/images/csdn/2024/csdn-136367715/image-002-5ec56270c2.png)
Base64 encoding is an encoding method used to convert binary data into text strings. It is commonly used to transmit binary data in text protocols, or to store binary data in text files.

When you encounter a very complex function, you can look for the constants used in the function and search for them on a search engine; you may be able to find the relevant source code and then compare it.

    long len;

        res[i+1]=base64_table[(str[j]&0x3)<<4 | (str[j+1]>>4)]; //将第一个字符的后位与第二个字符的前4位进行组合并找到对应的结果字符  
        res[i+2]=base64_table[(str[j+1]&0xf)<<2 | (str[j+2]>>6)]; //将第二个字符的后4位与第三个字符的前2位组合并找出对应的结果字符  
        res[i+3]=base64_table[str[j+2]&0x3f]; //取出第三个字符的后6位并找出结果字符  
    }

    {  
        case 1:  
            res[i-2]='=';  
            res[i-1]='=';  
            break;  
        case 2:  
            res[i-1]='=';  
            break;  
    }  
  
    return res;  
}

# IDA Dynamic Debugging IDA 8.3
We can use dynamic debugging to learn certain values or how they change, and we can also guess a function's purpose by observing how related values change before and after the function.

Running IDA on a Windows machine can directly debug exe files dynamically, but cannot debug elf files.
If you need to debug an elf file, you need to choose remote debugging.
