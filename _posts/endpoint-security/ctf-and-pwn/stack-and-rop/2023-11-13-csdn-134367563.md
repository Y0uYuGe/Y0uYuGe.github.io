# Introduction
An overflow means the number of bytes written into a variable exceeds the number of bytes the variable itself requested, causing the values of adjacent variables to be changed.
## Categories
Stack overflow, BSS overflow, heap overflow, etc.

# Techniques
## Dangerous functions
### Input
The gets() function reads a string from the standard input device (keyboard) until a newline; the newline is discarded, and a '\0' character is appended at the end. Its call format is: gets(s); where s is a string variable (a string array name or a string pointer).

scanf formatted input with the %s parameter
[An expert's view on scanf](https://blog.csdn.net/qq_54218833/article/details/121308367)

int vscanf ( const char * format, va_list arg );
Reads formatted data into a variable argument list
Reads data from standard input (stdin) and stores it, according to the format argument, into the locations pointed to by the elements of the variable argument list identified by arg.
Internally, the function retrieves arguments from the list identified by arg as if va_arg were used, so the state of arg is likely changed by the call.
In any case, arg should be initialized by va_start at some point before the call and is expected to be released by va_end at some point after the call.
### Output
sprintf is equivalent to fprintf(), except that its output is written to an array instead of a stream. A null character must be appended at the end of the written string

### Strings
strlen: computes the length of a string up to, but not including, the null terminator.
strcpy: string copy; stops at '\x00'
strcat: string concatenation; stops at '\x00'
bcopy: the bcopy() function does not check for null bytes (NULL) in the string
[Related knowledge about bcopy](https://blog.csdn.net/youbang321/article/details/7826333)

Overwrite the contents of some variable on the stack — this requires more precise calculation.
