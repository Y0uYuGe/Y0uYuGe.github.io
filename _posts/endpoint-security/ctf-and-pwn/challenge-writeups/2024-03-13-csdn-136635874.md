# AE64
[AE64](https://github.com/veritas501/ae64)

> AE64 is a tool which can transform any amd64 architecture shellcode into pure alphanumeric shellcode using self-modify code technology, so the page need to be writable.


- For 64-bit
- The original shellcode is allowed to contain null bytes
- Parameter passing when generating with ae64

```python
obj=AE64()
shellcode=(obj.encode(asm(shellcode),strategy="small",offset=0x34,register="rax"))
```
- The first parameter is the machine code of the shellcode, which may contain null bytes
- The second parameter, small, means generating as little shellcode as possible
- register is the register whose value, at the moment the first instruction of this shellcode is about to execute, plus offset equals the address of the shellcode's first instruction

# Reducing Shellcode Length
- Depending on the situation, you can avoid using 64-bit registers and use 32-bit registers instead
- Pay attention to whether any registers are still usable after a function finishes executing; for example, the third argument of read() remains unchanged after execution, so write can use it directly

# Bug
If there is no instruction after jnz loop_write and it is directly followed by the characters of flag, it somehow jumps to a strange place for no apparent reason, but adding any instruction such as pop rax makes the jump work normally
