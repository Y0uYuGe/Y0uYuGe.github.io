# View the Current Linking
```bash
ldd 可执行文件名
```
![Image](/images/csdn/2023/csdn-134234465/image-001-029b89d32b.png)
Ignore the first line
The second line is libc; libc is the C standard library
The third line is ld; ld is the dynamic linker

# Use patchelf to Modify libc and ld

```bash
patchelf --set-interpreter 新的ld文件的路径 当前程序名
```

``![Image](/images/csdn/2023/csdn-134234465/image-006-0fae858d96.png)
ld has been modified
![Image](/images/csdn/2023/csdn-134234465/image-007-fde4f7a674.png)

```bash
patchelf --replace-needed 原来第二行的==>前的libc名 新的libc文件的路径
```

![Image](/images/csdn/2023/csdn-134234465/image-008-79f0f47da8.png)
libc has been modified
