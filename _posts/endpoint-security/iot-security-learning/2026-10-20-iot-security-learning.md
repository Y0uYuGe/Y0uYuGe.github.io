## Overview

IoT_Security_Learning is a small starting-point collection for studying embedded and IoT security. Its README currently links to an IoT security tutorial, heterogeneous PWN practice material, a separate collection of learning records, and an IoT penetration-testing book translation.

## Use the collection

Open the [repository README](https://github.com/Y0uYuGe/IoT_Security_Learning#readme), choose a resource, and follow that resource's own setup instructions and prerequisites. The linked materials belong to their respective authors and retain their own licensing and maintenance status.

## Current scope

The current repository is a **README-based resource index**. Tutorials, exercises, and book material live in the linked projects.
