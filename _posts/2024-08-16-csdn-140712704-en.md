### Exploitation
Here, the input of `scanf("%lu%u", &addr, &offset)` can be split by a non-digit character (newline)

Then we can exploit the moment when it reads a character from the buffer to determine the sign: replace the sign character with the flag character being written. Then the next time scanf is called, it will read a character (the input character) from the stdin buffer and compare it with the written flag character. If it matches, the character is put into the current character buffer, and it continues taking from the stdin buffer (if there's nothing there it waits for user input, since it reads the buffer one byte at a time). If it doesn't match, it proceeds with the later digit-character reading.

We changed the character being checked, but the problem is that `__strtoull_internal` converts the string into a number and also has conversion rules for the corresponding signs
> Through source-level debugging with other versions, determine the position corresponding to the given version's IDA decompilation and the source paths of the related functions

`stdlib/strtol_l.c` first checks the first character, then converts the remaining characters into the corresponding digits, and finally determines the sign based on the earlier sign. If the first character check finds nothing suitable and the later conversion finds no corresponding digit either, it breaks and returns 0

```bash
.text:000000000011B2C4 8B 7C 24 08     mov     edi, dword ptr [rsp+28h+fd] ; fd
```

1. 8B: This is the opcode of the MOV instruction
   - 8B indicates a 32-bit move from memory to a register

2. 7C: This is the ModR/M byte
   - 7 = 111b: indicates using the [register + offset] addressing mode
   - C = 1100b: 
     - 11b: indicates the destination operand is a register
     - 00b: indicates the destination register is EDI (000 corresponds to EAX, 001 corresponds to ECX, ..., 111 corresponds to EDI)

3. 24: This is the SIB (Scale-Index-Base) byte
   - 2 = 00 10b:
     - 00b: scale factor is 1
     - 10b: index register is ESP (100)
   - 4 = 100b: base register is ESP/RSP (100)

4. 08: This is an 8-bit displacement
   - Indicates the offset relative to RSP is 8 bytes

Explanation:
- The MOV instruction is used for data movement
- The destination operand is the EDI register
- The source operand is a memory location, specified by [RSP + 8]
- The SIB byte is used because the base register is ESP/RSP

Notes:
1. In 64-bit mode, even if the operand is 32-bit, address calculation still uses 64-bit registers (here RSP)
2. The [rsp+28h+fd] in the original disassembly was optimized to [rsp+8] after compilation, probably because the compiler rearranged the stack frame layout

So here we just change the 08 byte so that [rsp+8] is zero

```bash
.text:000000000011B284 80 3D B5 B2 0E 00 00  cmp     cs:__libc_single_threaded, 0
```

1. **80**: This is the opcode, representing the `cmp` instruction. `cmp` is a comparison instruction used to compare two operands.

2. **3D**: This is the ModR/M byte of the `cmp` instruction, indicating that an immediate value is compared with the value at a memory address.

3. **B5 B2 0E 00 **: These four bytes represent the offset of the memory address. In this instruction, the memory address is an offset relative to the location of the current instruction. This is a 32-bit little-endian address (low bytes first, high bytes last), corresponding to the offset `0x000EB2B5`.

4. **00**: This is the immediate value to compare, meaning comparison with 0.

The value of __libc_single_threaded seems to default to 1; here we change the immediate value to 1

static zend_never_inline void *zend_mm_alloc_small_slow(zend_mm_heap *heap, uint32_t bin_num ZEND_FILE_LINE_DC ZEND_FILE_LINE_ORIG_DC)
{
	zend_mm_chunk *chunk;
	int page_num;
	zend_mm_bin *bin;
	zend_mm_free_slot *p, *end;

	bin = (zend_mm_bin*)zend_mm_alloc_pages(heap, bin_pages[bin_num] ZEND_FILE_LINE_RELAY_CC ZEND_FILE_LINE_ORIG_RELAY_CC);

	if (UNEXPECTED(bin == NULL)) {
		/* insufficient memory */
		return NULL;
	}

	chunk = (zend_mm_chunk*)ZEND_MM_ALIGNED_BASE(bin, ZEND_MM_CHUNK_SIZE);
	page_num = ZEND_MM_ALIGNED_OFFSET(bin, ZEND_MM_CHUNK_SIZE) / ZEND_MM_PAGE_SIZE;
	chunk->map[page_num] = ZEND_MM_SRUN(bin_num);
	if (bin_pages[bin_num] > 1) {
		uint32_t i = 1;

		do {
			chunk->map[page_num+i] = ZEND_MM_NRUN(bin_num, i);
			i++;
		} while (i < bin_pages[bin_num]);
	}

	/* create a linked list of elements from 1 to last */
	end = (zend_mm_free_slot*)((char*)bin + (bin_data_size[bin_num] * (bin_elements[bin_num] - 1)));
	heap->free_slot[bin_num] = p = (zend_mm_free_slot*)((char*)bin + bin_data_size[bin_num]);
	do {
		p->next_free_slot = (zend_mm_free_slot*)((char*)p + bin_data_size[bin_num]);
		p = (zend_mm_free_slot*)((char*)p + bin_data_size[bin_num]);
	} while (p != end);

	/* terminate list using NULL */
	p->next_free_slot = NULL;

	/* return first element */
	return bin;
}
