# Gradient Descent

Current parameters − the derivative of the loss function with respect to the parameters = new parameters; the new parameters move in the direction that decreases the loss function.

# Mini-Batch Gradient Descent
 
![Image](/images/csdn/2024/csdn-144621635/image-004-8b8018f2a1.png)

Mini-batch gradient descent: each iteration selects a subset of the data to compute the loss and perform gradient descent.
Stochastic gradient descent: randomly selects data to compute the loss and perform gradient descent.
![Image](/images/csdn/2024/csdn-144621635/image-005-af16b39a26.png)

## Multiple Training Epochs 
Each epoch performs gradient descent with each batch of data in turn, repeated for many epochs.
