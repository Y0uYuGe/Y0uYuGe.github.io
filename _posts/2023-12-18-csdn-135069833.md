## CPU Internal Single-Bus Approach
 At any one moment, a bus can only support data exchange between one pair of components
![Image](/images/csdn/2023/csdn-135069833/image-002-d01a9fdcc4.png)

Connecting the in and out lines of the CPU and each register controls whether it inputs or outputs
Y and the ALU have a dedicated data path

Every clock cycle the CU issues a set of control signals to implement a micro-operation
