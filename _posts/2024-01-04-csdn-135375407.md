# System Bus Standards
ISA and EISA are both parallel buses
![Image](/images/csdn/2024/csdn-135375407/image-004-b6f8d31a38.png)
Intel proposed the FSB bus standard, faster than EISA and ISA, and later proposed the QPI bus standard, faster still than FSB
# Local Bus Standards
Greater bandwidth is needed to transmit image data
VESA is also a parallel bus. Since VESA's operating frequency has a fixed upper limit (parallel frequencies cannot be too high), and the local bus is controlled by the CPU, VESA could not keep up as CPU operating frequencies grew higher and higher
![Image](/images/csdn/2024/csdn-135375407/image-005-883c05e0d1.png)
Intel proposed PCI, which is much faster than VESA. It is controlled by the northbridge chip, not attached to the CPU and not controlled by the CPU, so it adapts better to CPU development
PCI has also been used as a system bus, so calling it a system bus is fine too
![Image](/images/csdn/2024/csdn-135375407/image-006-181701fe47.png)
Intel proposed AGP, also to accommodate image transmission; it is divided into X1 and X8 classes
![Image](/images/csdn/2024/csdn-135375407/image-007-e25181108b.png)
Intel proposed PCI-E, a serial bus with a high operating frequency and therefore high bandwidth
A single PCI-E lane can serve as a bus; unlike the earlier parallel buses, it does not need many wires, saving space. Since one PCI-E lane can serve as a bus, providing each device with its own bus for independent data transmission does not take much space either

Full duplex: both sides can send to each other at the same time

Hot-pluggable: as long as the standard is followed, you can plug it directly into the port and use it
![Image](/images/csdn/2024/csdn-135375407/image-008-d162ae5db0.png)

# Why Serial Buses Replaced Parallel Buses
Because parallel buses usually use synchronous timing, if there is a length difference between wires, the signals do not arrive at the same time; but synchronous timing requires the data to be received within a specified clock cycle, so a bit that should have been received as 1 may be read as 0 because it did not arrive in time

The group of data a serial bus transmits over one wire corresponds to the group of data a parallel bus transmits across all its wires
