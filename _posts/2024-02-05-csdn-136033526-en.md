# Related Knowledge
## Directory Structure
The Linux file system is a tree-shaped hierarchical structure, as shown in the figure below; the most important part is the root directory (/).
![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-001-2e8841c03a.png)
The Linux command line is also called the terminal; in the command line, only the keyboard is used.

After opening the command line, you can see the current user and the current directory.


root refers to the username, ~ is the user's home directory; you can use pwd to view the current directory.
![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-002-a4b1286d12.png)
## Entering a Directory

The command to switch directories is cd; for example, to switch to the root directory: cd /; after entering it, press Enter to execute the command.
![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-003-52146af69b.png)
In Linux, paths are also divided into absolute paths and relative paths. An absolute path is calculated starting from the root directory, while a relative path is calculated starting from the current directory.
For example: switching to the /root/os/linux-0.11-lab directory while currently in the /root directory.
There are two ways to switch directories. One is through a relative path: switch with the current directory as the starting point.
![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-004-b20455b43a.png)
The other is through an absolute path: switch with the root directory as the starting point.
![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-005-ec2341d562.png)

The usage of cd is summarized below:

```bash
cd 进入用户主目录；
cd ~ 进入用户主目录；
cd - 返回进入此目录之前所在的目录；
cd .. 返回上级目录(若当前目录为”/“，则执行完后还在”/“；”..”为上级目录的意思)；
cd ../.. 返回上两级目录；
cd !$ 把上个命令的参数作为cd参数使用。
```

## Supplement
There are so many commands in the command line that it is definitely impossible to remember them all, so command completion is a very handy helper; when you can't remember a command or a path completely, just press the Tab key twice and the currently available options will appear — it is simply the best helper.

For example: if you can't remember a path completely, you can press Tab twice to see which directories are available.
(Note: since directories are also treated as files in Linux, switching into a file without knowing it will cause an error.)
![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-006-914325a58b.png)

## Viewing Directories
After entering a directory, use the ls command to view the contents of the current directory.
Available parameters of the ls command:

- --l displays file and directory information in long format, including permissions, owner, size, creation time, etc.; number of links, owner, group, file size, and the last modification time of the file, etc.;
- -a: displays all files and folders (including hidden files/folders).

ll lists all the file information under that directory, including hidden files, while ls -l only lists non-hidden files; these two commands are not equivalent.
![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-007-4ab53779e3.png)

If you add a path after it, you can view the files under the specified path without having to switch to that path first.

![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-008-7ad4027dbf.png)

## Creating Files
The common command for creating files in Linux is touch; the command format is as follows:

```bash
touch filename
```

Sometimes you may need to create an empty file. In this case, you can use the touch command to easily create an empty file.

For example: to create a new file testfile, you can use the following command.

```bash
touch testfile
```

![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-009-17e36e86a4.png)


If you want to create multiple files at the same time, you can also use the touch command; the specific format is as follows:

touch file1 file2 ...

Just separate the different file names with spaces to create multiple files.

## Deleting Files
The commonly used command for deleting files in Linux is rm; the usage format is as follows:

```bash
rm [命令选项] filename
```

Common command options:

-  -f: forcibly delete files;
 - -r or -R: recursive processing — process all files and subdirectories under the specified directory together;
-  -i: ask the user before deleting an existing file.
For example, to delete the file testfile we just created, you can use the following command.

```bash
rm  -f testfile
```

![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-010-96f762212a.png)
## Creating Folders
The command for creating folders in Linux is mkdir; the command format is as follows:

```bash
mkdir [命令选项] dirname
```

Common command options: -p or --parents: if the parent directory of the directory to be created does not yet exist, the parent directory will be created together;
![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-011-a6adae5224.png)
For example: to create a new folder testdir, you can use the following command.

```bash
mkdir testdir
```
Because the newly created folder is an empty folder, the result displayed by ls -l is empty.
![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-012-4e58d913bc.png)

## Deleting Folders
The commands for deleting folders in Linux are rmdir or rm -r; the command format is as follows:

```bash
rmdir [命令选项] dirname
```

Common command options: -p or --parents: after deleting the specified directory, if its parent directory has become an empty directory, delete it as well;
![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-013-5345b8a5f7.png)

For example: to delete the folder testdir just created, you can use the following command.

```bash

rmdir testdir
```




## Copying Files and Folders
Linux uses the cp command to copy one or more source files or directories to a specified directory; the command format is as follows:

```bash
cp [命令选项] 源文件 目的文件
```

Common command options:

- -f: forcibly copy the file, regardless of whether the target file already exists;
- -i: ask the user before overwriting an existing file;
- -p: preserve the attributes of the source file or directory;
- -R/r: recursive processing — process all files and subdirectories under the specified directory together. If you want to copy a directory, you need to use this option.

For example: create a new file newfile and a new folder newdir, and copy newfile into the newdir directory. The specific commands are as follows.

```bash
touch newfile
mkdir newdir
cp newfile newdir
```
![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-014-cd3fcd3d48.png)



## Moving/Renaming Files and Folders
Linux uses the mv command to rename a file or directory, or to move a file from one directory to another; the command format is as follows:

```bash
mv [命令选项] 源文件 目标文件
```

Common command options:

- -f: if the source directory or file to be moved has the same name as the target directory or file, it will directly overwrite the old file without asking;
- -i: if the source directory or file to be moved has the same name as the target directory or file, it will first ask whether to overwrite the old file; enter y to overwrite directly, and enter n to cancel the operation.
![在这里插入图片描述](/images/csdn/2024/csdn-136033526/image-015-b907457ddc.png)


For example: create a new file newfile and a new folder newdir, move newfile into the newdir directory, and rename it to newfileCpy. (If the target file does not contain a path, the source file is renamed directly; with a path, it is moved and then renamed.) The specific commands are as follows.

```bash
touch newfile
mkdir newdir
mv newfile newdir/ikun
```
