# Related Knowledge
## Introduction to apache2
![Image](/images/csdn/2024/csdn-135709202/image-001-93cab7af7d.png)

The Apache HTTP Server Project is dedicated to developing and maintaining an open-source HTTP server for modern operating systems (including UNIX and Windows). The project's goal is to provide a secure, efficient, and extensible server that delivers HTTP services in sync with current HTTP standards.

The Apache Software Foundation and the Apache HTTP Server Project announced the release of Apache HTTP Server ("httpd") version 2.4.48 on June 1, 2021. There are two names for the Apache HTTP server: one is httpd, the other is apache2. In fact, both are the same software for **different distributions of different operating systems**. For example, in RHEL 6.2 it is called httpd, while in Ubuntu it is called apache2.

**Note: the directives used in the apache2 and httpd configuration files and the directory structures are slightly different**

## Analysis of the apache2 Configuration File Directory
The apache2 configuration files are under the /etc/apache2 directory. The main configuration file is apache2.conf

![Image](/images/csdn/2024/csdn-135709202/image-008-2acc34dec7.png)
Open the file to view it
![Image](/images/csdn/2024/csdn-135709202/image-009-41ffefa875.png)
It contains

```markup
# It is split into several files forming the configuration hierarchy outlined 
# below, all located in the /etc/apache2/ directory:(apache2的配置功能分成了多个文件，形成如下的配置层次结构)
#
#       /etc/apache2/
#       |-- apache2.conf
#       |       `--  ports.conf
#       |-- mods-enabled
#       |       |-- *.load
#       |       `-- *.conf
#       |-- conf-enabled
#       |       `-- *.conf
#       `-- sites-enabled
#               `-- *.conf
```
- apache2.conf: the main configuration file
- port.conf: customize the ports apache2 listens on
- conf-enabled: configuration files already enabled on the apache2 server
- conf-available: configuration files that the apache2 server can enable
- mods-enabled: module configuration files already enabled on the apache2 server
- mods-available: module configuration files available to the apache2 server
- sites-enabled: website configuration files currently in use by apache2
- sites-available: website configuration files available to apache2.

[You can refer to the official Apache HTTP Server documentation](https://httpd.apache.org/docs/2.4/)

What should we do if we need to change the website's root directory? The website root directory can be configured in the configuration file.
- sites-enabled: website configuration files currently in use by apache2

Locate the file /etc/apache2/sites-enabled/000-default.conf
![Image](/images/csdn/2024/csdn-135709202/image-014-870d4f543f.png)

This file configures the default page, and its content is as follows:

```powershell
<VirtualHost *:80>
    # The ServerName directive sets the request scheme, hostname and port that
    # the server uses to identify itself. This is used when creating
    # redirection URLs. In the context of virtual hosts, the ServerName
    # specifies what hostname must appear in the request's Host: header to
    # match this virtual host. For the default virtual host (this file) this
    # value is not decisive as it is used as a last resort host regardless.
    # However, you must set it for any further virtual host explicitly.
    #ServerName www.example.com
    ServerAdmin webmaster@localhost
    DocumentRoot /var/www/html
    # Available loglevels: trace8, ..., trace1, debug, info, notice, warn,
    # error, crit, alert, emerg.
    # It is also possible to configure the loglevel for particular
    # modules, e.g.
    #LogLevel info ssl:warn
    ErrorLog ${APACHE_LOG_DIR}/error.log
    CustomLog ${APACHE_LOG_DIR}/access.log combined
    # For most configuration files from conf-available/, which are
    # enabled or disabled at a global level, it is possible to
    # include a line for only one particular virtual host. For example the
    # following line enables the CGI configuration for this host only
    # after it has been globally disabled with "a2disconf".
    #Include conf-available/serve-cgi-bin.conf
</VirtualHost>
```

Content after "# " is comment explanation.

- <VirtualHost *:80>: VirtualHost represents a virtual host, and 80 means listening on port 80.
- DocumentRoot /var/www/html: DocumentRoot specifies the root directory of this virtual host, currently /var/www/html
- ErrorLog ${APACHE_LOG_DIR}/error.log defines the error log path
- CustomLog ${APACHE_LOG_DIR}/access.log defines the access log path

If you need to change the website root directory, for example switch to /var/www/html/site1/

```powershell

mv /var/www/html/hello.html /var/www/html/site1/
```

## Changing the apache2 Listening Port
In some scenarios, we need to change the port apache2 listens on

This can be achieved by modifying the /etc/apache2/port.conf and /etc/apache2/sites-enabled/000-default.conf configuration files.

View the contents of the /etc/apache2/ports.conf file:


```markup
# If you just change the port or add more ports here, you will likely also
# have to change the VirtualHost statement in
# /etc/apache2/sites-enabled/000-default.conf
Listen 80
<IfModule ssl_module>
        Listen 443
</IfModule>
<IfModule mod_gnutls.c>
        Listen 443
</IfModule>
# vim: syntax=apache ts=4 sw=4 sts=4 sr noet
```

- Listen 80 indicates listening on port 80

After changing it to port 81, edit /etc/apache2/sites-enabled/000-default.conf and change <VirtualHost *:80> on the first line to <VirtualHost *:81>

Restart apache2 after the modification

```powershell
service apache2 restart
```

Check the port status: **netstat -antp**
![Image](/images/csdn/2024/csdn-135709202/image-024-f1988e3499.png)

You can see the port has been switched. When accessing with a browser, you need to access port 81: http://localhost:81/hello.html
![Image](/images/csdn/2024/csdn-135709202/image-025-61e833e81e.png)


## apache2 Listening on Multiple Ports
In some cases, we need to open multiple ports, where each port corresponds to a site, and each site has a different website root directory. How should apache2 be configured in this situation?

First edit /etc/apache2/ports.conf and add:

listen 8080

As shown in the figure:

![image-20210702155517787](/images/csdn/2024/csdn-135709202/image-026-2fc50089ed.png)


After restarting the apache2 service at this point, you can see the port is already being listened on.

![Image](/images/csdn/2024/csdn-135709202/image-027-031d0d9144.png)
Accessing port 8080 is equivalent to accessing a new site, but since the website root directory has not been set yet, when visiting http://localhost:8080/ you will see apache2's default index page. Next we set up the corresponding directory. (At this point the site directory of 8080 is the same as the initial default, /var/www/html/, because the conf files in /etc/apache2/sites-enabled/ only set the root directory for port 81)
![Image](/images/csdn/2024/csdn-135709202/image-028-dd26b8d7ce.png)


![Image](/images/csdn/2024/csdn-135709202/image-029-b0ca41d645.png)


Switch to the directory /etc/apache2/sites-enabled/

```powershell

cd /etc/apache2/sites-enabled/
```

Copy 000-default.conf, with any name, for example: 8080.conf

```markup

<VirtualHost *:8080>
        # The ServerName directive sets the request scheme, hostname and port that
        # the server uses to identify itself. This is used when creating
        # redirection URLs. In the context of virtual hosts, the ServerName
        # specifies what hostname must appear in the request's Host: header to
        # match this virtual host. For the default virtual host (this file) this
        # value is not decisive as it is used as a last resort host regardless.
        # However, you must set it for any further virtual host explicitly.
        #ServerName www.example.com
        ServerAdmin webmaster@localhost
        DocumentRoot /var/www/html/site2
        # Available loglevels: trace8, ..., trace1, debug, info, notice, warn,
        # error, crit, alert, emerg.
        # It is also possible to configure the loglevel for particular
        # modules, e.g.
        #LogLevel info ssl:warn
        ErrorLog ${APACHE_LOG_DIR}/error.log
        CustomLog ${APACHE_LOG_DIR}/access.log combined
        # For most configuration files from conf-available/, which are
        # enabled or disabled at a global level, it is possible to
        # include a line for only one particular virtual host. For example the
        # following line enables the CGI configuration for this host only
        # after it has been globally disabled with "a2disconf".
        #Include conf-available/serve-cgi-bin.conf
</VirtualHost>
# vim: syntax=apache ts=4 sw=4 sts=4 sr noet
```

Set DocumentRoot to: /var/www/html/site2
![Image](/images/csdn/2024/csdn-135709202/image-030-b5f0ad42af.png)


Then create the /var/www/html/site2 directory, create index.html in it, and write

```html
<html>
    <h1>
        site 2
    </h1>
</html>
```

Restart the apache2 service and visit http://localhost:8080/index.html
![Image](/images/csdn/2024/csdn-135709202/image-031-6524d60ac4.png)
Remember that after each modification, you need to restart apache2 for it to take effect
![Image](/images/csdn/2024/csdn-135709202/image-032-8eab751498.png)
