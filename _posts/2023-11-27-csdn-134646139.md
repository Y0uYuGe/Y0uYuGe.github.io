# Paged Storage
Place the program scattered across different blocks of main memory
![Image](/images/csdn/2023/csdn-134646139/image-001-6cd494d0f8.png)

# Virtual Address vs Physical Address
The operating system maps logical addresses to physical addresses in main memory blocks; the offset within the block of the corresponding physical address is the page offset of the logical address, and the block number is converted from the logical page number via the page table.
![Image](/images/csdn/2023/csdn-134646139/image-002-d3084854a1.png)
# Page Table: Logical Page -> Main Memory Block Number
 ![Image](/images/csdn/2023/csdn-134646139/image-003-3a1daa88d9.png)
# Address Translation Process
First, using the page number of the logical address and the base address of the page table in memory obtained from the page table base register, get the corresponding page table entry, then obtain the main memory block number, and combine it with the page offset of the logical address to get the physical address.
When reading or writing an address in main memory, the Cache is searched first
When accessing the page table, page table entries can be placed into the TLB (similar to Cache) based on the principle of locality, thereby improving the speed of address translation

![Image](/images/csdn/2023/csdn-134646139/image-004-1acf559b75.png)
# Address Translation Process (With TLB Added)
Cache and the TLB are similar: both are SRAM, faster than DRAM (main memory). And both have replacement policies when full
Both Cache and the TLB mainly serve to reduce the number of memory accesses, but the size and units of what they store differ.
