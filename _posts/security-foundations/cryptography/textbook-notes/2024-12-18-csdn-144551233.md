# Background
### The Problem:
Asymmetric encryption schemes such as RSA and ElGamal require exponentiation in integer rings and fields, with parameters usually exceeding 1000 bits. This leads to the following problems:
- **High computational cost**: On CPUs with 32-bit or 64-bit arithmetic, these operations are very time-consuming.
- **Large parameter sizes**: For small devices and embedded systems, storing these large parameters is a challenge.

### Motivation:
We hope to find smaller field sizes that provide equivalent security, reducing computation and storage requirements.

### Solution:
Elliptic curve cryptography (ECC) uses a set of points (rather than integers) for encryption operations, with coefficient sizes of 160-256 bits, significantly reducing computational overhead.
