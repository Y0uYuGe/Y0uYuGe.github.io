## Competition record

This repository is CloudEver Team's public overview for the second Tencent Cloud intelligent penetration-testing competition. Its README introduces the team effort and links the TPT-Agent and RedCortex projects, which explore Agent-assisted security workflows and multi-agent coordination.

The overview explicitly credits the projects as work designed and developed together by four team members. It provides context and shared attribution for both implementations.
