## Team project

RedCortex is a CloudEver Team project developed collaboratively for authorized CTF, laboratory, and competition environments. Its architecture combines a fixed workflow graph with an Agent that chooses the next stage, specialist Agents, and persistent task memory in `topology.md` and per-node Markdown files. This portfolio record credits the collaborative team.

## Implementation and entry point

The repository includes a Python orchestration layer, a FastAPI interface, Docker/MCP sandbox integration, task-state persistence, and tests. The web interface exposes workflow state and task artifacts. See the [README](https://github.com/CloudEver-Team/RedCortex#readme) for architecture, prerequisites, and setup; it documents Python 3.12+ and scope controls for authorized assets.

The README notes that a top-level `LICENSE` file has not yet been provided.
