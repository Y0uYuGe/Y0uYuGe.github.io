# Classification of Sorting Algorithms
Internal sorting: the data to be sorted is placed in memory, and written back to disk after sorting
External sorting: the data cannot all fit into memory at once for sorting; it must be processed in many passes. Each pass reads from disk, sorts, then writes back, and additional handling is needed, because each pass only sorts part of the data — merging the different parts together may not work directly
