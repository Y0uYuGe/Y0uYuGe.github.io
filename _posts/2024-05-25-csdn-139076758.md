# Goal
After pivot_root switches the working directory to /merged, save the filesystem of the working directory at that moment through docker commit, using a tar package to pack this filesystem into a tar file
The command is similar to ` ./mydocker commit myimage`, and then myimage.tar will be obtained in the current directory

# Note
- The commit operation is executed in another terminal, which means the container has already been started and is running. When executing the commit operation in another terminal at this point, there is no need to mount or start a child process again — it directly sets a location to store things, rather than getting the specific working directory address after a union mount as before

#  exec.Command

```python
exec.Command("tar", "-czf", imageTar, "-C", mntPath, ".").CombinedOutput()
```

This code uses Go's standard library `os/exec` to execute an external command — specifically, calling the `tar` command to create a compressed archive file. Here is a part-by-part explanation:

- `exec.Command`: This is the object used in Go to create and run an external command. It accepts a variable number of string arguments; the first argument is the command name, and the subsequent arguments are the options and parameters passed to that command.

- `"tar"`: This is the command itself. `tar` is a tool for creating, reading, updating, and managing archive files.

- `"-czf"`: These are the options passed to the `tar` command.
  - `-c` means creating a new archive file. This means you use the tar command to package a series of files and directories in the current directory into a single archive file (usually ending in .tar). This process does not compress the files; it simply collects them together into an archive file for easy management and transfer.
  - `-z` means applying gzip compression when creating the archive file. Combined with `-c`, this creates a compressed archive file in `.tar.gz` format.
  - `-f` is followed by the name of the archive file. Note that since `-f` needs to be directly followed by the file name, in the argument list, the `imageTar` variable will serve as the value of this option.

- `imageTar`: This is a variable representing the name (including the path) of the archive file to be created. For example, if the value of `imageTar` is `/path/to/image.tar.gz`, then this archive file will be created at the specified path and named `image.tar.gz`.

- `"-C"`: This option tells `tar` to switch to the specified directory before performing the operation. The specified directory here is determined by the argument that follows.

- `mntPath`: This is also a variable, representing a directory path. Combined with the `-C` option, it specifies the directory that `tar` should switch to before performing the operation. For example, if the value of `mntPath` is `/mnt/mydir`, then that directory will be entered before the packaging operation is performed.

- `"."`: This is a dot character representing the current directory. In the context of the `tar` command, it means packaging everything under the current directory. Since a directory was previously specified with `-C`, the "current directory" here is the directory pointed to by `mntPath`.

- `.CombinedOutput()`: This method executes the command constructed above and captures the combined output of its standard output and standard error. What is returned is a byte slice containing the output text after the command executes. This is very useful in debugging or scenarios where you need to handle command output.

In summary, the function of this code is: in a Go program, execute a command that uses the `tar` tool to package everything under the `mntPath` directory into a gzip-compressed archive file, saved at the path and file name specified by the `imageTar` variable.


# tar

- `tar`: Short for tape archive, it is a tool for creating, extracting, and viewing tarballs (.tar files).
- The `-t` option: means listing the contents inside a tar file. When you use the `-t` option on a .tar file, the tar command outputs a list of all files and directories in that archive file, but does not decompress or extract them.
- The `-f` option: followed by the name of the tar file to operate on. `-f` is short for file and is used to specify the archive file to process.

So, when you run the `tar -tf somefile.tar` command, it lists all the files and directory structures inside the `somefile.tar` archive, one item per line, but does not expand or extract the actual contents of this archive file. This is very useful for quickly checking what a tar file contains without actually extracting it.
