# The Operating System Boot Process


BIOS: basic input ouput system

At power-on, the CPU first goes to main memory to execute the boot program in ROM. This boot program has the CPU read the disk's Master Boot Record into memory, then executes the disk boot program according to the partition table. At this point it finds the C drive and reads the C drive's boot record (PBR) into memory, then executes this boot record to find the boot manager. At this point the boot manager is found from the root directory and read into memory, and the CPU then executes the boot manager
