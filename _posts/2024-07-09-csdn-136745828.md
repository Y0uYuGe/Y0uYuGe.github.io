# Script writing
Intel and AT&T are two different assembly language syntax styles, mainly used on x86-architecture processors. Although both are used to write low-level machine code, they differ significantly in syntax, especially in operand order and in the expression of certain details. The differences between the two are explained in detail below:

### Intel Syntax

Intel syntax is the most common x86 assembly language syntax and is also the syntax recommended in Intel's official documentation. Its characteristic is that operands appear before the instruction... more precisely, the "destination operand" is usually placed first and the "source operand" is placed after it.

#### Characteristics:
- Destination operand first, source operand last.
- Register names have no prefix.
- Curly braces `{}` are used to denote the range of an immediate value, for example `mov eax, {0x1234}` (although this is not the most common form; we usually write `mov eax, 0x1234`).

#### Examples:
```assembly
; Intel Syntax
mov eax, ebx    ; 将ebx的值移动到eax
add eax, 1      ; 将eax的值加1
```

### AT&T Syntax

AT&T syntax originated from UNIX systems and was developed by AT&T. Its main differences from Intel syntax are the reversed operand order and the percent sign `%` prepended to register names.

#### Characteristics:
- Source operand first, destination operand last.
- Register names are prefixed with a percent sign `%`.
- Immediate values are usually explicitly indicated in the operand, with no special curly-brace notation.

#### Examples:
```assembly
# AT&T Syntax
movl %ebx, %eax    # 将ebx的值移动到eax
addl $1, %eax      # 将eax的值加1
```

### Comparison summary

|          | Intel Syntax                          | AT&T Syntax                            |
|----------|---------------------------------------|----------------------------------------|
| Operand order | Destination operand first, source operand last         | Source operand first, destination operand last          |
| Register notation | No prefix                              | Percent-sign `%` prefix                   |
| Immediate marker | Usually no special marker                        | Explicitly indicated, e.g. `$1` represents the immediate value 1       |


## asm assembly in the C library
By default it follows AT&T Syntax. If you want to use

```c
  __asm__("mov user_cs, cs;"
            "mov user_ss, ss;"
            "mov user_sp, rsp;"
            "pushf;"
            "pop user_rflags;");
```
you need to add `-masm=intel`, otherwise it follows

```c
  asm(
            "movq %%cs, %0\n\t"
            "movq %%ss, %1\n\t"
            "movq %%rsp, %2\n\t"
            "pushfq\n\t"
            "popq %3\n\t"
            : "=r" (user_cs), "=r" (user_ss), "=r" (user_sp), "=r" (user_rflags)
            :
            : "memory");
```
