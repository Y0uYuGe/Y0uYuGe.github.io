# mcmf

### Structure Definition

The basic idea of the chained forward star is to maintain a linked list for each vertex in the graph, where each node in the list represents an edge starting from that vertex, and the node typically stores the target vertex number and the edge weight (if any). This way, the adjacent vertices of each vertex can be quickly accessed by traversing the linked list.

Taking C++ as an example, a simple chained forward star node definition might look like this:

```cpp
struct Edge {
    int to;      // 目标顶点编号
    int weight;  // 边的权值，可选，对于无权图可以忽略
    int next;    // 指向下一条边的指针，构成链表
};
```

At the same time, an array (or vector) is needed to record the position of the head node of each vertex's linked list, plus a global edge array (or vector) to store all edge information.

```cpp
const int MAXN = 100005; // 最大顶点数
Edge edge[MAXN << 1];   // 存储边，大小预估为最大顶点数的两倍，防止重边时越界
int head[MAXN], edgeCount; // head[i]表示第i个顶点的链表头指针，edgeCount记录当前边的数量

// 初始化
void init() {
    memset(head, -1, sizeof(head)); // 初始时，每个顶点的链表头指针都设为-1
    edgeCount = 0;
}
```

### Adding Edges

To add an edge from `from` to `to`, you can do it like this:

```cpp
void addEdge(int from, int to, int weight = 1) {
    edge[edgeCount].to = to;
    edge[edgeCount].weight = weight;
    edge[edgeCount].next = head[from];
    head[from] = edgeCount++;
}
```

### Traversing Adjacent Vertices

To traverse all adjacent vertices of a vertex, you can use a loop:

```cpp
void traverseAdj(int vertex) {
    for(int i = head[vertex]; i != -1; i = edge[i].next) {
        int adjVertex = edge[i].to;
        // 在此处处理与adjVertex的关系，比如打印、进一步计算等
        printf("Adjacent vertex of %d is %d\n", vertex, adjVertex);
    }
}
```

### Example Scenario

Suppose there is a logistics network with multiple nodes, and the goal is to transport goods from a factory (source S) to multiple distribution centers (intermediate nodes) and then distribute them to various sales points (sink set T1, T2, T3). The network is as follows:

- **Nodes**: S (source), A, B, C (intermediate nodes), T1, T2, T3 (sinks)
- **Edges and attributes**:
  - S to A: capacity 20 units, cost 5 yuan/unit
  - S to B: capacity 15 units, cost 4 yuan/unit
  - A to B: capacity 10 units, cost 3 yuan/unit
  - A to C: capacity 12 units, cost 2 yuan/unit
  - B to C: capacity 8 units, cost 2 yuan/unit
  - B to T1: capacity 10 units, cost 6 yuan/unit
  - C to T2: capacity 15 units, cost 4 yuan/unit
  - C to T3: capacity 20 units, cost 3 yuan/unit

The goal is to maximize the total transport volume from S to all T while minimizing the total cost.

### Solution Steps

#### 1. Initialization

- Initialize the network structure, recording the capacity and cost of each edge.
- Use a distance array `dist[]` to record the shortest distance to each node (initially, all are infinity except the source S which is 0).
- Initialize a queue for the SPFA algorithm.

#### 2. Apply SPFA to Find the Minimum-Cost Augmenting Path

- **Starting point**: Start from the source S.
- **Relaxation operation**: For each adjacent node of S (A and B), calculate the cost of reaching them through S and update their shortest distances. Then add these nodes to the queue.
- **Queue processing**: Take a vertex from the queue, and for each adjacent vertex of this vertex, try to relax the path to the adjacent vertex through the current vertex. If the relaxation succeeds, mark the adjacent vertex and add it to the queue. This process continues until the queue is empty or a path to some sink is found.


### 3. Augmentation Operation

1. **Find an augmenting path**: In the MCMF problem, we first use an algorithm like SPFA to find a minimum-cost path from the source S to some sink (here we use T1 as an example). In this example, the path found is S->B->T1.

2. **Determine the augmentation amount**: The "minimum residual capacity" of this path refers to how much additional flow can pass through the edge with the smallest capacity in the path. If the capacity of S->B is 15 units and the capacity of B->T1 is 10 units, then the minimum residual capacity of the entire path is 10 units, because the capacity of B to T1 limits the maximum flow the whole path can carry.

3. **Calculate the total cost**: Once the augmentation amount is determined (10 units), we need to calculate the total cost of augmenting along this path. According to the cost of each edge, the cost from S to B is 4 yuan/unit, and the cost from B to T1 is 6 yuan/unit, so the total cost of passing 10 units of flow is \(10 \times (4 + 6) = 100\) yuan.

4. **Update the network state**: After the augmentation operation is complete, the residual capacities of the edges on the path must be updated. Since we added 10 units of flow through the S->B->T1 path, the residual capacity of S to B decreases from 15 units to 5 units (15-10=5), and the residual capacity of B to T1 becomes 0 (because it has been fully used).

5. **Repeat the process**: After completing one augmentation, we need to continue looking for new augmenting paths. Since the path from B to T1 has been fully utilized, the SPFA algorithm will explore other paths, such as from S through other nodes (like A, C) to other sinks (T2 or T3). After finding a new path, perform the augmentation operation again, update the flow and residual capacity of the corresponding edges, and accumulate the total cost.


#### 4. Termination Condition

- When no new augmenting path can be found, the algorithm ends.

### Result Analysis

- **Maximum flow**: Through continuous augmentation, the maximum possible transport volume from S to all T is eventually obtained.
- **Minimum cost**: The sum of the costs of all augmenting paths is the minimum cost.
