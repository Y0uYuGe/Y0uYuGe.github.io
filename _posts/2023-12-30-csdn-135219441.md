# Physical Implementation of the Bus
If this is the data bus, then when the CPU sends high and low level signals over the four wires respectively, the signals travel along the wires to other components, thereby achieving data transfer
But if data is sent onto all the wires of the bus at the same time, conflicts may occur, such as one being 0 and another being 1

# Definition of the Bus
At first, components were connected according to function. With this decentralized connection approach, adding or removing external devices makes rewiring the circuit quite troublesome
![Image](/images/csdn/2023/csdn-135219441/image-004-438f105c1f.png)
# Characteristics of the Bus
Transmission direction refers to which direction the digital signals on the bus travel
The valid voltage range means the signal is valid, i.e., a 1, only when the voltage level falls within a certain range
The function of a transmission line refers to whether it carries addresses, data, or control signals
Timing characteristics: the scheduling of when the various signals are issued
![Image](/images/csdn/2023/csdn-135219441/image-005-bae58961fe.png)
# Classification of Buses
![Image](/images/csdn/2023/csdn-135219441/image-006-98e4022d29.png)
## Classification by Data Format

### Serial Bus
Only one bit can be transmitted at a time
Strong anti-interference ability — probably because there is only one electrical signal, with no other electrical signals interfering with it. I feel you can refer to the physics concept of electricity generating magnetism, magnetism generating electricity, and electricity interfering with electricity
Disassembly and assembly: since most data is not 1 bit, when data needs to be transmitted one bit at a time, multi-bit data must be disassembled into individual bits. And upon reception, these individual bits must be assembled back into the original multi-bit data
![Image](/images/csdn/2023/csdn-135219441/image-007-c25d90157a.png)

### Parallel Bus
Multiple bits can be transmitted at once
The higher the frequency, the stronger the interference with the digital signals of other lines
![Image](/images/csdn/2023/csdn-135219441/image-008-b851cf7449.png)
## Classification by Bus Function
On-chip bus, system bus, and communication bus — increasing level by level
![Image](/images/csdn/2023/csdn-135219441/image-009-f6b2b474f2.png)
### Note the Further Classification of the System Bus
Data bus: when the number of lines equals the machine word length, the length of the content read is exactly the maximum length the CPU can process at one time; if it equals the storage word length, then the corresponding content can be fetched in a single read. It is bidirectional because data needs to be transmitted in both directions

Address bus: with unified addressing, the number of devices must be considered. For example, if main memory is 0~n, then one device's address is n+1 and another device's address is n+2. In this case, the maximum binary number representable by the address bus width must be able to reach n+2. It is unidirectional because the transmission direction can only be from the CPU to main memory, so it must be unidirectional

Control bus: different control lines correspond to different control signals. Some control lines are used to send signals to other components, while others are used to receive signals sent by other components to the CPU
![Image](/images/csdn/2023/csdn-135219441/image-010-ec40ef74cf.png)

# Bus Structures
## Single-Bus Structure
Because signals sent by different devices onto the bus at the same time may conflict, concurrent transmission is not supported
Low bandwidth means slow transmission, because transmission may not happen immediately — you have to wait until other components release the bus, otherwise there is a conflict
Since there is only one bus, the considerations are less complicated, so connecting devices is relatively easy.
In addition, since the system bus transmits quickly while the data from I/O devices on the bus is slow, some of the bus's performance may be wasted
![Image](/images/csdn/2023/csdn-135219441/image-011-bc723f7c12.png)
## Dual-Bus Structure
Burst: you send out the address of one piece of data you need, but what you get back is that data plus the data stored contiguously adjacent to it
The CPU and the channel transfer over the main memory bus with no speed wasted, and the I/O devices and the channel transfer over the I/O bus, again with no speed wasted.
![Image](/images/csdn/2023/csdn-135219441/image-012-0b8c3b6098.png)
## Three-Bus Structure
The DMA bus is fast and is used to connect high-speed peripherals; the I/O bus is slow and is used to connect low-speed peripherals
The CPU accesses low-speed peripherals through the I/O bus, making full use of the I/O bus
If the disk needs to be accessed, the contents of the disk can first be transferred to main memory via DMA, and then to the CPU
The efficiency is low because only one of the three buses can work at a time
![Image](/images/csdn/2023/csdn-135219441/image-013-a0c13580fb.png)


## Four-Bus Structure
Different buses have different speeds, and bridges are used to convert between them
Data buffering and conversion: the bridge can convert received serial data into parallel data before sending it out
Control: deciding which device gets the right to use the bus
![Image](/images/csdn/2023/csdn-135219441/image-014-ddc5f5b804.png)
