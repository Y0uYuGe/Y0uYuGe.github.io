# Offset Addressing
Index register: IX
Base register: BR
![Image](/images/csdn/2023/csdn-134823840/image-003-85401cc8b9.png)
## Base Addressing
When there is no base register, a general-purpose register is sometimes used instead, in which case the instruction must specify it
![Image](/images/csdn/2023/csdn-134823840/image-004-64c0263524.png)

## The Role of Base Addressing
When the starting address is memory address 0, direct addressing can be used
![Image](/images/csdn/2023/csdn-134823840/image-005-31d22d9191.png)
When the starting address is not memory address 0, addressing can be done via BR + operand
BR points to the starting address of the currently executing program
![Image](/images/csdn/2023/csdn-134823840/image-006-fc88b3be43.png)
Where a program is placed in memory is managed by the operating system
![Image](/images/csdn/2023/csdn-134823840/image-007-7c111da4a3.png)
If a general-purpose register is designated as the base register, we can no longer modify that general-purpose register; it is managed by the operating system
![Image](/images/csdn/2023/csdn-134823840/image-008-fc454bb036.png)
It can expand the addressing range
![Image](/images/csdn/2023/csdn-134823840/image-009-9d0d6d21e5.png)

## Relative Addressing
A should be the offset relative to the instruction following the current instruction
![Image](/images/csdn/2023/csdn-134823840/image-015-6d1aec55fe.png)
## The Role of Relative Addressing
Segmentation solves the addressing of data elements when a program is moved. This way the formal address does not need to change every time the program code is moved. In the figure below, this means the 7 does not need to change
![Image](/images/csdn/2023/csdn-134823840/image-016-8c8aee5e5d.png)
Base addressing corresponds to the movement of the entire program in memory
Relative addressing corresponds to the movement of a piece of code within the program
![Image](/images/csdn/2023/csdn-134823840/image-017-8863311e77.png)
