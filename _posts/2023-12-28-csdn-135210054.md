# SISD
Concurrency means: execute one instruction sequence for a while, then execute another instruction sequence
Parallelism means: two instruction sequences run at the same time
Within a given time period, only the instruction sequence of one process or one thread can be handled; the instruction sequences of multiple processes or threads can only run concurrently, not in parallel
![Image](/images/csdn/2023/csdn-135210054/image-003-855ab059de.png)

Single instruction stream means only one instruction sequence can be processed within the same time period
Single data stream means each instruction can only process one or two data items 
![Image](/images/csdn/2023/csdn-135210054/image-004-e46a05ca27.png)
![Image](/images/csdn/2023/csdn-135210054/image-005-d04ec535ad.png)
# SIMD
Since each ALU processes a different address at this point, the address registers also differ
![Image](/images/csdn/2023/csdn-135210054/image-006-5525e48cc2.png)
It is equivalent to one instruction being given to multiple ALUs to execute simultaneously — equivalent to executing that instruction multiple times, or in other words the control signal goes to multiple ALUs and the multiple ALUs perform the same operation
Each has its own local memory, and these local memories together make up the whole memory region being controlled
At this point one instruction can process multiple data items in parallel (processing multiple data at the same time)

A corresponding example is pixel processing, where each ALU processes part of the pixels
Or applying the same operation to all array elements: each ALU's local memory corresponds to some element of the array, so each ALU processes one element of the array
![Image](/images/csdn/2023/csdn-135210054/image-007-f53c8448df.png)


# MISD
This does not exist in reality, because it is a rather foolish approach: the effect of the multiple instructions on the data would all be the same. It is impossible for multiple instructions to process the data differently — or rather, if they were instruction sequences, there would be no parallelism at all due to dependencies. For example, some instruction may need the result of the previous instruction. But here the original data is processed simultaneously, which is clearly unreasonable.
Therefore, since multiple instructions processing one datum in parallel have the same effect anyway, why not just use one instruction?
![Image](/images/csdn/2023/csdn-135210054/image-008-0f84c453fc.png)
# MIMD
There are multiple processors, which can execute multiple different instruction sequences, or multiple copies of the same instruction sequence (that is, processing multiple data streams in parallel)
 
![Image](/images/csdn/2023/csdn-135210054/image-009-48df82f0fe.png)
Multiprocessor system
Multiple processors share the LLC, and each processor also has higher-level caches for its own use
![Image](/images/csdn/2023/csdn-135210054/image-010-7695bfbad8.png)
Multi-computer system
Message passing can be understood as network transmission
Different instruction streams are executed simultaneously, and the data streams processed by each machine are also different, because the data to be processed can be given to different memories — the data given can differ
![Image](/images/csdn/2023/csdn-135210054/image-011-e2062b0e41.png)
![Image](/images/csdn/2023/csdn-135210054/image-012-3e97b2e163.png)
# Vector Processor

![Image](/images/csdn/2023/csdn-135210054/image-013-b35444c3bf.png)
Here one vector register stores an n-dimensional vector
When adding two n-dimensional vectors, a vector processor needs only one add instruction, because vector registers store vectors, so its unit of addition is an n-dimensional vector
Whereas an ordinary processor needs n add instructions, because each addition operates on a single datum
So a vector register can be regarded as data parallelism, or one instruction processing multiple data at the same time
Multi-ported, supporting simultaneous reads
![Image](/images/csdn/2023/csdn-135210054/image-014-d43ebdc31d.png)

A core is a processor
A shared-memory multiprocessor and a multicore processor are the same thing
