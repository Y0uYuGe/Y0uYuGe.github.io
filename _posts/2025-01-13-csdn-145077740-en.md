# Object Detection
Find the objects in an image, mark them with rectangular boxes, and give the category and corresponding probability.
![在这里插入图片描述](/images/csdn/2025/csdn-145077740/image-001-d9475b216f.png)

## Early Object Detection Pipeline
![在这里插入图片描述](/images/csdn/2025/csdn-145077740/image-002-4bd1493e6e.png)

---

### **Stage 1: Generate a Large Number of Candidate Boxes Using Computer Image Processing**
- The original image on the left contains the targets (a dog and a cat) as well as the background.
- The system first uses traditional image processing techniques (such as sliding windows, selective search, edge detection, etc.) to generate **a large number of candidate boxes**.
- Candidate boxes are rectangular boxes covering potential target regions in the image; the green rectangles on the right side of the figure represent these candidate boxes.
- Generating candidate boxes is the first step of object detection, aiming to reduce the regions that need to be analyzed.

---

### **Stage 2: Feed Each Box into a Machine Learning Classification Model for Judgment**
- After generating the candidate boxes, each candidate box is fed one by one into a **classifier** (such as a support vector machine or a simple neural network).
- The classifier's task is to determine whether each candidate box contains a target object, and the category of the target (such as dog or cat).
- If a candidate box is judged by the classifier to contain a target, it is kept; otherwise, it is discarded.
- In the right figure, the retained candidate boxes may cover targets such as the dog and the cat.

---

### **Summary**
The core of this method is a **two-step approach**:
1. First generate as many candidate boxes as possible to ensure that target regions are not missed.
2. Then use a classification model to judge each box one by one, determining the presence of targets and their categories.

---

### **Limitations**
The main problems of this early method are:
- The number of candidate boxes is large and the computational cost is high (especially for large images).
- The classifier needs to run separately for each candidate box, resulting in low efficiency.
- Candidate boxes may contain many overlapping regions, further increasing computational complexity.

Modern object detection algorithms (such as YOLO and Faster R-CNN) solve these problems by introducing the idea of **end-to-end detection**, directly and efficiently predicting objects and their locations in the entire image.

## Selective Search

 ![ ](/images/csdn/2025/csdn-145077740/image-003-83d0993f3c.png)
---

### **Introduction to Selective Search**
1. **Background:**
   - Selective Search is a method for generating candidate boxes, mainly used for object detection.
   - It was proposed by **Koen E.A** in 2011 and is a classic candidate region generation algorithm.

2. **Core idea:**
   - The regions where objects may exist in an image are often regions with similarity (such as color, texture, etc.) or continuity.
   - Based on the idea of **region merging** and combined with image segmentation techniques, selective search gradually merges regions with similar features to generate a series of candidate boxes.

---

### **Main Process of Selective Search**
1. **Image segmentation:**
   - First, perform a **preliminary segmentation** of the input image, dividing it into multiple smaller sub-regions.
   - The **color segmentation maps in the first row at the top of the figure** show the results of different segmentation stages; each color represents one segmented region.

2. **Region merging:**
   - Adjacent sub-regions are continuously merged according to similarity metrics (such as color, texture, size, etc.), gradually forming larger regions.
   - After each merge, candidate boxes (bounding boxes) are generated over these regions, i.e., the **blue rectangles in the second row at the bottom of the figure**.

3. **Candidate box generation:**
   - The final output is a set of rectangular candidate boxes containing potential targets, used by the subsequent classifier to determine whether a target exists.

---

### **Characteristics of Selective Search**
1. **Advantages:**
   - It does not rely on the sliding window method, so it is more efficient and flexible than traditional sliding windows.
   - It exploits the image's own characteristics (color, texture, etc.) to generate candidate regions, reducing computational cost.

2. **Disadvantages:**
   - The number of generated candidate boxes is still large and may contain redundant information (many overlapping boxes).
   - For high-resolution images, the segmentation and region merging processes are computationally slow.

---

### **Summary**
The core of selective search is to leverage the idea of hierarchical clustering in the image, gradually merging similar regions to generate candidate target regions (candidate boxes).  
Its main advantage is that it combines image segmentation techniques and is more efficient than the sliding window method; however, there is still room for improvement in speed and the number of boxes, so it has gradually been replaced by more efficient algorithms in modern object detection methods (such as Faster R-CNN).

# 	R-CNN
### **Introduction to R-CNN**
R-CNN (Regions with Convolutional Neural Networks) is a milestone method in the field of object detection, proposed by Ross Girshick in 2014. The core idea of R-CNN is to decompose the image object detection problem into two steps:
1. **Candidate region generation**: generate candidate boxes that may contain targets using traditional algorithms (such as Selective Search).
2. **Object classification**: use a convolutional neural network (CNN) to extract features from each candidate box one by one, classify them with a classifier (such as SVM), and use a regressor to adjust the positions of the candidate boxes.

Although R-CNN has high detection accuracy, it is slow because the CNN must be run separately for each candidate box.

---

### **Main Steps of R-CNN**

1. **Input image:**
   - Feed in the original image.
   
2. **Generate candidate regions:**
   - Use methods such as Selective Search to generate about 2000 candidate boxes (Regions of Interest, RoI).

3. **Feature extraction:**
   - Crop each candidate box individually and resize it (e.g., \(224 \times 224\)), then extract features through a CNN.

4. **Classification and bounding box adjustment:**
   - For the features extracted from each candidate box, use a classifier (such as SVM) to determine the target category.
   - Use a regressor to refine the boundaries of the candidate boxes, generating more accurate target boxes.

---




#  Fast R-CNN
![在这里插入图片描述](/images/csdn/2025/csdn-145077740/image-004-114e3437a7.png)
At the final end, the SVM is replaced by a Softmax classifier.
It adopts the SPP-net approach: the entire image is fed into the ConvNet, and then the positions corresponding to the proposals are mapped out from the feature map.
It borrows from SPP-net, except that the RoI Pooling layer is a special case of the SPP layer.
![在这里插入图片描述](/images/csdn/2025/csdn-145077740/image-005-5441a8ab7e.png)
Although it is still a two-stage framework,
the whole network can be trained in one stage during backpropagation.
But note that the algorithm for proposing candidate boxes is still Selective Search, which extracts proposals based on the original image and is not trainable.
![在这里插入图片描述](/images/csdn/2025/csdn-145077740/image-006-27f1455d30.png)
Multi-task loss: uses a multi-task loss function, including a classification loss (Log loss) and a regression loss (Smooth L1 loss).

- Log loss (classification loss):

Used for classification tasks, it measures the error of the model's prediction of the target category.
For example, if a candidate box is labeled "cat" but the model predicts "dog", a classification loss is incurred.
- Smooth L1 loss (bounding box regression loss):

Used for regression tasks, it measures the error between the predicted bounding box and the ground-truth bounding box.
The Smooth L1 function is used instead of the ordinary L2 loss to reduce sensitivity to outliers.
![在这里插入图片描述](/images/csdn/2025/csdn-145077740/image-007-9fe2058e9c.png)



## SPP-net (Spatial Pyramid Pooling Network)

SPP-net is a deep learning network for image classification and object detection, proposed by Kaiming He and others in 2014. Its core is the introduction of the SPP layer (Spatial Pyramid Pooling Layer), which solves the requirement of traditional CNN models for fixed input image sizes.



![在这里插入图片描述](/images/csdn/2025/csdn-145077740/image-008-23ee4a8e89.png)

# Faster R-CNN
The most important thing is the introduction of the RPN network, which replaces SS to extract candidate boxes!!! (SS is Selective Search)

Originally, the original image was used at the very beginning to find candidate boxes; now the image goes through a CNN to get a feature map, which then goes through the RPN to get the candidate boxes (proposals).

There are four loss functions.
![在这里插入图片描述](/images/csdn/2025/csdn-145077740/image-009-d09488f6d5.png)
The selective search method is slow; after replacing SS, the speed increases to 1/0.2 = 5 FPS (frames per second).
