# Drawbacks of the GBN Protocol
Batch retransmission causes redundant frames to be retransmitted as well.

Setting individual acknowledgments allows frames to be acknowledged one by one.
![在这里插入图片描述](/images/csdn/2024/csdn-136093828/image-001-a2d3680dca.png)
# Sliding Window in the Selective Repeat Protocol
Sender: if the lower bound of the window has not received an acknowledgment while other parts have received acknowledgments, the window will not move until the lower bound receives an acknowledgment, at which point it moves by the corresponding number of window slots.

Receiver: the lower bound has not been received, but the frame adjacent to it on the right has been received; in this case, if the lower bound is then received, the window will move by two slots.
![在这里插入图片描述](/images/csdn/2024/csdn-136093828/image-002-f60a30e221.png)
# Three Things the SR Sender Must Respond To
If the window has moved and there are unsent frames with sequence numbers within the window, send those frames: that is, after the window may have moved, if there are now unsent frames in the window, those frames will be sent.
![在这里插入图片描述](/images/csdn/2024/csdn-136093828/image-003-550f775326.png)
# What the SR Receiver Must Do

Until all frames (that is, frames with smaller sequence numbers) have been received: that is, after receiving 6 and 7, the window will not move; it only moves when 5 is received.
![在这里插入图片描述](/images/csdn/2024/csdn-136093828/image-004-4028069175.png)
# SR in Operation
Even if the receiver receives 3 and 4 but has not received 2, it will not shift the window to the right.
![在这里插入图片描述](/images/csdn/2024/csdn-136093828/image-005-a17721f9fb.png)
# Sliding Window Length
Too large: the send window is larger than the receive window, so the receiver cannot keep up.
Too small: the extra receive window is wasted.

At this point, the number 0 on the left is an old frame.
The number 0 on the right is a new frame, but at this point the receiver cannot distinguish whether it is a new frame or an old frame.
![在这里插入图片描述](/images/csdn/2024/csdn-136093828/image-006-20f0989313.png)
# Key Summary of the SR Protocol
Acknowledging each frame as it is received is limited to within the receive window.
![在这里插入图片描述](/images/csdn/2024/csdn-136093828/image-007-46bbf73f75.png)
