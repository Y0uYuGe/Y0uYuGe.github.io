# 注意事项
系好安全带
唯一需要打一圈半的情况是倒车入库后出库的时候。
有两个地方需要打转向灯

# 准备
先系好安全带，然后把车钥匙拧 90 度，调整座椅位置，直到身体靠后、头部平视前方时刚好看不到车的引擎盖。调整后视镜。最后把离合和刹车踩到底，钥匙再拧 90 度，车就启动了。松开手刹，挂一挡。松开离合。

# 倒车入库
左后视镜下沿中点对准左边线行驶。
当座位大致越过前方的边界线时，离合踩到底并刹车
然后倒车时，当左后视镜里看到的轮胎压线时，方向盘向右打死。白线消失时回半圈。继续倒车，车身摆正后，看座位是否正好在标志上方。出库时向左打一圈半，后视镜大致出库后挂倒挡，方向盘不动——回来的路上可以先打死一会儿——然后打一圈半继续倒车。车身摆正后，看座位是否正好在线上（线在座位中间）

# 侧方停车
车头镜左下角对准左边线行驶，看不到前方线时看右后视镜。对角居中时挂倒挡，看到第三根黑线（最左边的黑色算一根）时回正方向盘，然后倒入车位。车轮压线后开始打方向盘——向左打一圈半。车身摆正后打灯、换挡，方向盘不动，左后轮过线后回正方向盘并向右打一圈

# 曲线行驶
车头镜左下角对准左边线进入，发现左后视镜左侧离开左边曲线时，向左打一圈并保持，直到曲线改变方向，然后保持原有打法，直到从车门看不到线，再直行；右后视镜底部出现右边曲线时，向右打一圈加 45 度。继续行驶，方向盘回正后直行

# 直角转弯
车头镜左下角对准左边线进入。可以提前打左转向灯；等拐角线大致到座位中间（或者两腿分开的中间点对准那条线）时，向右打死

# 坡道定点停车与起步
上坡时，雨刷最高点的右侧大致贴着右边线；上坡后，改为雨刷最高点的左侧大致贴着右边线。线消失且第三根线出现在左后视镜稍下方时停车。拉手刹，松手刹，慢慢松离合直到车身抖动，然后松刹车，同时再稍微松一点离合，让车向前向上行驶
