#  我觉得不对的地方
我一直觉得学了什么都应该记录在博客里，方便以后复习或查阅。
但是 CSDN 似乎不适合全局搜索——也就是说，我其实得先知道模糊记忆对应的是哪篇文章，然后再在那篇文章里搜索，实在太麻烦了。另一个问题是，博客内容太长时会变得非常繁琐，而且需要展示的时候，博客的形式既不能清晰地展示流程，也不能帮助你快速回忆。



#  改进
使用 XMind——思维导图的形式，它同样可以记笔记，还能用来做演示，省去了做 PPT 的时间。但仍然有一个痛点：一个节点只能插入一张图片。

主要是它还能转换成 Markdown。以后我可能就直接把它转成 Markdown 发到博客上了，如有不准确之处还请见谅。

至少，XMind 支持全局搜索，而且更简洁，这样我能清楚地把握自己的进度以及正在做的事情。而且因为内容更加凝练，回忆起来也更容易。
