# CISC 和 RISC

 存储程序的计算机由电路加存储部件组成
![图片](./assets/csdn-135039555/image-002-3e9733ff16.png)

访存指令不同
RISC 更加灵活，因为很多功能不是固定的，而是由自己编写
由于 CISC 指令的执行时间各不相同，实现指令流水线更加困难
由于 CISC 对访存指令不加限制，过程没那么繁琐，需要的辅助寄存器也更少
