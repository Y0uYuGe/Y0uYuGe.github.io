二叉树的链式存储

n 个结点必然有 n-1 个非空指针域和 n+1 个空指针域。 之所以是 n-1，是因为有 n-1 条连接两个结点的边，所以对应的指针域中也会有 n-1 个非空指针域 常用操作 查找某个结点的双亲时，需要遍历整棵树，依次检查某个结点的孩子是否为目标结点。 在结点结构中增加一个双亲指针可以避免这种遍历

树的逻辑结构

顺序存储（双亲表示法）

顺序 + 链式存储（孩子表示法）

有指向孩子链表的指针的元素

链式存储（孩子兄弟表示法）

左孩子是原来的孩子结点，右孩子是原来的兄弟结点 所以从 B 的右孩子开始遍历到的所有右孩子都是原结点 A 的孩子

森林与二叉树的转换（孩子兄弟表示法）

把所有兄弟结点连起来，再断开兄弟结点与双亲结点之间的连线，就完成了

树和森林的遍历

树的先根遍历

类似二叉树的先序遍历：根、左、右 对应的二叉树就是用孩子兄弟表示法表示的树，这棵二叉树的先序遍历与原树的先根遍历相同

树的后根遍历

类似二叉树的后序遍历：左、右、根 对应的二叉树就是用孩子兄弟表示法表示的树，这棵二叉树的中序遍历与原树的后根遍历相同

树的层序遍历

后根遍历和先根遍历是深度优先遍历 层序遍历是广度优先遍历
