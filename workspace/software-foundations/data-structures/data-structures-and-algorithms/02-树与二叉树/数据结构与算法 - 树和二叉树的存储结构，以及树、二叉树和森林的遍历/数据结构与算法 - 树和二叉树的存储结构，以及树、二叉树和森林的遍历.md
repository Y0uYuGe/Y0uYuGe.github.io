通过计算某个结点对应的左孩子或右孩子的结点编号，再判断它是否在 n 个结点的范围内
![图片](./assets/csdn-134490413/image-003-04a32e7ec1.png)

## 二叉树的链式存储

n 个结点必然有 n-1 个非空指针域和 n+1 个空指针域。
之所以是 n-1，是因为有 n-1 条连接两个结点的边，所以对应的指针域中也会有 n-1 个非空指针域
![图片](./assets/csdn-134490413/image-007-0f0809d6b9.png)
常用操作
![图片](./assets/csdn-134490413/image-008-0bc67a3874.png)
查找某个结点的双亲时，需要遍历整棵树，依次检查某个结点的孩子是否为目标结点。
在结点结构中增加一个双亲指针可以避免这种遍历

# 树和森林的遍历
## 树的先根遍历
类似二叉树的先序遍历：根、左、右
对应的二叉树就是用孩子兄弟表示法表示的树，这棵二叉树的先序遍历与原树的先根遍历相同
![图片](./assets/csdn-134490413/image-051-f2c7a466e6.png)
## 树的后根遍历
类似二叉树的后序遍历：左、右、根
对应的二叉树就是用孩子兄弟表示法表示的树，这棵二叉树的中序遍历与原树的后根遍历相同
![图片](./assets/csdn-134490413/image-052-27201e8627.png)
## 树的层序遍历
后根遍历和先根遍历是深度优先遍历
层序遍历是广度优先遍历
![图片](./assets/csdn-134490413/image-053-e4d91f9a02.png)
