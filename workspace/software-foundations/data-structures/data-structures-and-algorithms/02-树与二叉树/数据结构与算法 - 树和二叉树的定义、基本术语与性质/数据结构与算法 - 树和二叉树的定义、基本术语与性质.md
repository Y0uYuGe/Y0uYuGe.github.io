## 描述结点之间的关系
 - 祖先结点：一个结点上面的所有结点都是它的祖先结点
 - 子孙结点：一个结点下面的所有结点都是它的子孙结点
 - 双亲结点：一个结点直接上面的那个结点是它的双亲结点
 - 兄弟结点：拥有同一个双亲结点的子孙结点
 - 堂兄弟结点：emmm，有点难描述——同一层但不包括兄弟的结点，比如图中标着“你”的结点和 G H I J 结点

![图片](./assets/csdn-134655131/image-005-e8cd89ac2b.png)

结点的深度（层次）可以从零开始，也可以从一开始，默认从一开始（高度同理）
高度与深度相反，从字面意思应该就能理解

# 树的相关性质
树的结点数 = 所有结点的度之和 + 1
可以这样理解：
某一层结点的度之和等于下一层的结点数，如下所示
有四层时，第一到四层的度之和等于第二到四层的结点数（第四层的度之和为零），但树的结点数还包括根结点，而第一到四层的度之和不包括第一层的结点数 1。
所以树的结点数 = 所有结点的度之和 + 1

# 二叉树的相关概念和基本术语
二叉树是有序的，每个结点最多有两棵子树（可以是空子树）
![图片](./assets/csdn-134655131/image-017-d3530dda26.png)

##   重要（五种状态）

![图片](./assets/csdn-134655131/image-018-d3e911283c.png)
## 特殊的二叉树
完全二叉树：结点与对应满二叉树的结点一一对应
完全二叉树最多只有一个度为 1 的结点；如果有两个，就说明这两个度为 1 的结点的孩子之间空了一个结点，这就违背了与对应满二叉树结点一一对应的要求
![图片](./assets/csdn-134655131/image-019-e892ba6f13.png)

**完全二叉树中如果某结点只有一个孩子，那一定是左孩子**

二叉排序树是指左孩子存的值小于双亲结点存的值，双亲结点存的值又小于右孩子存的值
  ![图片](./assets/csdn-134655131/image-020-1ace356834.png)
 当二叉排序树是平衡二叉树时，查找深度更小、效率更高，因为需要比较的次数更少
