算法的时间复杂度

如何评估算法的时间开销

如果在机器上运行算法，运行结束后再去测量时间，由于机器不同、实现算法所用的语言不同、编译器效率不同，结果会有差异 而且有些算法无法等到运行结束后再测量其运行时间，所以先运行算法再测量运行时间是不合理的

大小固定、与问题规模无关，意味着所占空间不随输入的变化而变化 原地工作意味着空间复杂度为常数 当这里的 n 变得很大时，常数级的项可以忽略，所占空间取决于与问题规模相关的变量
