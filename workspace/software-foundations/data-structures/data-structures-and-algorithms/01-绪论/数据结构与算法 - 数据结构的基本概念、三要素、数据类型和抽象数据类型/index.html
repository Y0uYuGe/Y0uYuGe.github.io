数据

早期与现代计算机处理的数据

早期计算机大多专注于计算数值型问题 现代计算机还经常处理非数值型问题，比如具体的信息（字符串）以及关系

数据元素——描述一个个体

数据元素是数据集合中的一个具体个体 比如取号等餐的例子 比如微博上的一个具体账号就是一个数据元素

数据对象——一类数据元素

数据由不同的数据对象组成

什么是数据结构

数据结构就是数据元素之间的关系——当然，它们可以属于同一类数据对象，也可以属于不同类的数据对象
