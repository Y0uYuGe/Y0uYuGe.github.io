# 常见的散列函数
## 除留余数法
这里我们发现取质数反而产生更多同义词，因为关键字是连续的
![图片](./assets/csdn-135358027/image-011-aad9dbbd55.png)
如果关键字大多是偶数
![图片](./assets/csdn-135358027/image-012-4727c63d40.png)
## 直接定址法
直接定址法中，由于关键字对应的位置也是连续的，如果缺少某个关键字，对应位置上的内容也就空缺。这会产生空位，浪费存储空间

![图片](./assets/csdn-135358027/image-013-48234c8c56.png)
## 数字分析法
分布比较均匀，即每个关键字可能对应不同的位置
![图片](./assets/csdn-135358027/image-014-9da7de282d.png)
## 平方取中法
适用于每一位上的取值分布不均匀，或者位数少于散列地址所需位数的情况
![图片](./assets/csdn-135358027/image-015-009b652e0c.png)
这样散列地址就与关键字的每一位都有关

![图片](./assets/csdn-135358027/image-016-de3bc9ab9f.png)

当比较到散列表中的空位置时，就认为查找失败
注意这里空位置也需要比较
拉链法中，散列表的每个位置实际存放的是指针，不算关键字比较；开放定址法中，存放的内容与关键字同类型，所以算作关键字比较
![图片](./assets/csdn-135358027/image-028-36e422c48b.png)
