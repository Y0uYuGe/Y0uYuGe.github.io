有向无环图（DAG）

用 DAG 描述表达式

合并一次 再次合并 再次合并

例题

解答

把相同的结点合并 只有同一层的结点才能合并；不同层之间存在包含关系，不可能相同 处于不同层就意味着存在包含关系
