图的概念

概述

图的定义

顶点集不能为空；边集可以为空，且每条边的两端都必须有顶点

图逻辑结构的应用


无向图与有向图

简单图与多重图

顶点的度、入度、出度

无向图中，一条边连接两个结点，贡献两个度
有向图中，一条边连接两个结点：给一个结点贡献一个入度，给另一个结点贡献一个出度

顶点与顶点之间关系的描述

连通（无向图中）：两个顶点之间有路径
强连通（有向图中）：两个顶点之间双向都有路径

连通图、强连通图

对于有 n 个顶点的无向图 G
若要成为连通图，只需把 n 个顶点连成一条线，需要 n-1 条边
若要成为非连通图，就孤立一个顶点，让其余结点之间的边全部连上，这相当于求从 n-1 个顶点中任选两个顶点有多少种选法。全部连上之后，再多加任何一条边都只能把孤立顶点和其余结点连起来，这会使图变成连通的，所以不允许。因此只需计算让其余结点全连通的边数即可

对于有 n 个顶点的有向图
若要成为强连通图，至少需要 n 条边（即构成一个回路，使任意顶点都能沿着回路的方向到达任意其他顶点）

研究图的局部——子图

子图也是图，所以也必须满足图的要求

邻接矩阵

它是一张横纵坐标都是顶点的图：相连为 1，不相连为 0
“邻接”指的是两个顶点之间是否有边相连

邻接表

顺序 + 链式存储

用一维数组存储图，每个顶点都有指向其对应边的指针信息

与树的孩子表示法对比

有向图与无向图

同一条边在无向图中需要存储两次，而在有向图中只需存储一次，所以空间复杂度不同

求顶点的度、入度、出度

无向图的度：遍历该结点的边表即可
有向图的出度：遍历该结点的边表即可
有向图的入度：需要遍历除该结点以外所有结点的边表（麻烦）
有向图的度：入度 + 出度

表示方式不唯一

即顶点的边表不唯一
但图的邻接矩阵是唯一的

十字链表

概述

背后的问题

邻接矩阵空间复杂度高
而邻接表找入边不方便

十字链表存储有向图

它为每个结点同时存储以该结点为弧尾的边表和以该结点为弧头的边表

性能分析

邻接矩阵、邻接表存储无向图的缺点

邻接多重表存储无向图

即每条边只对应一个边元素，用链表表示与某个顶点相连的边

删除边时，只需把前一个的指针改为指向下一条边
删除顶点时，删除该顶点对应的边表，并修改其他表中指向该表元素的那些元素的指针即可
