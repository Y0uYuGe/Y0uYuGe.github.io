在 Python 中使用正则表达式
正所谓人生苦短，我用 Python。Python 的一个特点就是拥有海量的库。它自然也有用于正则匹配的常用库，而且这个库内置在 Python 标准库中，使用起来非常方便——只需在代码中导入 re 模块即可。

import re
Python 的 re 模块使 Python 拥有了使用正则表达式全部功能的能力。为了能灵活运用正则表达式，我们现在的任务就是学习如何使用 re 库中的正则。

最基础的正则表达式
正则表达式是一种以简单直观的方式通过查找模式来匹配文本的工具。
听起来很复杂，其实非常简单。下面我们就开始体验最简单的正则表达式。最简单的正则表达式就是只包含简单字母数字字符的正则表达式——不含任何其他字符。这种情况下，正则表达式完全就是一个普通字符串。

例如，如果我们要匹配张明，那么“张明”这两个字就是我们需要的正则表达式。

正则匹配函数
既然知道了最基础的正则表达式，那么在 Python 中如何使用呢？首先我们学习第一个函数：search() 函数。它的作用是接收一个正则表达式和一个字符串，返回找到的第一个匹配的字符串。

import re
a = re.search(r'fox','the quick brown fox jumpred')  #第一个参数为正则表达式，第二个参数为要处理的字符串
print(a.span())      # span方法获取的是正则表达式匹配到的位置
b =  re.search(r'www','the quick brown fox jumpred') 
print(b)   #如果匹配不到则会返回None
输出如下：

(16, 19)
None
如何匹配到了，我们输出他在正则表达式中的位置，如果没有匹配到，则输出为空。

在上一个任务中，我们学习了只包含简单字母数字字符的正则表达式，但如果仅此而已，就大大低估了正则表达式的威力。正则表达式的强大之处在于能够指定文本模式进行匹配。本关我们将学习正则表达式中的字符组匹配。

获取多个匹配
在很多常见场景中需要进行多个匹配，比如从学生名单中筛选出所有姓张的学生的人数。

对于这类需求，我们可以使用 re 模块中的 findall 或 finditer 方法。两者的区别在于 findall 返回的是一个列表，而 finditer 返回的是一个生成器。

l = re.findall(r'张','张三 张三丰 张无忌 张小凡')
print(l)
['张', '张', '张', '张']
在这个例子中，我们会发现 findall 返回了 4 个“张”，这是因为“张”字在后面的字符串中出现了 4 次。即 findall 返回了所有的匹配信息。

字符组
字符组允许匹配一组可能的字符。在正则表达式中，[] 表示字符组。我们来看一个例子。

'I like Python3 and I like python2.7 '
在这句话中，既有大写的 Python,又有全部是小写的 python 。如果我要求都匹配出来，这时候该怎么操作了？这就是正则匹配中字符组的威力了。下面看下示例。

a = re.findall(r'[Pp]ython','I like Python3 and I like python2.7 ')
print(a)
['Python', 'python']
可以发现 [Pp] 既可以匹配大写的 P 也可以匹配小写的 p ，这里值的我们注意的是 [Pp] 仅匹配一个字符，他表示匹配在这个[]内的某一个。

本关我们将学习正则表达式的区间与区间取反。

区间
有些常见的字符组非常大。比如我们要匹配任意数字，如果照着上面的代码，每次都得用 [0123456789]，这显然很不明智；如果用这种方式写代码去匹配 a-z 的字母，肯定会把我们逼疯。

为了适应这一点，正则引擎在字符组中使用连字符（-）表示区间，所以我们可以用 [0-9] 匹配任意数字。同样，如果要匹配所有小写字母，可以写成 [a-z]；要匹配所有大写字母，可以写成 [A-Z]。

我们可能还会有这样的需求：匹配连字符本身。由于 - 会被正则引擎理解为表示区间，这种情况下需要对 - 进行转义。

示例：


a = re.findall(r'[0-9]','xxx007abc')
b = re.findall(r'[a-z]','abc001ABC')
c = re.findall(r'[A-Za-z0-9]','abc007ABC')
d = re.findall(r'[0-9\-]','0edu 007-edu')
print(a)
print(b)
print(c)
print(d)
执行结果如下：

['0', '0', '7']
['a', 'b', 'c']
['a', 'b', 'c', '0', '0', '7', 'A', 'B', 'C']
['0', '0', '0', '7', '-']

区间取反
到目前为止，我们定义的字符组都是由可能出现的字符定义的，但有时我们可能希望根据不会出现的字符来定义字符组，例如：匹配不包含数字的字符组。


a = re.findall(r'[^0-9]','xxx007abc')
b = re.search(r'[^0-9]','xxx007abc')
print(a)
print(b)
执行结果如下：

['x', 'x', 'x', 'a', 'b', 'c']
<re.Match object; span=(0, 1), match='x'>

可以在字符组开头使用 ^ 字符来进行取反操作，从而对一个字符组取反（意思是匹配除指定字符以外的所有字符）。

接下来再看一个表达式：n[^e]，它表示字符 n 后面跟着除 e 以外的任意字符。


a = re.findall(r'n[^e]','final')
b = re.search(r'n[^e]','final')
c = re.findall('r[n[^e]]','Python')
print(a)
print(b)
print(c)
执行结果如下：

['na']
<re.Match object; span=(2, 4), match='na'>
[]

这里我们可以看到 a 和 b 匹配到了 na。字符 a 之所以能被匹配，是因为它不是 e，而变量 c 的值为空。这种情况下正则引擎只匹配到了字符串 n 的位置，n 之后没有能匹配 [^e] 的字符，所以这里也匹配失败。

注意

search 找到的是第一个匹配，而 findall 找到的是所有匹配。
