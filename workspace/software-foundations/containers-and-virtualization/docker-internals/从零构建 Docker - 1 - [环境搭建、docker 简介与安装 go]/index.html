Docker 简介

Docker 可以看作一种极其轻量的“虚拟机”，它允许你把一个或多个程序连同其运行环境一起打包成一个标准化单元，这个单元可以在任何支持 Docker 的系统上运行，而不管底层是什么操作系统。

用一个更贴近日常生活的例子来解释，Docker 就像软件世界里的“集装箱”。集装箱在物流行业中用于标准化运输：它们可以装载货物，保护里面的东西不受外部环境影响，并且可以在全球范围内以同样的方式快速装卸和运输。同样，Docker 容器把软件连同其运行环境一起打包，确保软件在任何环境中都以同样的方式运行，简化了软件的部署和分发过程。

举个例子

当然，我们通过一个简单的日常例子来理解 Docker。

假设你想做一道复杂的菜，比如法式香煎鸭胸。首先，你需要一份详细的菜谱，告诉你烹饪步骤和所需的全部食材（这就像创建一个 Dockerfile）。然后，你需要在自己的厨房里备齐所有食材，按照菜谱开始烹饪（这就像构建一个 Docker 容器）。

但有一个问题。这道菜非常复杂，你不可能跑到每个人家里亲自去做。现在，假设你有一台神奇的设备，可以原样复制你的整个厨房和这道香煎鸭胸，包括撒在鸭胸上的每一粒海盐，并且还能保持你做完菜时的状态。那么你就可以把这个复制出来的“厨房”运到任何地方，人们只需稍微加热一下就能享用这道菜（这就像运行一个 Docker 容器）。

在这个例子中，你的厨房就像 Docker 容器，你的菜谱就像 Dockerfile，你准备的食材就是应用程序及其依赖环境，而你复制并送到别处的“厨房”就像运行在另一台机器上的 Docker 容器。

所以 Docker 的工作方式有点像把你的应用程序连同其环境一起“烹饪”好，然后把“做好的”容器“运送”到你想去的任何地方，稍微加热（运行）一下，就可以享用了。

安装 Docker

curl -sSL https://get .docker.com | sh

  1. curl：这是一个用于获取或发送数据的命令行工具，这里用它从指定的 URL 下载数据。

  2. -sSL：这些都是 curl 命令的选项。其中，-s 或 --silent 表示静默模式。在静默模式下，所有常规的进度显示和错误信息都会被屏蔽。-S 或 --show-error 表示显示错误。使用了 -s 选项时，这个 -S 选项就非常有用，因为它可以在出现问题时显示错误信息。-L 或 --location 表示如果服务器报告页面已移动到别处（即发送了 location 头），就跟随到新的位置。

https://get.docker.com：这是用于下载 Docker 安装脚本的 URL。

  1. |：这是管道符，作用是把前一个命令的输出作为后一个命令的输入。

  2. sh：这是 Shell 解释器，这里用它来执行从 https://get.docker.com 下载的脚本。
    然后就可以直接使用 docker 了。

Go 语言

Go，又称 Golang，是由 Google 开发的一种静态强类型、编译型编程语言。Go 兼具 C 的效率、Python 的可读性以及强大的并发处理能力。

Go 的语法非常清晰简洁，便于初学者学习。同时，Go 提供了丰富的标准库，涵盖网络编程、图形处理、文本处理、数据库操作等，开发者无需借助第三方库，直接用标准库就能完成许多功能开发。

C/C++ 是传统的编程语言，属于面向过程和面向对象的语言，具备完整的指针操作和内存管理能力。Go 是一门现代编程语言，带有垃圾回收机制，开发者不必过多关注内存管理，同时它还支持并发编程。

此外，Go 是编译型语言，运行前需要先编译，编译后的执行效率较高。在编译过程中，Go 还会检测出许多错误和问题，保证了程序的质量。

最后，Go 在并发处理方面也做得非常出色。它支持 Goroutine，类似于轻量级线程，可以进行大规模并行计算，非常适合需要处理高并发的网络编程和云编程。

安装 Go

  • 到官网找合适的版本下载。
  • 下载后解压。
tar -C /usr/local -xzf  go1.22.0.linux-amd64.tar.gz
  • 编辑 $HOME/.bashrc 并使其立即生效。
code  $HOME/.bashrc

  • tar：这是一个常用的 Unix/Linux 命令，用于处理归档/压缩文件。

  • -C /usr/local：'-C' 参数用于改变 tar 命令的工作目录。这里 tar 将在 '/usr/local' 目录下进行操作。

  • -xzf：这三个选项告诉 tar 命令要执行什么操作。

    • x：表示“解压（extract）”。
    • z：表示 tar 命令应使用 gzip 来解压或压缩文件。
    • f：表示“文件（file）”，即后面跟的是文件名。

  • go1.22.0.linux-amd64.tar.gz：这是你要解压的文件名。文件名表明这是 Linux 平台上 Go 1.22.0 版本的 64 位安装包。

添加 export PATH=$PATH:/usr/local/go/bin

  • export：这是一个用于设置环境变量的 shell 命令。它告诉 shell 我们要修改 PATH 环境变量的值。

  • PATH：这是一个特殊的环境变量，操作系统用它来查找在命令行中输入的命令。当你在命令行中输入一个命令（比如 go）时，shell 会在 PATH 变量列出的所有目录中搜索这个命令。

  • $PATH：这是获取 PATH 环境变量当前值的方式。这里我们用冒号（:）把它和新路径拼接起来，从而添加新路径。

  • :/usr/local/go/bin：这是你要添加到 PATH 中的新路径，也就是系统中安装的 Go 语言二进制文件所在的位置。

  • =：这是赋值运算符。这里用它把新的 PATH 值（即在原 PATH 值后追加新路径）赋给 PATH 环境变量。

source $HOME/.bashrc

  • source：这是一个 Bash 命令，在当前 shell 会话中读取并执行指定文件中的命令。

  • $HOME：这是一个环境变量，表示用户的主目录。在大多数系统上，它等同于 /home/你的用户名。

  • /.bashrc：.bashrc 是用户主目录下的一个文件，包含定义 Bash shell 行为的脚本。每次启动新的 Bash shell 会话时（例如打开一个新的终端窗口），.bashrc 文件中的脚本都会自动执行。
    安装成功。

Go 配置

GOPATH 是实际存放代码的路径。Go 根据 GOPATH 来查找依赖包。GOPATH 目录按约定包含以下子目录。
src：存放你的 Go 源文件。每个包在 src 下都有自己的目录。
pkg：该目录包含包对象，即编译后的 Go 源代码文件，用于生成可执行文件。
bin：该目录包含可执行命令。当你运行 go install package，且 go install 通过 src 目录下的工作区找到该包时，Go 会把文件安装到这里。
这里我们用 /go 作为 GOPATH 路径。编辑 $HOME/.bashrc 文件，把命令 export GOPATH=/go 添加到文件中，
