目录结构

Linux 文件系统是一个树形的层次结构，如下图所示；其中最重要的是根目录（/）。 Linux 命令行也叫终端；在命令行中，只使用键盘。

打开命令行后，可以看到当前用户和当前目录。

root 指用户名，~ 是用户的主目录；可以使用 pwd 查看当前目录。

进入目录

切换目录的命令是 cd；例如切换到根目录：cd /，输入后按回车执行命令。 在 Linux 中，路径也分为绝对路径和相对路径。绝对路径从根目录开始算起，而相对路径从当前目录开始算起。 例如：当前在 /root 目录下，要切换到 /root/os/linux-0.11-lab 目录。 切换目录有两种方式。一种是通过相对路径：以当前目录为起点进行切换。 另一种是通过绝对路径：以根目录为起点进行切换。

cd 的用法总结如下：

cd 进入用户主目录；
cd ~ 进入用户主目录；
cd - 返回进入此目录之前所在的目录；
cd .. 返回上级目录(若当前目录为”/“，则执行完后还在”/“；”..”为上级目录的意思)；
cd ../.. 返回上两级目录；
cd !$ 把上个命令的参数作为cd参数使用。

补充

命令行中的命令太多，肯定不可能全部记住，所以命令补全是一个非常好用的帮手；当记不全某个命令或路径时，只要按两下 Tab 键，就会出现当前可用的选项——简直是最好的帮手。

例如：如果记不全某个路径，可以按两下 Tab 查看有哪些可用的目录。 （注意：由于 Linux 中目录也被当作文件，不知情地切换进一个文件会报错。）

查看目录

进入目录后，使用 ls 命令查看当前目录的内容。 ls 命令的可用参数：

  • --l 以长格式显示文件和目录信息，包括权限、所有者、大小、创建时间等；链接数、所有者、所属组、文件大小以及文件的最后修改时间等；
  • -a：显示所有文件和文件夹（包括隐藏的文件/文件夹）。

ll 会列出该目录下的所有文件信息，包括隐藏文件，而 ls -l 只列出非隐藏文件，这两个命令并不等价。

如果在后面加上路径，就可以查看指定路径下的文件，而不必先切换到该路径。

创建文件

Linux 中创建文件的常用命令是 touch，命令格式如下：

touch filename

有时可能需要创建一个空文件，这时可以使用 touch 命令轻松创建空文件。

例如：要新建一个文件 testfile，可以使用如下命令。

touch testfile

如果想同时创建多个文件，也可以使用 touch 命令，具体格式如下：

touch file1 file2 ...

只要用空格分隔不同的文件名，就可以创建多个文件。

删除文件

Linux 中删除文件的常用命令是 rm，使用格式如下：

rm [命令选项] filename

常用命令选项：

  • -f：强制删除文件；
  • -r 或 -R：递归处理——将指定目录下的所有文件和子目录一并处理；
  • -i：删除已有文件前先询问用户。 例如，要删除刚才创建的文件 testfile，可以使用如下命令。
rm  -f testfile

创建文件夹

Linux 中创建文件夹的命令是 mkdir，命令格式如下：

mkdir [命令选项] dirname

常用命令选项：-p 或 --parents：如果要创建的目录的上层目录尚不存在，则一并创建上层目录； 例如：要新建一个文件夹 testdir，可以使用如下命令。

mkdir testdir

因为新建的文件夹是空文件夹，所以 ls -l 显示的结果为空。

删除文件夹

Linux 中删除文件夹的命令是 rmdir 或 rm -r，命令格式如下：

rmdir [命令选项] dirname

常用命令选项：-p 或 --parents：删除指定目录后，如果其上层目录已变成空目录，则一并删除；

例如：要删除刚才创建的文件夹 testdir，可以使用如下命令。


rmdir testdir

复制文件和文件夹

Linux 使用 cp 命令把一个或多个源文件或目录复制到指定目录，命令格式如下：

cp [命令选项] 源文件 目的文件

常用命令选项：

  • -f：强制复制文件，不管目标文件是否已经存在；
  • -i：覆盖已有文件前先询问用户；
  • -p：保留源文件或目录的属性；
  • -R/r：递归处理——将指定目录下的所有文件和子目录一并处理。如果要复制目录，就需要使用这个选项。

例如：新建一个文件 newfile 和一个文件夹 newdir，并把 newfile 复制到 newdir 目录下。具体命令如下。

touch newfile
mkdir newdir
cp newfile newdir

移动/重命名文件和文件夹

Linux 使用 mv 命令对文件或目录重命名，或者把文件从一个目录移动到另一个目录，命令格式如下：

mv [命令选项] 源文件 目标文件

常用命令选项：

  • -f：如果要移动的源目录或文件与目标目录或文件同名，则不询问，直接覆盖旧文件；
  • -i：如果要移动的源目录或文件与目标目录或文件同名，则先询问是否覆盖旧文件，输入 y 直接覆盖，输入 n 取消操作。

例如：新建一个文件 newfile 和一个文件夹 newdir，把 newfile 移动到 newdir 目录下，并重命名为 newfileCpy。（如果目标文件不包含路径，则直接对源文件重命名；带路径时，则先移动再重命名。）具体命令如下。

touch newfile
mkdir newdir
mv newfile newdir/ikun

文件查看命令

当我们想查看一些文本文件的内容时，会使用文本编辑器来查看。在 Linux 上，可以使用一些命令来预览文本文件的内容，而不必用文本编辑器打开它。就像查看图片一样——一般直接点开图片就能看，而不需要下载专门的看图软件。本关主要介绍常用的查看命令，例如：cat、head、tail 和 nl。

cat 命令

cat 命令用于连接文件并打印到标准输出设备上。很多人称它为“猫”命令，但实际上 cat 命令是 concatenate 的缩写，意思是连续地显示文本内容。cat 命令常用于查看内容较少的文件，因为当文件太大时，前面的内容会滚出屏幕，就再也看不到了。

head 命令

head 命令可以用来查看文件的开头部分，它有一个常用参数 -n，用于指定显示的行数，默认是 10，即显示 10 行内容。

如果查看文件前 5 行，可以使用命令head -5 filename

tail 命令

tail 命令的作用是把指定文件的最后部分输出到标准设备，通常是终端；通俗地讲，就是把某个档案文件的最后几行（默认最后 10 行）显示在终端上。

tail -f filename 会把 filename 文件的尾部内容显示在屏幕上并不断刷新，只要 filename 有更新，就能看到最新的文件内容。

查看最后文件 5 行命令tail -5 filename

nl 命令

nl 命令把指定的文件加上行号后写到标准输出。空行不编号，但空行仍然存在。

文件编辑基本命令

对于文件编辑操作，可以使用 vi/vim 编辑器；vim 是 vi 的升级版，两者的操作基本相同。 编辑器的基本命令如下：

  • vi filename：打开文件。
  • 在键盘上按 i 或 a 进行编辑：最底部出现 insert 时，表示已进入编辑模式，可以编辑。
  • 按键盘上的 Esc 键：退出编辑模式。
  • 在键盘上输入 :q!：强制退出编辑，不保存。
  • 在键盘上输入 :wq 或 :x：保存文件并退出。
