双标志后检查法

当进程 P0 的 while 循环执行到一半切换到进程 P1 时，P1 也会进入它的 while 循环；当进程 P1 的 while 循环执行到一半又切换回进程 P0 时，P0 的 while 循环仍会继续执行——就这样来回切换，但时钟都卡在各个进程的 while 循环里。

Peterson 算法

让权等待：此时如果进程无法进入临界区，就会在 while 循环中卡住一段时间，浪费处理机资源。
