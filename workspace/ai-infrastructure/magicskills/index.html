The problem

A team using several agents can accumulate many copies of the same SKILL.md directory. Updates then need to be repeated, each agent's available capabilities become harder to track, and framework migrations introduce another integration layer. MagicSkills, developed in Narwhal-Lab, gives those reusable instructions and supporting files a common management workflow.

The practical goal is to maintain a skill once, select an appropriate working set for each agent, and connect that set to different runtimes. The project includes examples for agent applications and frameworks such as Codex, Cursor, LangChain, and CrewAI. See the project overview for the supported integration patterns.

How the pieces fit

Skill discovery. A skill is a directory containing SKILL.md. The implementation records its path, description, and source, allowing the content to stay in ordinary files that can be inspected and versioned.

Collection composition. A Skills instance selects the capabilities needed by one workflow. Several collections can reference the same installed directory. Lookup accepts names or explicit paths, which resolves ambiguity when two directories share a name. These operations live in the collection implementation.

Persistence and integration. REGISTRY stores collection configuration and path references in ~/.magicskills/collections.json; it does not duplicate the complete skill contents. Synchronization generates the skills section of AGENTS.md. Frameworks can instead call the collection's list, read, and execution interface through Python or the CLI. The registry implementation and Python API guide explain these boundaries.

Try the documented workflow

The following example uses the repository's included C-to-AST skill and a fresh collection name. It follows the CLI documentation; Python 3.10–3.13 and Git are required.

git clone https://github.com/Narwhal-Lab/MagicSkills.git
cd MagicSkills
python -m pip install -e .
magicskills install skill_template -t ./demo-skills
magicskills addskills portfolio_demo --skill-list c_2_ast --agent-md-path ./demo-agent/AGENTS.md
magicskills syncskills portfolio_demo
magicskills skill-tool listskill --name portfolio_demo

Review the synchronization prompt to write the generated file. The final command lists the selected skill; reading its instructions and running its parser are separate steps. The sample skill provides those files. Execution uses the current working directory, so an integration must choose its working directory explicitly.
