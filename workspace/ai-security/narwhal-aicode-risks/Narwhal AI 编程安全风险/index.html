概述

一个协作维护的知识库，记录涉及 AI 编程工具及其软件供应链的安全事件。每个案例都关联了受影响的工具、攻击路径、影响以及支撑来源。

  • 存档了参考页面，以保留案例分析背后的证据。
  • 提交了关于 Claude Code 以及 Visual Studio 中 GitHub Copilot 的补充案例研究。
