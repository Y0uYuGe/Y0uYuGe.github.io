## 概述

一个协作维护的知识库，记录涉及 AI 编程工具及其软件供应链的安全事件。每个案例都关联了受影响的工具、攻击路径、影响以及支撑来源。

## 我的贡献

- 研究并记录了涉及 LiteLLM、Nx、Gemini CLI、Cursor 和 Cline 的案例。
- 添加了结构化的 YAML 元数据、攻击链图，以及指向安全公告和事件报告的链接。
- 存档了参考页面，以保留案例分析背后的证据。
- 提交了关于 Claude Code 以及 Visual Studio 中 GitHub Copilot 的补充案例研究。

## 范围

我的工作侧重于基于所引用的安全公告和已发布事件报告的案例研究与文档编写。整体报告由 Narwhal Lab 及其贡献者协作维护。
