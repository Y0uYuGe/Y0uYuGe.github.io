DHKE（Diffie-Hellman 密钥交换）是一种密钥交换协议，不用于加密（要基于 DHKE 进行加密，可以使用 ElGamal）。

它被广泛用于 SSH（Secure Shell）、TLS（Transport Layer Security）和 IPSec（Internet Protocol Security）等协议中。
