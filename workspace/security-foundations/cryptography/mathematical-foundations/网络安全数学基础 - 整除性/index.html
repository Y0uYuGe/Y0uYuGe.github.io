欧几里得算法的证明

  • d1 是 a 和 b 的最大公约数，所以它也是 r 的因子，因此 d1 也是 b 和 r 的公因子
  • d2 是 b 和 r 的最大公约数，所以它也是 a 的因子，因此 d2 也是 a 和 b 的公因子
  • d1 小于等于 d2（d1 是 b 和 r 的公因子）
  • d2 小于等于 d1（d2 是 a 和 b 的公因子）
  • 因此两者相等
