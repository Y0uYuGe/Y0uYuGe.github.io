所有公因子都整除最大公因子。能整除最大公因子的数是 1 和 -1，所以公因子是 1 和 -1；公因子为 1 和 -1 的两个数最大公因子为 1，即互素
![图片](./assets/csdn-143672960/image-030-3646780695.png)
![图片](./assets/csdn-143672960/image-031-c06aa2290e.png)

如下所示，这里 3 和 4 互素
![图片](./assets/csdn-143672960/image-032-04c91ba99d.png)

注意任何整数都是 0 的公因子
![图片](./assets/csdn-143672960/image-033-9c549750a1.png)


欧几里得算法的证明
- d1 是 a 和 b 的最大公约数，所以它也是 r 的因子，因此 d1 也是 b 和 r 的公因子
- d2 是 b 和 r 的最大公约数，所以它也是 a 的因子，因此 d2 也是 a 和 b 的公因子
- d1 小于等于 d2（d1 是 b 和 r 的公因子）
- d2 小于等于 d1（d2 是 a 和 b 的公因子）
- 因此两者相等
