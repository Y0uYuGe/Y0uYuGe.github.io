  • 加密
    A 用 B 的公钥加密
    B 用 B 的私钥解密
  • 认证
    A 用 A 的私钥加密
    B 用 A 的公钥解密

  • 加密 + 认证
    A 先用 A 的私钥加密，再用 B 的公钥加密
    B 先用 B 的私钥解密，再用 A 的公钥解密
