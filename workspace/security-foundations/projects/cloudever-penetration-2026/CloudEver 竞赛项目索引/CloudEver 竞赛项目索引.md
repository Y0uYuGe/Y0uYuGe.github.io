## 竞赛记录

本仓库是 CloudEver 团队参加第二届腾讯云智能渗透测试竞赛的公开概览。其 README 介绍了团队的工作，并链接了 TPT-Agent 和 RedCortex 两个项目，它们探索的是 Agent 辅助的安全工作流以及多智能体协作。

该概览明确说明这些项目是由四名团队成员共同设计和开发的成果，为两个实现提供了背景说明和共同署名。
