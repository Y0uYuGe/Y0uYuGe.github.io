## 概述

IoT_Security_Learning 是一个用于学习嵌入式与 IoT 安全的小型入门合集。目前其 README 链接了一份 IoT 安全教程、异构 PWN 练习材料、另一份学习记录合集，以及一本 IoT 渗透测试书籍的译本。

## 使用方法

打开[仓库 README](https://github.com/Y0uYuGe/IoT_Security_Learning#readme)，选择一个资源，并按照该资源自身的环境搭建说明和前置要求进行学习。所链接的材料归各自作者所有，并保留其各自的许可协议和维护状态。
