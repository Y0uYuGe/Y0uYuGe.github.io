介绍

溢出是指向某个变量中写入的字节数超过了该变量本身所申请的字节数，从而导致与其相邻的变量的值被改变。

int vscanf ( const char * format, va_list arg ); 将格式化数据读入可变参数列表 从标准输入（stdin）读取数据，并按照 format 参数将其存储到 arg 所标识的可变参数列表中各元素所指向的位置。 在内部，该函数如同使用 va_arg 一样从 arg 所标识的列表中获取参数，因此 arg 的状态很可能会被该调用改变。 无论如何，arg 都应在调用之前的某个时刻由 va_start 初始化，并应在调用之后的某个时刻由 va_end 释放。
