大佬说这个函数末尾有一条 movaps 指令：
movaps[rsp+198h+var_158],xmmo
（可以直接在 IDA 的 system 区域搜索该指令是否存在）
该指令要求 rsp+198h+var_158 的值的十六进制形式必须是 0x10 的倍数，否则无法 getshell

方法：

  1. 改变 payload 长度（局部变量入栈，栈长度发生变化），使 rsp 的值发生变化
  2. 利用 ret 使 rsp+1
  3. 利用其他 gadget 影响 rsp
  4. 栈迁移（stack pivoting）：当 payload 长度受限时，不断尝试改变 rsp 的方法
  5. 调用 execve 需要三个参数，要求更高
